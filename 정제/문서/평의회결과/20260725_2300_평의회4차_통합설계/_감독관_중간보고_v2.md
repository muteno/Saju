## 3. ★★두 번째 보고 — 새 다리 241개에 출처가 없다 (v1 §5-A의 확대)

감독관 전수 검사 (23:22 판본):

```
비계층 간선 828개 전체
  근거유형 = '결정론규칙'   828 / 828  (100%)
  author   = '명리 결정론'  828 / 828  (100%)
  source 가 문단 포인터인 것 =  0 / 828  (0%)
  as_of (시간축)            = 전건 null
```

실물:
```json
{"a":"괴강","b":"직업·직무","kind":"발현","polarity":"+","weight":0.7,
 "근거유형":"결정론규칙","source":"신살 발현 배속 — 괴강 = 강한 직업 성향","author":"명리 결정론"}
```

**O6가 이걸 독립으로 확인했다** — 자기 반증 1에서:
> *"관계 간선 587개(→627)는 전부 기계가 만든 것이다. **근거유형 100% 결정론규칙 · author 100% 명리 결정론 — 코퍼스 축자가 한 줄도 없다.** 즉 내가 '유일하게 눈금 있는 척도'라고 부른 것은 우리가 짠 표 위의 거리일 뿐, 코퍼스가 보증하는 거리가 아니다."*

**감독관이 O6보다 한 발 더 나간다 — 이건 척도 문제가 아니라 헌법 문제다.**

1. **프로젝트 헌법 위반 소지.** *"모든 주장에 축자 인용 + 출처"*(소집장 §5). 출처가 **"명리 결정론"이라는 저자 없는 이름**이다.
2. **소집장 R3의 미적용.** 유닛 개념링크는 축자 게이트(38.2% 불합격)를 통과해야 하는데, **간선 층에는 그 게이트가 아예 없다.**
3. **🔴가장 위험한 것 = 신살·발현 계열.** `도화·홍염·역마·삼재·괴강·양인·천을귀인·문창·학당`은
   **저자마다 stance가 갈리는 영역**이다(박재완 오불언 = 신살 언급 금지 · 초명 회의 · 도화도레 중심).
   그걸 `결정론규칙`으로 박으면 **갈리는 것을 안 갈리는 것으로 위조**한 것이다.
   O5가 예측한 오작동 3번(*"계산이 항상 이겨서 축자가 죽는다"*)의 실물이 20분 뒤에 241개로 태어났다.
4. **새 kind `반증`(2건)까지 `결정론규칙`이다.** 반증은 본래 근거 종류를 가리는 장치인데, 그 자신이 무출처다.

**→ 권고: 새 간선을 지우지 말고(헌법 §5), `근거유형` 재라벨 + 문단 포인터 부착을 4차 결정문 실행 항목으로 등재.**
O5의 4축(근거종류/축자강도/확신도/인용자격)과 O6의 `strength`/`confidence` 분리가 정확히 이 자리에 꽂힌다.

### 부수 — `polarity`가 두 뜻으로 섞였다 (감독관 단독)

```
역마     → 이동·이사   '+'  "역마 = 이동·해외"          ← +가 '촉진'(이동을 늘림)
천을귀인 → 구설·송사   '+'  "흉을 푸는 길신(해소 방향)"  ← +가 '해소'(구설을 줄임)
```
**같은 `+`가 대상 축에 정반대로 작용한다.** 엔진이 부호를 합산하면 조용히 틀린다.
→ `polarity` 명세를 확정하거나, 발현용 `effect(증가/감소/해소)`를 분리할 것.

| **O6** | **공기 `w`**(관측 빈도). 21,869개 전부 값이 있으므로 **별개 축이 맞다** | ②strength·⑥confidence와 다른 컬럼 |

**감독관 판정 소견:**
- **원문 충실도는 F3·F4가 가장 높다** — *"시점이 넘는다"*는 상태 변화이지 정적 속성이 아니다.
- **그러나 O6의 지적이 결정적이다:** 지금 `weight` 한 칸에 **②강도와 ⑥신뢰도가 같이 들어 있다.**
  ⑤를 논하기 전에 **②와 ⑥부터 갈라야** 한다. O5(4축 분리)·O6(strength/confidence 분리)가 같은 처방이다.
- **정리 제안(의장용 3층 판정):**
  1. **먼저 `weight`를 `strength`(물리 세기)와 `confidence`(근거 확실성)로 쪼갠다** — O5·O6 합의 사항
  2. **⑤의 최종형 = 동적 활성값**(F3·F4). 명식 층(G2)이 생겨야 구현 가능
  3. **그때까지 ⑤ 채널은 비워두지 말고** F1의 "변화 하이라이트" 또는 O6의 "공기 w 슬라이더"가 임시 점유
  4. F2의 "밝기=신뢰도"는 ⑥의 채널 배정이지 ⑤의 정의가 아님 — **이름을 갈라 부르면 충돌 소멸**

### 🔴M2 — **파이프라인.py를 지금 채택할까** (F5 ↔ O3 정면 충돌)
