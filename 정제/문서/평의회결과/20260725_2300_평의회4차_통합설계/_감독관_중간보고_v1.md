### ⚠발견 1 — 소집장의 21,916은 오기다. 그것도 자기 안에서 모순이다

- 실측 `neuron_edges.jsonl` = **21,869행** (파일 시각 22:54:13, 소집장은 22:57 작성 → **소집장을 쓸 때 이미 21,869였다**).
- 결정적 증거: 소집장이 스스로 적은 **밀도 70.8%**를 역산하면 `21,869 / 30,876 = 70.83%`다.
  21,916으로 계산하면 **70.98%**가 나온다. **소집장 안에서 간선 수와 밀도가 서로 안 맞는다.**
- 즉 21,916은 이전 빌드에서 넘어온 숫자다 — 소집장 §0-2가 경고한 **"틀린 인계 수치"의 9번째 사례**이며,
  경고문을 쓴 문서 자신이 걸렸다. (소집장 §1·§2·§5 **세 군데** 모두 21,916으로 박혀 있다.)
- **정본 = 21,869.** 4인이 독립 실측했고 내가 5번째로 재현했다.

### ⚠발견 2 — 계층 300 vs 315는 3차 평의회 "68링크 사태"의 재발이다

둘 다 참이다. **세는 정의가 다르다.**

```
relation_edges.jsonl 의 계층 300 = 대주제→중주제 51 + 중주제→개념 249
지식망.html 화면의  315       = 위 300 + 뿌리→대주제 15
```
실측: 노드의 대주제 고유값 15 · 중주제 고유값 51 · 개념 249 → `51+249=300`, `15+51+249=315`.

3차에서 같은 68링크가 정의에 따라 20·26·29·32·40·46·52로 갈렸던 그 병이다.
**의장은 "계층 간선"의 정의를 하나로 못 박아야 한다** — 안 하면 다음 인계에서 또 갈린다.
(권고: 파일 정본 300을 쓰고, 화면 표기는 "315(뿌리 포함)"로 괄호를 달 것.)

### ⚠발견 3 — ★위원들이 글 쓰는 20분 사이에 데이터가 바뀌었다

`relation_edges.jsonl` 갱신 시각 = **23:12:40** (생성기 `build_relation_edges.py`는 23:11).

**이 +28개 발현 간선이 정확히 F3이 "없다"고 절규한 그 다리다.**

## 5. ★사각지대 — 아무도 안 다룬 것

### A. 🔴**23:12에 새로 깔린 다리 28개에 "저자 축자"가 하나도 없다** (감독관 단독 발견)

위원들이 잰 뒤에 생긴 간선이라 **5인 중 아무도 못 봤다.** 내가 전수 검사했다.

```
발현 간선 33개 전수:
  근거유형 = '결정론규칙'  33/33 (100%)
  author   = '명리 결정론' 33/33 (100%)
  source 가 문단 포인터인 것 = 0/33  ← 전부 손으로 쓴 산문 설명
  as_of    = null          33/33
비계층 간선 627개 전체 근거유형 = '결정론규칙' 627/627 (100%)
```

실물 예시:
```json
{"a":"괴강","b":"직업·직무","kind":"발현","polarity":"+","weight":0.7,
 "근거유형":"결정론규칙","source":"신살 발현 배속 — 괴강 = 강한 직업 성향","author":"명리 결정론"}
```

**왜 위험한가:**
1. **프로젝트 헌법 위반 소지** — *"모든 주장에 축자 인용 + 출처"*(소집장 §5). 이 간선들은 출처가 "명리 결정론"이라는 **저자 없는 이름**이다.
2. **소집장 R3의 재발** — 유닛 개념링크 68건 중 26건(38.2%)이 저자 축자에 없어서 게이트를 투입했는데, **간선 층에는 그 게이트가 없다.**
3. **특히 신살 발현 11개**(도화·홍염·역마·삼재·괴강·양인·천을귀인·문창·학당·생지·배우자)는 **저자마다 stance가 갈리는 영역**이다 — 박재완 오불언(신살 언급 금지) · 초명 회의 · 도화도레 중심. 그걸 `결정론규칙`으로 박으면 **갈리는 것을 안 갈리는 것으로 위조**한 것이다.
   (오행→장부 5개와 십성→S15 17개는 상대적으로 정론이라 위험이 덜하다. 문제는 신살 11개다.)
4. O5가 §6에서 예측한 오작동 **3번("계산이 항상 이겨서 축자가 죽는다")의 실물**이 20분 뒤에 태어난 셈이다.

**→ 의장 권고: 새 발현 간선 28개를 지우지 말고, `근거유형`을 `결정론규칙`이 아닌 값으로 재라벨하고 문단 포인터를 다는 과제로 즉시 등재.** 특히 신살 11개는 저자 stance 병기 대상이다.

### B. 🔴**`polarity` 필드가 두 가지 뜻으로 섞였다** (감독관 단독 발견)

```
역마     → 이동·이사   polarity '+'   source "역마 = 이동·해외"        ← +가 '촉진'
천을귀인 → 구설·송사   polarity '+'   source "흉을 푸는 길신(해소 방향)" ← +가 '해소(막아줌)'
```
**같은 `+`인데 대상 축에 정반대로 작용한다.** 역마는 이동을 늘리고, 천을귀인은 구설을 줄인다.
엔진이 부호를 합산하는 순간 조용히 틀린다. O5가 말한 *"종류가 다른 것을 같은 자로 쟀다"*의 **새 사례**이고,
F4가 말한 *"polarity는 관계의 부호이지 간선 간 억제가 아니다"*의 **다음 단계 문제**다.
→ 의장 권고: `polarity`의 뜻을 **명세로 확정**하거나, 발현 간선용 `effect(증가/감소/해소)`를 분리.
