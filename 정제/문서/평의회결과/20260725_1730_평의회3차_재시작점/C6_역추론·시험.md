# C6 — 역추론·시험 (Fable — P4를 통과할 수 있나)

> 작성: 2026-07-25, 평의회 3차. 모든 수치는 이 세션이 파일을 직접 열어 잰 것과 추론을 §7에서 분리했다.

---

## 1. 시작점 — 단 하나만

**`gate.py` 배선(1인 감사 1️⃣에 동의)하되, 규칙을 2개가 아니라 3개로 — 위험별칭 208건 + 인용자격 + 역추론 정답유출 문단 18개를 한 모듈에.**

근거 숫자(이 세션 실측): 같은 프로젝트 안에 **게이트의 A/B 실물이 공존한다.**
- 별칭 판정 658건 → 읽는 빌더 **0개** (grep 실측: 생산자 `lint_aliases.py` 1개뿐) → 위험 별칭이 계속 흐름
- 역추론 금지 18건 → 읽는 빌더 **2개** (`build_pilot_UI.py` · `build_pilot_UJ.py`가 `queue_guard` import — grep 실측) → 실제로 exit 1로 막힘

**소비자가 있는 판정만 막고, 없는 판정은 벽에 붙은 종이다** — 추론이 아니라 두 실물의 대조 실측이다. 시험 위원 관점의 추가 이유: queue_guard의 소비자 2개는 **파일럿 빌더 전용**이라, 다음에 만들 유닛 빌더가 import를 빼먹으면 정답 유출이 에러 없이 재개된다. gate.py에 합류시켜야 앞으로의 모든 빌더에 강제된다.

## 2. 현재 수준 — 한 줄 판정

**"순방향 절반, 역방향 0" — 순방향 이론망은 절반쯤 서 있는데, P4가 재려는 역방향(발현→글자)은 유닛 0개·다리 2개·화자분리 0%로 시작조차 안 했다.**

숫자 3개(전부 파일 실측):
1. **역함수(발현→글자) 유닛 0 / 12** — kind 분포 = U-INV 6 + U-JUDGE 6, 4번째 종류 없음
2. **발현축(S15) 노드 10개에 유닛 다리 2 / 92 (2.2%)** — 역추론이 착지할 결과축이 이름만 있음
3. **화자 분리 태깅 0%** — 기출 적격 11편이 문항화 대기 (작업큐 §3 축자: "⛔ 선행 조건 — 화자 분리 태깅이 아직 0%다")

---## 4. 판정 5문 (임무 지시분)

### ① 현 구조(노드 249·유닛 12·다리 21,916)로 P4를 통과할 수 있나 — **못 한다. 원리적으로.**

보드 **1-22** 축자:
> "그래서 이런 노하우와 풀이법을 담기 위해 역추론 시험을 해서 우리으 ㅣ지식이 그만큼 뉴런 사이사이로 얽혀있어서. 그것을 타고가면서 화자랑 대화하면 역추론 까지 오는 도사경지가 될 수 있냐는거지."

P4 = 망을 **역방향으로 타고 오는** 검사다. 모자란 것 4개, 전부 실측:
1. 역함수 유닛 **0개** (필요 최소 3 — 재료는 T2에 있음)
2. 발현축(S15) 유닛 다리 **2 / 92** (건강·직업·재물 등 노드 10개가 사실상 고아)
3. 화자 분리 **0%** → 시험 문항 자체를 못 만듦
4. 도화 유닛 **0 / 12** vs 기출 문항의 도화 비중 **7 / 11 = 63.6%**

**T1 16 / T2 12 / T3 37 분류는 유효 — 파일로 확증.** `queue_역추론.json` 실측: tier 필드 T1=16 · T2=12 · T3=37 (합 65), 기출 16(적격 11 — 부적격사유 필드 5건과 정합), 금지문단 18. `queue_guard.py` 자체점검 로직(절차 문단 통과 / 정답 문단 차단)도 축자 확인.

### ② 환경 관측 대리(근묘화실 = 시대상 + 조상·부모) — **채점에선 빼고 추론에선 넣는다. 문항 스키마를 3분할하라.**

보드 1-22 판독 주 축자: *"채점에서 나이→연주는 '공짜 정보'로 빼되, 추론에서는 환경 인자의 핵심 입력으로 반드시 쓴다. 두 용도를 섞지 말 것."*

**규격 — 문항 파일 3분할:**
```
{ 입력: 게스트 대사·정보만 (1-17 ①),
  공짜정보: { 나이→연주 2글자, 성별+나이→대운 순역 },   ← 추론기 입력 O · 채점 0점
  채점키: 나머지 6글자 (+시주 확정 여부) }               ← 별도 보관, 봇 접근 차단
```

**섞으면 왜 망가지나 — 숫자:** 연주 2글자는 나이만 알면 자동 적중이므로, 섞는 순간 **아무 이론 없는 봇도 8글자 중 2글자 = 기저 적중 25%p**를 공짜로 먹는다. 대운 순역까지 계산분기의 공짜 비트다. P4의 측정 대상은 "망이 기여한 적중"인데 공짜분을 안 빼면 **유닛 0개짜리 봇과 유닛 30개짜리 봇의 점수 차가 25%p만큼 압축**되어 계기판이 무뎌진다. 현 유닛의 환경축 실측: **시대상 0/12 · 근묘화실 3/12** — 스키마 칸은 있는데 채우기는 미착수. U-REV 제작 시 필수 필드로 승격할 것.

### ③ 1-23의 제동을 받아들이면 어디까지 투자하나 — **U-JUDGE 30개 이후. 단 예외 2개는 지금.**

보드 **1-23** 축자:
> "근데 사주는 풀이에 따라서 그 내용이 많이 달라져, 역술인이 바꾸는 술사들을 의미하는거거든. 그니까 이걸 얼마나 정곡을 찌르냐 등등 이건 하나의 예시일 뿐이고, 각 논리와 지식에 담긴 노하우를 확률과 글로, 그리고 알고리즘으로 만들어내야해. 근데 가장 중요한건 데이터 정제임."

"하나의 예시일 뿐" = P4만 최적화하지 말라는 제동. 수용한다. 문항 제작·상시 시험 가동은 **U-JUDGE 30개 이후**다 — 지금 유닛이 닿는 개념이 50/249 = 20.1%뿐이라, 지금 시험을 돌리면 문항 대부분이 "이론 없음"으로 실패해 **시험이 망 품질이 아니라 이론 공백을 측정**한다(그건 개념지도가 이미 하는 일).
**예외 2개(지금 한다):** (a) gate.py에 queue_guard 규칙 합류 — §1 (b) 잔여 18유닛에 **U-REV 3개 포함** — 1-22 판독 주 축자 *"4번째 종류 신설은 선택이 아니라 P4 통과의 전제"*이고, 재료가 이미 큐에 좌표로 있어 추가 비용이 유닛 3개분뿐이다.

### ④ "T2 12편은 시험문항이 아니라 교본" — **맞다. 지금 증류에 써도 P4는 오염되지 않는다. 실측 2개로 논증.**

- **T2 ∩ 기출 = 공집합** (실측: T2 12편 = CT-P032·034·035·036·037·038·039·053·187 / DT-P176 / ST-P0642·0657, 기출 적격 11편과 post 단위 겹침 **0**)
- **금지문단 18개 중 T2 소속 = 0개** (실측: 18개 전부 기출·부적격 post 소속)
- 방향 논증: T2는 "원국을 **알고** 애매한 설정(시간·용신·대운)을 삶의 이력으로 확정" — P4 문항(원국을 **모르고** 추론)의 정답을 노출할 수 있는 구조가 아니다. 보드 **1-17** 축자 규격(*"그들의 대사만 보고 역추론 할 수 있어? … 그럼 '뭐' 겠군요 연주는.. 뭐 이런식으로 하는거 그런 부분은 제외하고"*)이 가리는 대상은 도사 추론 발화·정답 공개부이고, T2 증류는 그 어느 쪽도 건드리지 않는다.
- 안전장치: 실수로 정답 문단을 인용해도 queue_guard가 exit 1 — 단 **§1의 배선 확장이 전제**(현 소비자 2개는 파일럿 빌더뿐).

### ⑤ 1인 감사가 역추론을 확정 순서에서 뺀 것 — **부분 이의. 재료는 썩지 않지만, 순서표 3️⃣에 U-REV를 명시하지 않으면 P4 전제가 또 밀린다.**

- 뺀 것 자체는 수용: "완료 판정 기준 없는 항목은 안 싣는다"는 감사 원칙은 옳고, 문항화는 실제로 화자 분리(미착수) 뒤다.
- **재료 부패 없음**: 큐는 파일 포인터+좌표 저장(`queue_역추론.json`의 file·lines·역추론문단·뽑을_인사이트)이라 시간이 지나도 안 썩는다. 게이트도 배선돼 있다(소비자 2개 실측).
- **진짜 리스크는 재료가 아니라 순서표의 침묵**: 감사 3️⃣(18유닛)의 완료 기준 3개 어디에도 U-REV가 없다. 1-22 판독 주가 "P4 통과의 전제"로 못 박은 4번째 유닛 종류가 **순서표에서 이름이 사라지면**, 30유닛을 다 채우고도 역함수 0개인 상태가 에러 없이 완성된다 — 이 평의회가 잡아야 할 조용한 오작동이다. **수정 요구: 3️⃣ 완료 기준에 "U-REV ≥ 3 (T2 재료, 금지문단 18 회피)" 추가.**
