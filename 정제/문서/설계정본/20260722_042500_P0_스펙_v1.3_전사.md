## 3. paras — 캡션 재조립 (이 작업의 본체)

whisper 본문은 문장 파편 줄들이다. **화제 단위로 묶어 문단을 만든다.**
1. 경계 1순위 = **화제 전환**(새 개념 시작, 다른 인물/사례로 이동, 질문→답변 전환). 목표 입도 = "하나의 주장 또는 하나의 사례"(대략 8~80줄 — 구어라 웹보다 길다).
2. 인트로 인사("하나 둘 셋 도와 안녕하세요")·구독 유도·광고 = `잡동`. 메타데이터 헤더+경고문(1~`---`)도 `잡동` 문단 하나로.
3. kind는 v1과 동일 8종. 구어 특성상 `화법`(시청자 응대·질문 던지기·리액션)과 `사례`(실명·익명 명식 풀이)가 많을 것이다.
4. **quote = 오전사 포함 원문 그대로.** 오전사를 고치는 것은 **절대 금지**다(예: 원문이 "도와살"이면 "도화살"로 고치지 말고 그대로). 표준 용어는 gist에 써라(gist: `도화살 정의…`, quote: `도와살이라고 있어요`). 조회 시 정규화는 P1이 W0 매핑으로 한다.
5. quote는 도구 출력에서 복사(재입력 금지)·자르기만 허용·120자 이내. gist 40자 이내.

## 4. flags — 기존 체계 + 전사 전용 3종 신설

기존: `별점` `결정론` `수치` `실명명식` `프로브` `게이트` `병존` `stance:*` `확인필요` + 고전명.
신설:
- **`역추론`** — (질문을 던지고 → 상대 답을 듣고 → 원국 글자를 추정·확정하는) 실전 장면. **이 코퍼스에서 가장 값진 유형이다.** 장면이 걸치는 문단 전부에 달아라.
- **`콜드오프닝`** — 정보 없이 먼저 특성을 짚고 들어가는 발화("혹시 ~한 편 아니에요?").
- **`오전사후보`** — 사주 용어가 잘못 전사된 것으로 보이는 새 패턴(W0 사전에 없는 것). report에 목록으로도 모아라.
