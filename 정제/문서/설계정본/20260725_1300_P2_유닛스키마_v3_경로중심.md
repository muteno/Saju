# P2 유닛 스키마 v3 — 경로 중심 (2026-07-25, 7대 세션)

> **왜 v3인가:** v2(증류공백진단)는 유닛을 **3종으로 분리**하고 `chain` 필수를 세웠다. 그 처방은 유효하다.
> 그런데 2026-07-25 운영자 브리핑 **1-19 ~ 1-25**가 도착하면서 **네 개의 요구가 동시에 들어왔고, 넷이 같은 것을 가리켰다 — 경로(풀이)를 담을 수 있는 자료구조.**
>
> | 지시 | 요구 |
> |---|---|
> | **1-23** | *"사주는 풀이에 따라서 그 내용이 많이 달라져"* → **결론이 아니라 경로를 저장한다** |
> | **1-19** | 고유 노드 · 하향 트리 · **내려가다 관계 일치하면 옆으로 새어 나감** |
> | **1-20** | 사건 → 방법론 → **기존 망과 대조** → **증분만**(가심비) |
> | **1-22** | 뉴런을 타고 **역방향**으로 갈 수 있어야 도사 경지 → **역함수 유닛 신설** |
>
> **한 줄 요약: 우리가 만드는 건 답이 든 사전이 아니라 풀이 경로가 든 지도다.**
> 현재 상태 진단: 노드 221개·문단 38,072개는 모았고 **경로는 0개** 모았다. "판단 유닛 0개"가 곧 "경로 0개"라는 뜻이다.

## 0. v2 → v3 차이 (한눈에)

| | v2 | **v3** |
|---|---|---|
| 유닛 종류 | 정의 / 판단 / 화법 3종 | **+ 역함수 4종**(발현→글자) |
| chain | 있어야 한다 | **순서·방향·부호를 갖는다.** 뒤 단계가 앞 단계의 결론을 뒤집을 수 있다 |
| 저장 판단 | 좋은 재료면 만든다 | **`delta`가 0이면 만들지 않는다.** 기존 유닛의 근거만 하나 늘린다 |
| 산출 | 유닛 1개 | **확률 · 글 · 알고리즘 3면을 동시에 갖춘 유닛 1개** |
| 링크 | 개념 태그 | **계층(트리) + 횡단(뉴런) 2종.** 횡단 간선은 종류·방향·부호를 갖는다 |
| 입력 | `paras_all.jsonl`(문단당 74자) | **스냅샷 원문 span**(`post.file` + `para.lines`) |
| 근거 | quote 1개 | **chain 축자 3~5개, 합 300자+** |

## 1. 유닛 4종

| 코드 | 종류 | 성격 | 코퍼스 | 대표 소스 |
|---|---|---|---|---|
| `U-DEF` | 정의 | **채집** — 글자·개념이 무엇인가 | 넘침 | 웹 4저자, 초코 커리큘럼 |
| `U-JUDGE` | **판단** | **재구성** — 조건에서 결론까지의 경로 | **얇음 ← 본체** | 절차형 post 236 · 운세 격자 · T2 역검증 |
| `U-SPEAK` | 화법 | **채집** — 어떻게 말하는가/말하지 않는가 | 넘침 | 게이트 2,985 · 헤지 1,975 |
| **`U-INV`** | **역함수** | **재구성** — 발현에서 글자 후보로 | **거의 없음 ← 신설** | `ST-P0657`·`ST-P0642`·`ST-P0290` |

### `U-INV`가 왜 별도 종류인가 (1-22)
U-JUDGE를 거꾸로 읽으면 될 것 같지만 안 된다. 순방향은 `조건 → 결론`이 다:1이고, 역방향은 **항상 분기**한다. 산책처럼이 규칙을 언어화해 놨다:

> `플로리스트다? 그럼 목을 쓰시겠죠 … 목이 고립돼 있을 가능성` / `근데 목기운이 많아도 … 금대운이 들어오면 이 목을 또 쓰게 되거든요` → `그럼 결론은 두 가지의 경우수가 딱 나오네요` (ST-P0657)

**→ 발현→글자는 1:1이 아니라 항상 `{희소·고립} ∪ {과다 + 상대 오행 대운}` 2분기다.** 이걸 순방향 유닛에서 유도할 방법이 없다. 그래서 4번째 종류.
그리고 **U-INV 없이는 P4를 원리적으로 통과할 수 없다** — 시험이 요구하는 방향이 정확히 이 방향이다.

## 3. `chain` 규격 — 순서가 의미다

**`op` 7종:**

| op | 뜻 | 예 |
|---|---|---|
| `관측` | 원국·운에서 무엇이 보이는가 | 월지 진토 = 습토 |
| `계산` | L1 결정론 산출 | 점수론 110점법, 합충 판정 |
| `조회` | 사전 인출 | 편재 = 아버지 |
| `판정` | 임계 비교 | 45 < 50 → 과다 아님 |
| `프로브` | 사용자에게 물음 | "환경이 바뀐 적 있어?" |
| `검증` | 이력과 대조해 가설 확정/기각 | 갑인대운 체감 대조 |
| `반전` | **앞 단계 결론을 뒤집음** | 을경합금(기반) → 우호운이 불리로 |

**`반전`이 v3의 핵심이다.** 인계서 4-3의 실물:
> 용신=목 → 대운 을목이 **을경합금(기반)** → 우호적 운이 불리로 → 세운 갑목이 **갑경충(포켓세운)** → 복구 (`CT-P146-22`)

이건 "다음 단계"가 아니라 **부호를 뒤집는 조건부 간선**이다. 배열 순서 없이는 표현 불가하고, 동시출현 그래프로는 원리적으로 담기지 않는다(순서가 없으므로). **1-23이 자료구조에 내린 명령이 정확히 이것.**

**필수 규칙**
1. `chain` 길이 ≥ 2, `근거` para_id가 붙은 단계 ≥ 2 — 아니면 **P3 반려**
2. 근거 축자 합 **300자 이상**(quote 1개 52자로는 인과 접속어가 0.45개뿐. 원문 문단은 5.37개)
3. **입력은 스냅샷 원문 span** — `paras_all.jsonl`의 gist+quote(74자)로 chain을 쓰면 "결론만 있고 이유 없음"이 대량 생산된다(chain 회수율 8.4% 실측). 이게 정확히 운영자가 금지한 사전 낭독이다
4. `권위 근거형`(`이거는 제 체감상인 겁니다`)은 재현 불가 → 유닛이 아니라 **stance로 격리**. 유닛에 남길 땐 `권위근거: true` + `확률.주의`에 격리 표기(빌더가 검사)
5. **★전사 소스는 연속 줄 span으로 인용한다** (260725 파일럿 2차에서 확정) — 웹 글은 문단이 길지만 유튜브 전사는 Whisper가 캡션 단위로 잘라 **한 줄이 5~15자**다. 한 줄씩 인용하면 근거가 문장 조각 목록이 되어 **인과 흐름이 끊긴다.** `\n`으로 이어진 **원문 연속 구간**을 통째로 인용할 것(축자 검증은 줄바꿈 포함 대조라 그대로 통과한다). ⚠떨어진 줄을 이어 붙이면 저자가 하지 않은 말이 만들어진다 — 반드시 연속이어야 한다
6. **근거 분량 기준은 종류별** — `U-JUDGE 300자 / U-INV 150 / U-SPEAK 120 / U-DEF 80`. **완화 근거가 다르므로 U-INV 기준을 U-JUDGE로 옮기지 말 것.** 여기에 더해 **인과·조건 접속어 ≥ 3개**(분량이 놓치는 "결론만 있고 이유 없음"을 직접 잡는 지표)

## 3-1. ★링크 강도 `weight` — 근거의 종류가 곧 굵기다 (보드 1-26)

운영자 260725: *"그 뉴런(키워드)간 연결의 강도는 얼마나 이게 강하게 붙어있느냐지… 그 강도는 굵기, 채색으로도 나눌 수 있는 느낌"*
그리고 같은 지시에서 **근거의 등급이 판정됐다**: *"저 사람들의 임상은 어차피 다 거의 수술 결과를 말하는 거나 다름없으니까 권위가 없다. 이런 의견도 있었다 정도로 링크만 걸되, 그 정도를 약하게 하면 됨."*

**→ weight는 임의로 매기지 않는다. 근거의 종류에서 결정론적으로 나온다.**

| 근거유형 | weight | 뜻 |
|---|---:|---|
| `축자정의` | **1.0** | 저자가 정의로 못 박은 것(`기준이 일관입니다`) |
| `다저자합의` | **0.9** | 서로 다른 계보에서 같은 말(계보 보정 후) |
| `단일저자논증` | **0.7** | 한 저자가 근거를 대며 논증 |
| `사례` | **0.5** | 사례 1건에서 도출 |
| **`권위·임상`** | **0.2** | `임상에서 느낀겁니다` — **성공 사례만 선택 보고되는 구조라 근거력 없음.** 삭제하지 않고 얇게 건다 |
| `추론` | **0.1** | 우리가 메운 것(축자 없음) |

**규칙**
1. 링크에 `weight`가 없으면 유닛의 `근거유형`에서 상속한다. 링크별 override 가능(같은 유닛 안에서도 이견 없는 부분은 굵게, 갑론을박은 얇게).
2. **`권위근거: true`인 유닛은 `weight ≤ 0.3`인 약한 링크를 최소 하나 가져야 한다** — 빌더가 강제. 없으면 임상 주장을 단단한 링크로 위장한 것이다.
3. **삭제는 여전히 금지.** 채택/폐기 이분법이 아니라 **가중치가 제3의 처분**이다(운영자가 제시).

## 3-2. ★갑론을박은 결론이 아니라 분기로 담는다 (보드 1-26 ①)

> *"월지 일지는 다들 갑론을박이 많고, 뭐가 더 중요하다라기보다는 **어떤 상황에 그게 적용되냐**의 개념이 더 강해"*

우열을 정해 하나를 버리면 그 순간 다른 관법의 사용자가 틀린 답을 받는다. 그래서:
- **결론 필드에 우열을 쓰지 않는다.** `precondition`에 적용 국면을 쓰고, 두 가중을 **각각 산출**한다.
- **결과가 갈리면 계산 분기 카드로 넘긴다**(운영자 260722: 두 후보의 결과가 어긋나는 지점을 역질문).
- delta 유형은 `부호반전`이 아니라 **`판본추가`** — 뒤집는 게 아니라 판본이 하나 느는 것이다(보드 1-24: 풀이 다각도가 자산).
- 실물: `UJ-0004`(뿌리 위치). 월지·일지 링크는 `rel: 분기후보` · `weight: 0.2`, 이견 적은 부분(연지 최약·통근 전제)은 0.9.

## 4. `delta` 규격 — 만들지 않을 용기

보드 1-20의 4단을 그대로 절차로 굳힌 것. **③대조가 사람 눈으로는 불가능하다**(개념 221 × 문단 38,072) → **대조 자체가 도구여야 한다.**

| delta.type | 뜻 | 처분 |
|---|---|---|
| `신규개념` | 망에 없던 개념 | 유닛 생성 + 사전 등재 |
| `신규경로` | 개념은 있는데 그 경로가 없음 | **유닛 생성 (가장 값진 것)** |
| `조건정밀화` | 기존 경로에 조건 추가 | 유닛 생성(기존 유닛에 링크) |
| `반례` | 기존 결론을 뒤집음 | 유닛 생성 + `반증` 횡단 간선 |
| `판본추가` | 다른 저자가 같은 결론을 다른 경로로 | **유닛 생성**(1-24: 풀이 다각도가 자산) |
| `부호반전` | 조건에 따라 결론 부호가 뒤집힘 | 유닛 생성 + chain에 `반전` 단계 |
| `근거보강` | 같은 말을 한 번 더 | **⛔유닛 생성 금지.** 기존 유닛의 `근거[]`에 축자 1개만 추가 |

> **가심비 판정 = "이걸 저장해서 망이 무엇을 새로 할 수 있게 되나".** 답이 "없음"이면 근거보강이다.
