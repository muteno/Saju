# W0 Q-카탈로그 v1 (초판) + C층 절차 문법 v1 초안

- **작성(KST):** 2026-07-21 21:55 실측 · 설계 v2.2 §4 W0 ④ 산출물 + §1-1 동결 항목(C층 문법) 초안
- **정체:** Q-카탈로그는 **C층 데이터**다 — 지식을 새로 만들지 않고 B층 유닛을 인용만 한다(축자 원칙 보호). 이 초판의 키셋은 **통설 스켈레톤**(통독 지식 기반 뼈대)이며, P2 증류에서 근거 유닛이 연결되기 전에는 **실전 발화에 사용 금지**(부정 게이트: 근거 유닛 포인터가 빈 엔트리는 조회 전용).
- **증보 규칙:** 유형·필드 구조는 안정 유지, 엔트리는 append. P1 히트맵·P2 웨이브마다 키셋과 근거 포인터를 채운다.

## §0. C층 절차 문법 v1 (초안 — P0 착수 시점에 동결 선언)

C층 선언형 데이터는 3종뿐이다. 공통 원칙: **유닛 포인터 없는 주장 필드 금지 · 절차는 순서 있는 스텝 · 모든 확률은 내부용(§헤지 사다리로만 렌더)**.

```
① 가설카드 (루프 A 구현체 — 전체 필드는 설계 v2.2 §2가 정본)
   {id, 트리거_키셋[], 선행_체크[], 후보_상황, 확인_질문{유형, 선택지[{텍스트, 배후_가설}], 탈출구},
    확률{prior_밴드, 우도표, hits, misses}, 적중_시{해석, 조언}, 빗나감_시{리커버리, 다음_후보},
    근거_유닛[]}

② 레시피 (통변 절차 — "보는 순서"의 선언형)
   {id, 목적(주제 도메인), 스텝[{순서, 행동(키 계산|유닛 조회|판정|질문), 입력, 출력, 분기 조건}],
    선행_게이트(예: 신강약 판정 스텝이 용신 스텝보다 앞 — 위반 시 P3 반려), 근거_유닛[]}
   ※운영자 정리본의 6단 절차(본질일간→나일주→에너지월지→조화→흐름→궁합)는 '가설' 레시피로 등록
     — 코퍼스 통변 방법론(웹 28편)과 어긋나면 코퍼스가 이긴다(결정 로그).

③ Q-엔트리 (이 문서의 본체 — 질문·사건 → 조회 계획)
   {id, 루프(A|B|C), 유형(§1·§2 분류), 사용자_발화_예, 조회_키셋[](축0 문법),
    선행_게이트, 확인_질문_유형(§2의 5형 중), 근거_상태(스켈레톤|유닛연결완료)}
```

## §1. 질문 유형론 — 내담자→앱 (사공 6형 기반, ✅축자 확보)

"좋은 질문은 좋은 대답을 이끌어 낼 수 있습니다"(사공, 「사주 상담 똑똑하게 질문하기」 211219). 앱은 사용자의 자유 발화를 아래 6형으로 분류해 라우팅한다.

| 유형 | 원형 예시 | 라우팅 |
|---|---|---|
| Q1 방법·과정 | "어떻게 하면 ~할 수 있을까?" | 레시피 → 환경 조언(확률을 올리는 행동 프레임) |
| Q2 선택 (A vs B) | "이직할까 남을까?" | 두 선택지 각각의 키셋 대조 조회("내담자가 미리 고민하여 선택을 축약" — 사공) |
| Q3 해결책 | "이 문제 어떻게 풀지?" | 문제→사건 역매핑(§4) → 조언 |
| Q4 문제의 이유 ★루프 B의 원형 | "왜 자꾸 이런 일이 생기지?" | 사건 역매핑 → 당시 운 계산 → 운×원국 유닛 |
| Q5 성향·특성 | "나는 어떤 사람이야?" ★루프 A 진입점 | 원국 성향 유닛 + 가설 카드 개시 |
| Q6 주의사항 | "조심할 게 뭐야?" | 운 유닛(기신운 시기) + 헤지 사다리 렌더 |

**나쁜 질문 2형 → 변환 규칙(✅사공):**
- "내 사주 어때요?"(평가 유도) → Q5로 재프레임("점수 매기기보다, 어떤 기질인지부터 볼게" 톤).
- "내 사주 나빠요?"(답정너 — 공포 마케팅 진입로) → Q4/Q6으로 재프레임 + **공포 조장 출력 금지 게이트**(초명 "좋다/나쁘다 개념이 따로 존재하지 않는다" 스탠스가 근거).

## §2. 프로브 유형론 — 앱→내담자 (도화도레 실전 5형, ✅축자 확보)

가설 카드의 '확인 질문' 표준. 규칙 4개: **①모든 선택지는 배후 가설에 매핑(장식 금지) ②'둘 다 아니야' 탈출구 필수 ③첫 가설 스테이크 전 질문 예산 2~3개 ④후보를 가장 고르게 가르는 질문 우선**("혹시 양간이신가요?" = 집합 이등분 원형).

| 유형 | 실측 원형(사주탐구영역 ep.1 등) | 용도 |
|---|---|---|
| P1 이지선다 | "무터 아니면 임수예요?" (→무토/임수) | 후보 2개 최종 변별 |
| P2 집합분할 | "혹시 양간이신가요?" | 후보셋 절반 소거 |
| P3 개수척도 | "정제(→정재)나 정관이 많나요, 혹시?" | 구성 비율 확인 |
| P4 운 체감 | "임술 어땠어요? 힘드셨어요? 좋았어요?" · "혹시 22년도 때 어떠셨어요?"(연도 앵커) | 운 시점 대조로 확률 갱신 |
| P5 스테이크드 리빌 | "그럼 나는 약간 갑자일 것 같은데?" → "정답 말씀드릴까요?" | 내기 톤 공개(헤지 필수, 리커버리 장전) |
| + 제시형 화법 | "~사주다라는 생각이 들더라고요. 혹시 맞을까요?" (240615 자영업 편) | 가설 카드 '후보 상황 서술'의 표준 문형 |

## §4. 사건 유형 → 키 역매핑 초판 (루프 B "왜?"용)

※동일 — 스켈레톤. 사건 서술 → 유형 분류 → 당시 운 계산 → 아래 키셋 조회.

| 사건 유형 | 역매핑 키셋(스켈레톤) |
|---|---|
| 이직·퇴사·해고 | 운:관성 충/합·교운기·신살:역마 발동·공식:상관견관 |
| 이별·이혼·다툼 | 관계:충/원진@일지·운이 배우자성(재/관) 극·신살:도화/홍염 운 |
| 금전 손실·사기 | 공식:군겁쟁재(비겁운에 재 다툼)·공식:탐재괴인·재성 입고(⚠유파차) |
| 사고·건강 이상 | 신살:백호/양인 운 중첩·충@일지·오행 과다 폭주(전도 규칙) |
| 이사·이동·해외 | 신살:역마 운·관계:충@주거궁(⚠궁위 배속 유파차) |
| 시험·합격·승진 | 십성:인성운(문서)·공식:관인상생 성립 시점·신살:문창 |
| 소송·관재 | 십성:편관(칠살) 운·공식:관살혼잡 촉발·신살:천라지망 |
| 새 만남·인연 | 신살:도화 운·관계:합@일지·십성:재/관 운 도래 |

**환경 귀인 규칙(설계 v2.2 §2):** 루프 B에서 사건은 사용자가 보고한 입력이다 — 운으로 설명하되, 설명이 막힐 때 미기록 환경을 지어내 변명하지 않는다("운도 원국도 조용했네 — 이건 사주 밖 일이었을 수 있어"가 정직한 출력).

## §6. 갭 목록 (P1 히트맵에서 확인·충원할 것)

1. 건강·소송 도메인의 웹 근거 밀도 미확인(통독 범위 밖) — 히트맵 요주의.
