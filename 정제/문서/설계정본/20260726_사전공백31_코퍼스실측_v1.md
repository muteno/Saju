> 1. **보드는 근거가 아니다. 코퍼스 문단 수가 근거다.** 보드에 있어도 코퍼스에 없으면 `기각`.

> 3. **문단 수와 글 수를 둘 다 쟀다.** 전사·격자 코퍼스는 제목 반복 문단이 많아 문단 수만 보면 부풀려진다(예: 편인도식 147문단이지만 33글).
> 4. 저자는 클러스터로 병합해 셌다: 도화도레+도화로운=**도화(김정훈)**, 현묘+안녕사주명리=**현묘**. 최대 7클러스터(초코서당·현묘·도화·사공·산책처럼·명리학탐구·플러스명리학).
> 5. 짧은 별칭은 전부 표본을 직접 열어 오탐률을 쟀다. 못 잰 것은 `[미측정]`.

## 0. 한 장 요약 (운영자용 쉬운 말)

**보드에 있는데 우리 사전에 없다던 31개를 코퍼스에서 하나하나 세어봤다. 결과는 3무더기다.**

| 판정 | 건수 | 뜻 |
|---|---:|---|
| **등재** | **21** | 코퍼스에 진짜 많이 나온다. 사전에 넣어야 한다 (새 노드 15 + 기존 노드에 별칭만 추가 6) |
| **보류** | **5** | 나오긴 하는데 1~6문단뿐이라 얇다. 노드로 만들기엔 이르다 |
| **기각** | **5** | **코퍼스에 0번 나온다.** 보드(운영자 수업 노트)에만 있는 말이다 |

**가장 중요한 발견 3가지:**
1. **보드 출현 횟수는 코퍼스 규모를 전혀 예측하지 못했다.** 보드에 2번 나온 편인도식이 코퍼스엔 178문단, 보드 2번의 재생관이 127문단. 반대로 보드에 6번 나온 부성입묘는 코퍼스 **0문단**. → "보드에 자주 나오니 중요하겠지"라는 추측은 위험하다는 게 숫자로 확인됐다.
2. **이름이 다른 경우가 3건 있었다.** 보드가 부르는 이름과 코퍼스(저자들)가 부르는 이름이 다르다: 보드 '재성입묘' → 코퍼스는 **재고귀인**(42문단), 보드 '상형' → 코퍼스는 주로 **인사형·사신형·축술형·술미형**(222문단), 보드 '6단계 절차' → 코퍼스는 각자의 **풀이 순서**(27문단+). 사전에는 **코퍼스가 쓰는 이름**으로 넣어야 조회가 뚫리지 않는다.
3. **기각 5건(자매강강·군겁탈부 / 부성입묘 / 삼전공망 / 록전록후 / 구류업)은 보드 특수 개념이다.** 넣으려면 코퍼스 근거가 아니라 "운영자 정리본 가설" 태그(B갈래, weight 낮게)로만 넣어야 한다.

## 3. 상세 근거 (축자 표본)

### 3-1. 합화 성립조건 — 개념은 풍부, 보드의 이름만 없다
- 조건·성립 서술 34문단·27글·5저자(패턴 기반이라 **하한선**). 축자:
  - `천간합은 조건이 되어야만 합화(合化…)가 이루어지지만` (SG-BASIC-P054-02, 사공)
  - `갑기합만 성립할 뿐, 합화가 되지 않습니다` (MT-BASIC-P075-01, 명리학탐구)
  - `원국에서는 웬만해서는 합화가 되지 않습니다` (CT-P245-10, 초코)
  - `운에서는 무조건 합이 이루어지고, 합화가 이루어진다 (단, 충이 동시에…)` (PL-SIPSIN-P030-04, 현묘) — **원국/운 이원 규칙**까지 확보
- '합이화' 0문단. '합이불화'는 명리학탐구 목차 1문단뿐. → **노드를 새로 만들지 말고 기존 `합화` 노드에 별칭(합이불화·화기격·합화격)과 규칙 문단을 붙이는 게 맞다.**

### 3-2. 합이불합(일간 불합) — 이름 0, 규칙 축자는 2저자
- `일간은 합을 하지 않는다` (PL-SIPSIN-P030-02, 현묘) · `일간은 합화가 될 수 없다` (CHO-HAP-P001-08, 초코 웹) · `일간이 합파하는 경우는 없어요`(=합화 오전사 추정, CT-P133-35, 초코 라이브)
- 5문단·3글·2저자 = 사전 노드로는 얇다. **하지만 L1 결정론 규칙(일간 합거 금지)으로는 2저자 축자 확보** → 규칙집 채택 권고. 보드의 "거리 우선순위" 절반은 [미측정](용어 없이 서술만 있어 기계 탐색 불가).

### 3-3. 부분삼형·자묘형 — 보드의 '상형'은 코퍼스에서 두 갈래로 갈린다
- 보드 뜻(삼형 중 2글자): 코퍼스 실명은 **인사형·사신형·축술형·술미형**(222문단·107글·6저자). 규칙 축자: `삼형살에서 하나가 빠진 두 글자… 삼형보다는 많이 약하다`(MT-BASIC-P012-05) · `인사형, 인신형, 축술형, 술미형 등도 약한 삼형의 기운으로 판단`(PL-JAPYEONG-P016-01) · 사공은 방합×삼합 세로 조합으로 **산출 원리**까지(SG-BASIC-P058-01).
- 단어 '상형'의 코퍼스 주 용법은 **자묘상형**(초코 10글, 전용 영상 "자묘상형은 찐 능력자!"). 초코 축자: `상형은 자묘상형 하나뿐이죠`(CT-P115-03) — **보드 용법과 정면 충돌.**
- → 노드 2개 권고: **①부분삼형(2자형) ②자묘형**. 현 사전엔 자묘형이 삼형·자형 어느 별칭에도 없다(공백). '상형'이라는 표기는 두 노드가 나눠 갖는 다의어라 단독 별칭 등재 금지.

### 3-4. 진도화·가도화 — 도화도레 메인 관법인데 정의가 3파전
- 도화도레(6글): **일지 기준** 진도화 판정(DT-P026-05 `저는 신사를 볼 일지를 기준으로 봅니다`), 진도화=매력 실체·가도화=사람이 모임(DT-P026-04).
- 사공(1글): 연살(12신살)=진도화, 왕지 글자=가도화, `출처를 잘 알 수 없으나 흔히 가도화(假桃花)`(SG-SINSAL-P012-03·06) + 하위명칭 사전(월장·나체·곤랑·도삽·월령도화 21문단).
- 도화로운(1글): 자미두수 탐랑=`가장 순도 높은 도화살인 진도화(眞桃花)`(DR-P627-11).
- → 등재하되 **stance 3병기 필수.** 오전사: `진도와 가도화 개념`(DT-P006-07).

### 3-5. 천문성 — 6저자 확증, 단 문단 수는 접어 읽어라
- 현묘 299글 중 294글 = 연운 일주 글마다 반복되는 정형문 1문장(`일주와 상관없이 卯월(양력 3월 경)에 태어난 사람은 임인년에 천의성, 천문성이 성립합니다` — HM-Y2020~2024 전 60일주 글 복붙). **P1 반복 접기 규칙의 정확한 표적.**
- 접고 남는 실질: 현묘 전용 글(천의성·천문성, 2019-06-16) · 산책처럼 전용 영상("천라지망은 왜 천문성이 있을까" ST-P0492, 총 8글) · 초코 술해천문 시리즈(6글) · 도화도레 3글 · 사공 신살 목록 · 플러스명리학 → **6저자. 등재 확고.**
- ⚠별칭 충돌 주의: `술해천문`은 현 사전에서 **천라지망의 별칭**으로 이미 등재됨. 천문성 노드를 만들면 이 표기를 누가 갖는지 정해야 한다(공유 등재 시 뉴런망의 "긴 별칭 우선" 규칙 확인 필요). 오전사: 수레천문·술래천문(초코 라이브).
- **덤 발견: `천의성`(天醫星)도 사전에 없다.** 천문성과 같은 글·같은 정형문에서 동행(사공 신살 목록에도). 다음 보강 후보로 등재 제안.

### 3-6. 풀이 순서 — 보드 6단계는 없지만, 저자마다 자기 순서를 명문화했다
- 보드의 "본질→나→에너지→조화→흐름→궁합" 단계명 조합: 축자 0.
- 코퍼스의 실물: 초코 `사주를 풀이하는 순서 첫번째가 뭘까요? 일간입니다`(CT-P024-03, 책 집필 언급까지 CT-P049-20) · 도화도레 `일간, 일지, 월지, 오행, 배치, 십성…순으로`(DT-P081-25) · 사공 `통변은 아래와 같이 크게 5단계로`(SG-MID-P002) · 플러스 "사주풀이 순서"(PL-JAPYEONG-P004·P006·P031) · 현묘 상담 실황(HM-P034-01).
- → S11에 **'풀이 순서(통변 순서)' 노드 신설**, 보드 6단계는 그 노드의 **B갈래 가설**로만 매달 것.

### 3-7. 재고귀인 — 보드 '재성입묘'의 코퍼스 실명
- '재성입묘' 축자 0, 재성~입묘 25자 근접도 0. 대신 **재고귀인 42문단·14글·4저자**(도화 7글 — 전용 영상 "재고귀인 테스트" DT-P035, 도화로운 부자사주 글 DR-P010 `재고귀인은 땅에 돈이…`).
- 뜻은 보드 증보(L971 "재성이 지장간에 숨는 경우")와 같은 뿌리(재성의 창고/입묘지)이나, 코퍼스는 길신(부자 사주 인자)로 쓴다. → **노드명 재고귀인로 등재**, '재성입묘'는 보드 가설 표기로만 기록.

### 3-8. 십성 분류축·공식 — 자평진전 원문까지 확보
- 사길신·사흉신: `3. 財官印食 차용신지선이순용지자야 … 4. 煞傷刼刃 살상겁인 용신지불선이역용지자야`(SG-MID-P017-12, **자평진전 원문+번역**) · `사길신 - 재관인식(정재, 정관, 정인, 식신)… 사흉신 - 살상겁효(편관, 상관, 겁재, 편인)`(PL-MANSE-P019-02 — **겁인/겁효 두 판본이 코퍼스에 다 있다**).
- 현대적 재해석 stance 풍부(초코 `절대 사길신과…`(CT-P133-04) · 도화로운 "사흉신의 현대적 해석" 전용 글) → 분류축 노드에 stance 병기 재료 완비.
- 편인도식 원리 축자: `편인이 식신을 극하기 때문에 편인을 일컬어 "도식, 탈식"이라고`(PL-SIPSIN-P026-07) + 밥그릇 서술 7문단·4저자.
- 상관패인 뜻풀이: `상관이 마패처럼 인성을 차고 있다`(CT-P231-10, '상관폐인'으로 오전사). 참고: **재격패인**(재성이 인성을 봄, 플러스 5글)은 별개 공식 — 차기 후보.
- 재생관: 7저자 전원. `재생관(財生官)과 기부 문화` 전용 글(현묘 PL-SIPSIN-P037) · 흉화 버전 **재생살**(PL-SIPSIN-P022-06)도 1건 — 차기 후보.
- 관살혼잡: 초코 전용 영상 + 일주론 다수. **십성 혼잡 일반**(인성혼잡·식상혼잡·재성혼잡·재살혼잡)이 53문단·45글로 따로 크다 — '혼잡(십성 일반)' 상위 노드 검토 권고.

## 7. 다음 담당(사전 반영자)에게 — 반영 시 주의 4가지

1. **TAXONOMY는 내가 건드리지 않았다.** 이 문서는 제안서다. 반영 시 §1 표의 게이트(괄호 정규식)를 별칭과 함께 옮겨야 한다 — 게이트 없이 별칭만 넣으면 `해` 4.0% 사고가 재발한다(상형·일귀·진방합·활인·염상·윤하·도식이 위험 별칭).
2. **중복 등재 금지(1-19① 고유성) 체크 3건:** 효신(이미 편인 별칭) · 술해천문(이미 천라지망 별칭) · 궁성(이미 궁위 별칭). 새 노드가 이 표기를 나눠 가지려면 기존 노드와의 소유권을 명시적으로 정할 것.
3. **문단 수만 보고 가중치 주지 말 것.** 천문성(정형문 복붙)·편인도식(제목 반복)·가도화(사공 1글 17문단)는 접기(대표 1+반복 N) 후의 글 수가 실질이다. 이 표에 글 수를 같이 적은 이유다.
4. **기각 5건을 버리지는 말 것.** 보드 B갈래 가설(`근거유형: 가설(운영자 정리본)`, weight ≤0.3, 승격대기)로는 남겨둘 가치가 있다 — 나중에 석우당·효명작명 등 신규 전사가 들어오면 재측정 트리거(대조표 §재검토 트리거와 같은 방식).
