## 1. 알게 된 사실 — 코퍼스가 가르쳐준 것 (미션 크리티컬 순)

### 1-1. 방법론의 지형 (가장 중요)
- **우리가 만들려는 것의 인간 버전이 이미 존재한다.** 초코서당 = 백과사전(지식) + 상담사 양성(2년 커리큘럼, 20명) + 무료상담(실증 루프, 월 72건). 그들의 상담 원칙 = "사주만 갖고 맞추지 않는다 · 문진지(연도별 이력) · 근거 없는 말 금지 · 품평 금지 · **용신은 원국만으론 1차 추정, 삶의 이력과 대조해 확정**". 우리 가설카드→발현확인→확정 루프와 동형. **위협이 아니라 지도이자, 운영자의 "통달자 감수" 후보군.**
- **적중의 두 가지 길이 코퍼스에 반쪽씩 있다.** 도화도레 = 정보 없이 맞혀서 신뢰 획득(블라인드 역추론·콜드 오프닝). 초코 = 정보를 받아 정밀해짐(문진·프로필 누적). 심지어 초명은 공개통변(일방향)을 "가능성을 제한한다"며 스스로 중단했다 — **일방향 해석의 한계를 실무자가 자인**. → 앱 = 첫 만남은 도레식(선택지 내밀기), 재방문은 초코식(누적 정밀화). 운영자의 스무고개 루프가 양쪽에서 실증된다.
- **내담자가 지불하는 것은 적중이 아니라 '이유'다.** 초코 무료상담 후기 21건의 공통 언어 = "왜 그런지 알게 되어" · "근거를 갖고 설명" · "이해가 되니 마음이 풀렸다". 적중 자랑 후기가 아니라 설명 만족 후기가 지배적. **축자 인용+근거 제시 절대원칙은 윤리 조항이 아니라 상품성의 핵심.**
- **저자마다 '관법 자백 문장'이 있다.** 현묘: "제 관법의 중심축은 세 가지 — 인시일수론, T존, 묘운력". 초명: "일주론을 넘어 간지론으로"(+박청화 "명리는 결국 간지학" 계승). 증류(P2)는 이 척추 문장에서 시작해 살을 붙이는 방식이 옳다 — 문단을 균등하게 갈지 말고.

### 1-2. 유파 지형 (stance 지도 — 병기 없이는 코퍼스가 자기모순)
- **4대 대립축**: ①십이운성(초코 "십성 못지않게 중요" 적극 수용+삼합 구조에 활용 / 현묘 "허상, 버립시다" — 게다가 현묘는 자기 초기 콘텐츠를 뒤집은 것 → **저자 내 시계열 stance 축 필수**) ②하루의 시작(초코 자시 / 현묘 인시일수론 — L1 엔진 분기: 자시·축시생 일주 변경) ③역사·국운 십신 해석(초코 활용[경자년 나열·갑오 상관 등, 단 "국운은 알 수 없다" 면책 병행] / 현묘 배격["갑오년에는 북반구 전체에서 개혁이 일어났어야"]) ④통계·임상(초코 인용["3만 일주×MBTI"·이혼율·전왕 5~7%] / 현묘 "빅데이터니 통계니 하는 궤변" — 단 현묘도 묘운력 120:1에서 "임상 결과를 우선 적용"이라 예외 자인).
- **계보가 하나로 얽혀 있다**: 초명은 현묘 블로그로 글 구성을 사사했다고 명시 + 강헌(철공소)·안도균·박청화·김동완·하건충 인용. 현묘도 철공소 명리 엔진 참여. **4저자 일치 = 독립 확증이 아니라 같은 상류의 메아리일 수 있음** → 교차 확증 가중치에 계보 보정 필수(v2.2 반영됨). 안도균 삼각존(일간=의식·일지=신체·월지=무의식)과 현묘 T존의 유사성도 이 맥락(비교 검토 미결).
- 억부 vs 조후: 초코 "조후용신은 억부용신을 중점 파악한 후 2차" 선언 — 운영자 결핍보충(=억부) 직관과 정합. 궁통보감 공식화 비판은 초코·현묘 공통.

### 1-3. 엔진(L1·L2)에 꽂히는 결정론 지식
- **충 해석 알고리즘**(초코 갑경충·진술충 편 — 이번 통독 최대의 구현 수확): 1:1충=활성화 / 쟁충=배가("쟁합은 반감, 쟁충은 배가") / 수화충=정신·목금충=현실 사고 / 붕충=지장간 내부 충 검사 → **"원국에 없는 오행"이 손상** → 건강(최우선)·십성·육친 3축 판정 / 합이 충을 해소 / 전극(대운⊥세운) / 뿌리·거리 보정.
- **지장간 수치**: 생지 23/23/54% · 왕지 33/67% · 고지 30/10/60% · 오화 33/30/37% + 형성 규칙 5 + 유파차(하건충은 생지·왕지 초기 무시, 인원용사는 한국서 불채택). **안도균 위치별 점수표**(월지 8, 일지·시지·일간 4, 나머지 3; 태과 14+/평기 6~13/불급 3~5).
- **병존 6종의 60갑자 결정론**(을을→을유시 유일, 병병→병신시=광역역마, 무무→무오시=해외역마, 기기→기사시=좁은 역마 등) — 기계 검증 가능 주장군.
- **합화 판정**: 원국 내 합화는 희귀(1:1+무방해+주변 지원+인접) · **일간은 절대 합화 불가** · 합화 시 십성은 오행 단위 재해석.
- **투간(같은 간지만)/투출(오행도 가능·대세운도)/통근(천간 기준·거리 무관)** 용어 3분 + 신왕(뿌리)≠신강(세력) 구분.
- **연운 문법**: 연운=전 지구 공통, 대운이라는 담벼락 아래 / 천간 상반기·지지 하반기(소운법) / 운 간지 자체의 강약(갑진년 갑목=간여지동급) / 길흉(결과)≠희기(원인)·희기동소.
- L1 입력 스펙 재확증: 생년월일시+성별+출생지역(지역보정·균시차), 시간 미상은 초명도 상담 거절. 진태양시 기준(현묘 "해시계").

### 1-4. 콘텐츠·시장 사실
- 시장: 포스텔러 "압도적 점유율", AI 사주 대중화(현묘 "제미나이나 쳇GPT로 사주 보는" 2026 실황), 운세박람회 개최, 웹툰·방송 자문 수요(초명), 수강생 여성 8할·2030 절반.

- 현묘의 AI론이 우리 합격선을 정의: "AI가 A4 30장을 쏟아내도 삶을 관통하는 단 하나의 패턴을 못 잡는다 · 전문가 = 정보를 더하는 게 아니라 **덜어내는 힘**" → 통달 봇 = 정보 폭포가 아니라 단일 관법으로 수렴하는 봇.
- 저작권: 초명 글은 글별로 문구 상이(전면 금지형 vs 출처 명기 시 2차 재편집 허용형) — **P0에서 글별 라이선스 태그 필수**, 상업 편입은 운영자-저자 협의 검토(미결).

## 2. 비전 (제품이 완성됐을 때의 모습)

> **"근거를 보여주는 용한 친구."** 생년월일시를 넣으면 앱이 먼저 "혹시 요즘 이런 거 아니야?"라고 선택지를 내민다(도레식 콜드 오프닝). 맞으면 소름, 빗나가면 산뜻하게 다음 가설로(헤지 사다리·리커버리). 대화할수록 내 발현 프로필이 쌓여 점점 정밀해진다(초코식 문진). 무슨 일이 생기면 "왜?"를 물으러 돌아오고(충 알고리즘 역추적), 아침엔 일진을 확인한다(연운·월운 문법). 모든 발화는 4저자 코퍼스의 축자 인용에 닿아 있고, 이견은 "현묘는 이렇게, 초명은 이렇게 봐"라고 병기한다 — 단정하지 않되 물러서지도 않는다.

## 3. 미션 (지금 하는 일의 정의)

**고수의 노하우를 확률 트리로 데이터화한다.** 고수는 데이터화를 못 하고, 기존 앱은 노하우가 없다 — 그 교집합이 우리 진입 지점(운영자 창업 논리). 이를 위해 1,100만 자+246편을 "키로 조회되는 유닛"으로 정제한다. 절대원칙: RAG 금지 · 결정론 조회 · 축자+출처 · 이견 병기 · LLM은 서술층. 통달 판정 = 역추론(발화만 보고 원국 산출).

## 4. 방향성 — 전략적 선택들 (이유와 함께)

1. **P0은 청사진이다**(운영자 재정의): 야채썰기가 아니라 "약재를 어떻게 썰지" 정하는 단계. 문단 경계·태그 체계가 증류 품질의 상한을 정한다. → 스펙에 최고 수준 투입, 실행은 fan-out.
2. **포인터-퍼스트 인벤토리**: 문단 저장소는 원문 복사가 아니라 (파일·줄범위) 포인터+태그+요지. 축자 정본은 동결 스냅샷(P0_인벤토리/webtxt_v1)에 있다. 이유: ①축자 왜곡 원천 차단 ②산출량 1/10 ③"유닛은 원본 포인터+축자만 보유" 원칙과 일치.
3. **증류 순서 = 웹 먼저, 저자 집필 순서**(v2.1): 1차 배치 = 초코·현묘·사공·명리학탐구. 운세 대양(이달의 운세 242만 바이트 등)과 전사 246편은 후속 라운드 — 운세는 "사례은행" 소스로 취급.
4. **stance 병기는 생존 조건**: 같은 계보 안에서도 4축이 갈린다. 유닛 스키마의 stance 필드는 장식이 아니라 조회 결과의 신뢰를 만드는 뼈대.
5. **하이브리드 오케스트레이션**: 판단·승격·게이트는 메인 세션, 기계적 스캔·문단화는 에이전트. 에이전트 산출물은 전량 메인 검수 통과 후 정식 반입(운영자 "모니터링 감시" 지시와 일치).
6. **직관 프라이머**: 세션이 바뀌어도 "감"을 재주입할 시동 팩을 웨이브마다 재생성. 이번 통독의 후보 1페이지 = 현묘 "덜어내는 힘" + 초코 "문진·1차 추정" + 도레 콜드 오프닝 + 헤지 사다리.

## 6. 직관·감 (2대의 날것 — 다음 나에게)

- **저자의 자백을 찾아라.** 백만 자보다 "내 중심축은 셋"이라는 한 줄이 값지다. P2 첫 작업은 저자별 척추 문장 확정.
- **게이트 문장이 걸려들면 정제가 잘 되고 있는 것이다.** "좋다/나쁘다는 없다"(초코) · "모든 상담은 근거와 함께"(초코) · "덜어내는 힘"(현묘) · "확률이 좀 크죠"(도레 헤지) — 스키마가 늘어나는 것보다 이런 문장이 유닛에 계속 잡히는 게 품질 신호.
- **초코는 '구조적 원인 규명' 패턴이 반복된다**: 고서 흉평 → 60갑자 조합의 수학적 유일성으로 원인 해명 → 시대 보정 재해석 → 명암 병기. 이 4단 패턴 자체를 유닛 유형으로 삼을 것.
- **현묘는 반증리스트를 준다**: 세운 물상 환원 금지·국운 금지·색 처방 금지·개별 유기체 한정. 우리 출력 게이트의 부정 규칙(negative rules)은 현묘 코퍼스에서 뽑는 게 가장 풍부하다.
- **운세 코퍼스는 '해석'이 아니라 '화법' 광맥이다**: 연운 총론의 서사 구조(전년 리뷰→간지 의미→과거 사례→예측→활용 처방)가 일진·월운 루프의 콘텐츠 템플릿.
- **에이전트 검수에서 볼 것**: 요약으로 원문을 대체했는지(반려 1순위), 문단 경계가 소제목과 어긋나는지, 태그 남발(과목 3개 초과)인지, 라이선스 태그 누락(초코)인지.
