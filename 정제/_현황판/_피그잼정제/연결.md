# 보드는 표 목록이 아니다 — «다 이어져 있다»

> 운영자 지시: *"저거 행성 표하고 다 연결되어있는거야 / 다 붙여"*
> 이 문서는 **A가 B의 근거로 쓰이는 자리**만 적는다. 결론은 없다.
> 표기: `A ──[관계]──▶ B` · 줄번호는 `figjam_board_full.md` 기준(`raw`라고 적힌 것은 `figjam_board_raw.txt`).

## 1. 자전축 → 육합 → 합화오행 → 계절 → 행성 → 오행 (운영자가 짚은 그 줄)

**위치: 2426–2579(육합 절). 지지 라벨은 `raw` 에만 있었다(→ 해설 §0).**

원형 도해다. 12지지가 원둘레에 놓이고, **육합 짝이 좌우로 마주 본다.** 그 마주 보는 축이 곧 **지구의 자전축(23.5˚)** 이고, 짝마다 합화 오행 → 계절 → 행성이 붙는다.

| 육합 쌍 | 합화 | 계절 | 행성 | 종류 |
|---|---|---|---|---|
| 자·축 (子丑) | 토(土) | — | **토성** | 극합 |
| 인·해 (寅亥) | 목(木) | **봄** | **목성** | 생합 |
| 묘·술 (卯戌) | 화(火) | **여름** | **화성** | 극합 |
| 진·유 (辰酉) | 금(金) | **가을** | **금성** | 생합 |
| 사·신 (巳申) | 수(水) | **겨울** | **수성** | 극합 |
| 오·미 (午未) | 화(火) | — | **태양** | 생합 |

**이어지는 자리:**
- `자전축 23.5˚` ──[도해의 축]──▶ `육합 6쌍` (2432)
- `육합 쌍` ──[합화]──▶ `오행` ──[배속]──▶ `계절` ──[배속]──▶ `행성`
- `육합축` ──[수직 교차]──▶ **`해(害)`** — 보드 축자: 「해 = 육합을 푼다 / 육합과 **수직으로 교차하며(자전축과 평행)** 완화하는 관계」(2976). 해 절(2926)의 도해에도 「지구의 자전축(23.5˚)」이 다시 나온다.
- `육합축` ──[수직 교차]──▶ **`파(破)`** — 파 절(3042)에도 「지구의 자전축(23.5˚)」이 반복된다. **파의 도해도 같은 축 위에 그려져 있다.**
- `계절` ──[배속]──▶ `오행 5` ──[배속]──▶ **`방위·오상·상징색·장기·물상·숫자`** (raw 10천간 절)
  - 木 동(東)·인(仁)·초록·간·나무/풀꽃·3·8 / 火 남(南)·예(禮)·빨강·심·태양/달난로·2·7 / 土 중앙·신(信)·황색·비·넓은땅/경계있는땅·5·10 / 金 서(西)·의(義)·흰색·폐·도끼큰바위/칼바늘보석·4·9 / 水 북(北)·지(智)·검정·신·강바다/안개이슬눈·1·6
- `오상(인예신의지)` ──[재등장]──▶ 음양오행 절(592–600)에 **「인(仁)·예(禮)·신(信)·의(義)·지(智)」와 「중용(中庸)」**이 따로 또 있다 → 같은 배속이 두 곳에서 쓰인다.

**왜 중요한가(구조로만 말하면):** 오행 배속의 근거가 보드 안에서 «천문 → 육합 → 합화 → 계절»로 **거슬러 올라가 닫힌다.** 오행이 먼저 있고 나중에 방위를 붙인 게 아니라, 자전축 도해 하나에서 육합·해·파·오행·행성이 **같이** 나온다.

## 2. 황도 → 절기 → 월지 → 조후

- `태양황경(0˚~345˚, 15˚ 등차)` ──[정의]──▶ `24절기` (1466–1594) — 절기마다 **양력 날짜 + 각도**가 함께 적혀 있다.
- `24절기` ──[12절만 추림]──▶ `12절(節)` ──[띠바뀜]──▶ **`월지`** — 보드 축자 「12절기 / (띠바뀜)」(1466–1468)
- `월지` ──[판정 기준]──▶ **`한(寒)-난(煖)`** — 「한(寒)-난(煖) 월지 중심으로 판단」(1596)
- `일지` ──[판정 기준]──▶ **`조(燥)-습(濕)`** — 「조(燥)-습(濕) 일지 중심으로 판단」(1598)
- `한난조습` ──[투입]──▶ **`사주풀이 4단계 «조화»`** — 절차표 「4-1. **조후관계**, 십성 분석 신강·신약」(306)
- `공간(위도·경도)` ──[생성]──▶ `한난조습` — 명(命) 절 축자 「지구의 위도, 경도에 따른 태양의 영향에 따라 **한난조습(寒暖燥濕) 형성**」(334)
  → **조후의 뿌리가 «공간»이고, 공간은 보드가 「바꿀 수 있는 것」이라고 못 박은 유일한 축이다.**
- `황도` ──[재등장]──▶ 12지 절 머리(raw)의 황도 설명, 그리고 육합 도해의 자전축. **같은 천문 골격이 세 번 쓰인다.**

## 3. 지지의 세 얼굴 — 생지/왕지/고지가 모든 관계표의 «행 이름»이다

`생지(인신사해) · 왕지(자오묘유) · 고지(진술축미)` 이 3분류가 보드 전체를 관통하는 **인덱스 키**다.

| 쓰이는 곳 | 어떻게 |
|---|---|
| 삼합 (2374) | 첫 글자=생지 · 둘째=왕지 · 셋째=고지 |
| **십이신살 (3405)** | 조건이 전부 「(어느) 삼합국의 **생지/왕지/고지**」로 서술된다 |
| 지지충 (2580–2723) | 「생지/왕지/고지 **간에** 충하는 관계」 → 인신·사해(생지) / 자오·묘유(왕지) / 진술·축미(고지) |
| 파 (3050) | 「생지, 왕지, 고지 끼리 파가 됨」 → 생지파·왕지파·고지파 |
| 형 (2746) | 방합·삼합 겹침에서 「생지의 충돌 / 왕지의 충돌 / 고지의 충돌」 |
| 지장간 (1710–1872) | 생지 7/7/16 · 왕지 10/20 · 고지 9/3/18 — **일수 배분 자체가 이 3분류로 갈린다** |
| 삼합 반합 강도 (2374) | 「생지반합이 고지반합보다 강도가 쎄다」 |
| 12지 표 (1252–1274) | 12지지 각각에 (생지)/(왕지)/(고지) 표기 |
| 신살 별칭 | 생지=**역마** · 왕지=**도화** · 고지=**화개** (1874·1902·1930) |

→ **하나만 알면 여섯 표를 다 읽는다.** 이게 이 보드가 «인덱싱 표»인 이유다.

## 4. 삼합국 / 방합국 → 십이신살 12종 + 고신·과숙

`기준지(연지 또는 일지)` ──[속한 삼합국]──▶ `현재/이전/다음/반대 삼합국` ──[그 국의 생지·왕지·고지]──▶ `신살`

| 신살 | 조건 |
|---|---|
| 겁살 | 이전 삼합국의 **생지** |
| 재살(수옥살) | 반대 삼합국의 **왕지** |
| 천살 | 다음 삼합국의 **고지** |
| 지살 | 현재 삼합국의 **생지** |
| 년살(진도화) | 이전 삼합국의 **왕지** |
| 월살(고초살) | 반대 삼합국의 **고지** |
| 망신살 | 다음 삼합국의 **생지** |
| 장성살 | 현재 삼합국의 **왕지** |
| 반안살(금여) | 이전 삼합국의 **고지** |
| 역마살 | 반대 삼합국의 **왕지** |
| 육해살 | 다음 삼합국의 **왕지** |
| 화개살 | 현재 삼합국의 **고지** |
| **고신살(남)** | **다음 방합국의 생지** |
| **과숙살(여)** | **이전 방합국의 고지** |

**이어지는 자리:**
- `삼합국` ──[정의]──▶ 12신살 전부 (3405) · **`방합국`** ──[정의]──▶ 고신·과숙만
- `년살(진도화)` ──[전환 조건]──▶ **`지지충`** — 「가도화→진도화 (지지충 발생 시)」(3410)
- `왕지 절`도 같은 말을 한다 — 「왕지충/형 발생 시 … **가도화살이 진도화처럼 발현**」(1906). **두 곳이 서로를 뒷받침한다.**
- `반안살` 별칭이 **금여** — 그런데 같은 보드의 대격자에는 «금여록»이 일간 기준으로 따로 있다(§6). **같은 이름의 서로 다른 산출 두 개가 보드에 공존한다.** 병기 대상.
- `기준 판본` ──[갈림]──▶ 「기존 명리: 연지(사회 → 나)」 / 「현대 명리: 일지(내 행동 → 사회)」 (3403) — **어느 쪽을 쓰라는 말이 없다.**

## 5. 방합 + 삼합이 «겹치는 자리»에서 형(刑)이 나온다

보드가 형의 **생성 원리**를 직접 적었다 (2746). 형은 별표가 아니라 **두 합의 간섭 결과**다.

| 방합 | 삼합 | 겹침 | 생지 충돌 | 왕지 충돌 | 고지 충돌 |
|---|---|---|---|---|---|
| 인묘진(東·木) | 신자진(冬·水) | 발산 ↔ 수렴 | 인신형 | **자묘형** | 진진형 |
| 사오미(南·火) | 인오술(夏·火) | 염상에 염상 | 사인형 | 오오형 | 미술형 |
| 신유술(西·金) | 사유축(秋·金) | 예기에 예기 | 신사형 | 유유형 | 술축형 |
| 해자축(北·水) | 해묘미(春·木) | 발산 ↔ 수렴 | 해해형 | **자묘형** | 축미형 |

- 「이러한 합에서 **자묘형이 두 번 중첩되므로 별도로 표현**」 → 자묘형이 따로 절(2738)을 가진 이유가 여기서 나온다.
- 「공간은 체(體), 시간은 용(用)」 — 방합=공간, 삼합=시간. **§9 체용론과 같은 어휘.**
- `삼형(인사신)` ──[구성]──▶ 「인신 → 충 / 사신 → 합, 파, 형」 (2732–2734) — **한 조합 안에서 충·합·파·형이 동시에 성립한다.**
- `자형(진진·오오·유유·해해)` ──[성립]──▶ **`병존`** — 「午辰酉亥 **병존**이 됐을 때」(2744) → 지지 카드의 «병존» 줄과 직결(§7).

## 6. 십이운성 격자 → 신살 배정 (보드 최대 조견표의 배선)

이 표(3371–3399)는 **신살표가 아니라 «십이운성 격자에 신살을 얹은» 이중 표**다.

```
일간 10  ×  십이운성 12단계  →  지지 1개 확정  →  그 칸에 걸리는 신살 목록 + 성립요건
```

- `일간` + `장생지` ──[순행/역행]──▶ `십이운성 배정` (3270: 「양일간: 순행 / 음일간: 역행」)
- `십이운성 배정` ──[칸이 곧 지지]──▶ **`신살 배정`**
- 표 머리의 판정 단서 두 개가 **체용론과 이어진다**:
  - 「음영된 부분은 일지에 위치할 수 없음(**‘체’ 기준**, 일간과 일지의 음양이 같아야함)」(3367)
  - 칸마다 「(체+)」·「(체−)」 표기

**어느 십이운성 자리에 어느 신살이 앉는가 — 보드가 실제로 배선해 둔 것:**

| 십이운성 단계 | 그 자리에 앉은 신살 |
|---|---|
| 월지(별도 행) | 홍염살 3(을·기·계) |
| 장생 | 암록 2 · 홍염 1 · 천을귀인(일귀격) 2 · 천문성 · 현침살 |
| 목욕 | **금여록 6** · 고란살 3 · 천을귀인 1 · 천문성 · 현침살 |
| 관대 | 천을귀인 2 · 암록 3 · **간여지동 2** · 백호대살 3 · 홍염 1 · 천문성 |
| **건록** | **건록 10(전 일간)** · **간여지동 5** · 고란살 1 · 홍염 1 · 현침살 |
| **제왕** | **양인살 5** · 간여지동 4 · 고란 1 · 홍염 1 · 천문성 |
| 쇠 | **금여록 4** · 백호대살 2 · 괴강살 1 · 천을귀인 1 · 홍염 1 · 천문성 |
| 병 | 암록 4 · 천을귀인 2 · 고란살 1 · 천문성 · 현침살 |
| 사 | 천을귀인 2 · 홍염 1 · 천문성 · 현침살 |
| 묘 | 천을귀인 2 · 암록 2 · 백호대살 2 · **괴강살 2** · 간여지동 2 · 천문성 |
| 절 | 천을귀인 3 · 현침살 |
| 태 | 천을귀인 4(일귀격 2) · 천문성 · 현침살 |
| 양 | **괴강살 1** · 백호대살 1 · 천을귀인 1 · 천문성 · 현침살 |

**여기서 드러나는 결선:**
- `건록(乾祿)` ──[바로 다음 칸]──▶ **`양인`** — 표에서 건록 행 바로 아래가 제왕 행이고, 양인살은 정확히 **제왕 행에만** 있다. 그리고 규칙 절(322)이 같은 말을 글로 적었다 — 「양일생은 건록의 **다음** 글자가 양인 / 음일생은 건록의 **앞** 글자」. **표와 글이 서로를 검증한다.**
- `건록` ──[동일 칸]──▶ **`간여지동`** — 건록 행 10칸 중 5칸에 간여지동이 겹친다. 규칙 절도 「건록(**일주 간여지동에 해당하는 지지**)」라고 못 박는다.
- `간여지동` ──[등장 자리]──▶ 건록·제왕·관대·묘 — **일간과 지지의 오행이 같은 12쌍**이 이 네 단계에 흩어져 앉는다.
- `양인` ──[강도]──▶ **`비겁`** — 「비겁 ×2」(양간) / 「비겁 +0.5」(음간) → **양인이 신강약 계산에 직접 들어간다**(§8).
- `양인` ──[합]──▶ **`편관(칠살)`** = 양인합살 (3429) ──[처분]──▶ **`용신`**(「양인격이 강할 때에는 이를 극하거나 설기하는 쪽으로 용신을 삼음」)
- `건록` ──[자리별 차등]──▶ **`근묘화실`** — 「연주: 건록으로 보지 않음 / 월주: 사회궁 / 일주: 전록 / 시주: 귀록」(3321)
- `양인` ──[자리별 강도]──▶ **`근묘화실`** — 「월 > 일 > 연 > 시」(3433)

## 7. 지지 12글자 카드 — 한 글자에 걸리는 모든 관계가 «한 장»에 모여 있다

1990–2273. 이 형식이 값이다. 우리 지도는 이걸 «쌍 목록»으로 흩어서만 갖고 있어 「이 글자 하나에 뭐가 다 걸리나」를 못 본다.

```
지지 1글자
 ├─ 병존 (같은 글자 2개)          → 자형(진·오·유·해)과 직결
 ├─ 합 ─┬─ 반 방합 (이웃 글자)
 │      ├─ 반 삼합 (건너 글자)
 │      └─ 육합 (마주 글자)        → §1 행성축
 ├─ 충  (마주 6칸)
 ├─ 귀문관살
 ├─ 원진살
 └─ 귀문/원진 «동시 발현» 표시     → §10 중첩표와 대응
```

**동시발현 표시가 붙은 글자(원문 「#귀문/원진 동시 발현」) — 실측 8개:** 묘 · 진 · 사 · 오 · 술 · 신 · 해 · 축
(안 붙은 4개: 인 · 미 · 유 · 자)

→ **이 8개가 원진표의 「귀문관 중첩 여부 O」 4쌍(진해 · 축오 · 사술 · 묘신)을 글자로 푼 것과 정확히 같다.**
→ 그리고 §10의 판본 불일치(사술이 원진표에선 O, 귀문표에선 X)에 대해 **카드 12장이 원진표 편을 든다.** 카드는 «글자 시점», 표는 «쌍 시점» — 같은 사실의 두 표현이고, 셋 중 둘이 일치한다.

**카드 ↔ 표의 교차 검증 자리:**
- 카드의 「충: 신(申)」(인목) ↔ 지충 절의 「인신충」 — **12칸 전부 일치**
- 카드의 「합: (육합) 寅+亥=木」 ↔ 육합 도해의 인해합 목성 — **6쌍 전부 일치**
- 카드의 「원진살: 유(酉)」(인목) ↔ 원진표 「인유(寅酉)」 — 일치
- 카드의 「병존: 辰辰 #자형에 해당」 ↔ 자형 규칙 「午辰酉亥 병존」 — **카드가 규칙을 명시적으로 가리킨다**

## 8. 지장간 → 통근/투출 → 득령 → 신강약 → 용신 → 대세운 (계산 사슬)

보드에서 유일하게 **끝까지 이어지는 계산 사슬**이다.

```
지지 ──▶ 지장간(여기·중기·정기 + 일수)
            │
            ├─[천간에 같은 글자]──▶ 통근
            ├─[지장간 오행이 천간에]──▶ 투출
            └─[지장간 간지가 천간에]──▶ 투간 ──[월간이면]──▶ 격(格)
                                                    │
월지 ──▶ 월령 ──[비/인이면]──▶ 득령 ──[사령이면]──▶ 더 강한 득령
            │                          ▲
            └─[식/재/관이면]──▶ 실령    └─ ⚠「월지가 일간의 욕(浴地)이면 득령 아님」
                                            = 십이운성이 강약 판정에 개입하는 지점
            │
            ▼
   신강약 (110점: 천간 각10 · 연지10 · 월지30 · 일지15 · 시지15)
            │      + 양인 가산(비겁 ×2 / +0.5)
            │      + 십이운성 강도(왕/중/약)
            ▼
      30 신약 / 45 중화 / 60 신강
            │
            ▼
   용신 (용희한 3 : 기구 2)
            │
            ▼
   대세운 유불리 ──▶ 교운기(대운 마지막 해 하반기 / 세운 11월 중후반 / 월운 매달 마지막 주)
```

**연결 축자:**
- `지장간 강도` ──[통근 판정에 사용]──▶ 「통근했는지 정도는 지장간의 1)비겁/인성인지, 2)**비겁/인성 지장간의 강도(여기/중기/정기)**로 확인」(2276)
- `투출 서열` = 「**정기 > 여기 > 중기** 순으로 투출될수록 강함」(1946) — **지장간 일수(18>9>3, 16>7>7)와 서열이 정확히 맞는다.** 일수표가 서열의 근거다.
- `십이운성` ──[개입]──▶ `득령` — 「월지가 일간의 욕(浴地)에 해당하는 경우에는 득령했다고 볼 수 없음」(2278). **십이운성이 «참고 지표»가 아니라 강약 판정의 게이트로 쓰인다.**
- `신강약` ──[투입]──▶ 사주풀이 절차 「4-1. 조후관계, 십성 분석 **신강·신약**」 → 「4-2. **용신 분석** 용희한(3):기구(2)」(306–307)
- `건록·제왕운` ──[신강/신약별 처분]──▶ 「신강한 사주: 지나침 관리 / 신약한 사주: 기회와 도전」(3321) — **운 해석이 강약 판정 결과에 조건부로 갈린다.**

## 9. 체(體)와 용(用) — 보드가 세 곳에서 같은 어휘를 쓴다

| 위치 | 무엇을 체/용으로 나누나 |
|---|---|
| 12지 표 (1348·1390) | **「체(본질:천간음양)」 / 「용(쓰임:지지음양)」** — 지지 하나에 음양이 두 벌 |
| 형의 생성 원리 (2746) | **「공간은 체(體), 시간은 용(用)」** — 방합=공간=체 / 삼합=시간=용 |
| 대격자 (3367 + 칸마다) | 「음영된 부분은 일지에 위치할 수 없음(**‘체’ 기준**, 일간과 일지의 음양이 같아야함)」 · 「(체+)」「(체−)」 |

→ 운영자 260722 확정 「**사해오자 = 체용 구분 채택**」의 보드 근거가 여기다. 그리고 보드는 그 구분을 **신살 판정의 게이트로 실제 사용**하고 있다(대격자). 즉 「어떤 맥락에서 體를 쓰는가」라는 기존 미결 질문에 보드가 답 하나를 준다 — **일지 배치 가능 여부 판정.**

## 10. 원진 ↔ 귀문관살 — 두 표가 서로를 참조한다

| 원진 6쌍 | 강도 | 귀문 중첩 |   | 귀문 6쌍 | 강도 | 원진 중첩 |
|---|---|---|---|---|---|---|
| 진해 | +++ | O |   | 인미 | +++ | X |
| 축오 | ++ | O |   | 묘신 | ++ | O |
| 사술 | ++ | O |   | 진해 | ++ | O |
| 묘신 | ++ | O |   | 축오 | + | O |
| 자미 | + | X |   | 사술 | + | X |
| 인유 | + | X |   | 자유 | − | X |

- **⚠두 표의 중첩 표기가 서로 어긋난다.** 원진표는 사술을 「귀문 중첩 O」라 하고, 귀문표는 사술을 「원진 중첩 X」라 한다. 진해·축오·묘신 3쌍은 양쪽 O로 일치.
  → **제3의 증거로 §7 지지 카드 12장이 있다.** 「#귀문/원진 동시 발현」이 붙은 8글자(묘진사오술신해축)가 **원진표의 O 4쌍과 정확히 일치**한다. 3표 중 2표가 같은 값 → 병기하되 원진표 쪽이 무겁다.
- `형성 조건`이 **같은 문장**이다 — 원진·귀문 둘 다 「원국에서: 일지와 월지(또는 시지)의 합 / 맞닿은 지지만 유효 / 궁합에서: 상호간 일지 / 운에서: 운과 일지」(3186·3249). 귀문 쪽에만 궁합 항에 「(확인 필요)」가 붙어 있다.
- `귀문` ──[근거]──▶ **`자전축`** — 「인미(寅未)가 귀신이 寅(간방) 未(곤방), **지구 자전축 23.5도와 유사**」(3260) → **§1 자전축이 여기서 또 나온다.**
- `원진 구성 원리` ──[근거]──▶ **`충`** — 「일간 지지와 **충 관계에 있는 지지의 전/후**와 짝을 이뤄 원진」(3192). **원진은 충에서 파생된다.**

## 11. 공망 — 계산식과 표가 서로를 대체한다

- `천간 10 ≠ 지지 12` ──[부조화]──▶ `공망` (3210)
