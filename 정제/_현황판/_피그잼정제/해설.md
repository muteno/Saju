## 🚨 0. 가장 먼저 — 정본이 원본의 일부를 통째로 버리고 있었다

**`figjam_board_full.md` 는 완전한 추출본이 아니다.**

그 파일을 만든 `extract_board.py` 의 `walk()` 가 처리하는 태그는
`section · table · text · shape · sticky · rounded-rectangle · widget · connector` 뿐이다.
그런데 raw 원본의 태그 분포는 이렇다.

| 태그 | 개수 | full.md 반영 |
|---|---:|---|
| text | 1,456 | ✅ |
| table-cell | 991 | ✅ |
| **shape-with-text** | **661** | **❌ 통째로 누락** |
| frame | 450 | (컨테이너) |
| connector | 171 | ✅(라벨만) |
| rounded-rectangle | 133 | ✅ |
| section | 89 | ✅ |

두 가지가 겹쳤다.
① `shape-with-text` 는 `walk()` 의 `else` 로 떨어져 **내용을 찍지 않고 자식만 순회**한다.
② 게다가 이 노드는 내용이 `name` 속성이 아니라 **element text**(`<shape-with-text …>여기</shape-with-text>`)에 들어 있어, `text`/`shape` 분기에 넣었더라도 여전히 안 나왔다.

**실측 손실 = 55,406자 → 69,364자 (+13,958자, +25%).**
그래서 `figjam_board_full.md` 의 `#### 10천간 / ##### 木` 절은 **라벨만 있고 값이 하나도 없다**(본질·방위·오상·상징색·장기·물상·숫자가 전부 빈칸으로 보인다). 값은 전부 `shape-with-text` 에 있었다.

- 검증: 재추출본은 full.md 의 **모든 줄을 포함하는 진부분집합**이다(누락 0, 헤더 3줄만 다름).
- 재추출기 = `<스크래치패드>\extract_full2.py` (원본 무수정, 산출도 스크래치패드에만 씀).

## 2. 🟡 중간지대 — 개념 정의·분류 서술 (계산 규칙은 아니지만 개념 노트에 쓸 수 있는 것)

아래는 **«해설»이다.** 계산에 넣지 마라. 개념 노트의 «이 개념이 무엇인가»에만 쓴다.

### 2-1. 운(運)과 명(命)의 정의
- **운** = 움직일 행(行), 운전할 운(運). 「변하는 것 / 움직이게 하는 것」. 운전에 비유 — 앞으로 마주할 도로의 형태와 시점을 예측하면 잘 운전할 수 있다. 운은 시공간의 변화.
  - **[1] 시간 = 바꿀 수 없는 것.** 시작(태어남)과 끝(죽음)의 기준. 자신이 있는 곳을 기준으로 함(사주는 지구의 공전·자전에 따라 성립).
  - **[2] 공간 = 바꿀 수 있는 것.** 위도·경도에 따른 태양의 영향으로 한난조습(寒暖燥濕)이 형성됨. **「현대 시대에 와서 자신의 근본을 바꿀 수 있는 유일한 요인으로 변화 / 현대 명리와 과거 명리가 다른 가장 큰 이유」**
- **명** = 사주 팔자. 「불변하는 것 / 움직이는 것」. 사람이 첫 호흡해서 세상으로부터 받아들인 타고난 기운을 연·월·일·시로 구분. **월지(부모, 1020 시기)와 일주(나, 3050 시기)를 가장 중요시.**
- 보드 최상단의 3분법: **1. 정해져 있는 것(운명) = 주체(명, 1차원) + 흐름(운, 2차원) → [예측]의 단계 / 2. 정해지지 않은 것(태도) = 상태(태, 3차원) → [변화]의 단계.**
  - ※운영자 해석 철학 1원칙(「명 = 기질, 운명 아님」)·2원칙(「환경 = 사주 밖 변수」)과 같은 골격이 보드에 이미 적혀 있다.

### 2-2. 생지 / 왕지 / 고지의 분류 정의
- **생지 = 계절의 시작 (인신사해 寅申巳亥)** — 역마에 해당
- **왕지 = 계절의 절정 (자오묘유 子午卯酉)** — 도화에 해당. 「순수한 성향(해당하는 오행의 지장간으로만 구성)」
- **고지 = 계절의 마무리 (진술축미 辰戌丑未)** — 화개에 해당. 「(묘지=환절기)」
- 고지의 구조: **여기 = 현 계절 / 중기 = 전 계절 / 정기 = 자기 자신.** 「[중기(전 계절)]의 무덤이 됨」 → 진=수의 묘지, 술=화의 묘지, 축=금의 묘지, 미=목의 묘지.

### 2-3. 삼합 / 방합 / 육합의 성격 구분 (계산이 아니라 «무엇인가»)
- **삼합 = 사회적인 합.** 「서로 떨어진 기운이 합하여 특정한 오행을 같이 지향 / 공식적인, 내 삶의 외적인 부분, 직업적 역할」. 방합(공간)에 비해 삼합은 **«시간»적인 개념**. 「국(局)」은 어떠한 세력을 의미.
- **방합 = 공간의 합.** 국을 이루면 곡직(木)·염상(火)·종혁(金)·윤하(水).
- **육합 = 1:1의 강력한 합.** 「묶임/중단/연기의 뉘앙스」. 1:1 궁합에서 가장 강함.
- **한 계절은 «전» 계절에 시작해서 «다음» 계절의 «토»에서 끝난다.**

### 2-4. 충·형·해·파·원진·귀문·공망의 «정의»
- **충** = 충돌한다·부딪힌다·무용(無用)하게 된다·쓸 수 없게 된다·깨지고 부숴진다. 「해석 → 긍정/부정 모두 가능」. 「8글자가 10성을 다 가지지 못하므로 우리 삶은 부족할 수밖에 없음」
- **형(刑)** = 「‘가둠’의 의미. 범죄, 사고와 관련 多」. 별칭: 인사신=무은지형(無恩之刑) / 축술미=지세지형(持勢之刑) / 자묘=무례지형(無禮之刑).
- **해(害)** = **육합을 푼다.** 「육합과 수직으로 교차하며(자전축과 평행) 완화하는 관계」
- **파(破)** = **재정리·재정의(Reverse).** 「[길 ↔ 흉]으로 서로 변하는 현상 / 원래 계산된 것에 대한 수정과 조정」. 육파살이라고도 함.
- **원진** = 怨嗔, 원망할 원(怨) 성낼 진(嗔).
- **귀문관살** = 鬼門關. 「긍정적 의미: 귀신의 힘으로 통찰을! / 부정적 의미: 귀신이 문으로 들어와 빗장을 잠근다!」
- **공망** = 빌 공(空) 망할 망(亡), 「천중살(天中煞)」. 「천간의 기운을 받지 못함 / 10개의 천간과 12개의 지지가 서로 짝을 못 이뤄 생기는 부조화」
- **관재구설(官災口舌)** = 「관성이 지나치게 왕성하여 일간을 짓누를 때, 일간이 더 이상 버틸 수 없는 상황」
- **부성입묘(夫星入墓)** = 「여자 사주에서 관성(官星)이 묘궁(墓宮)에 들어 있다는 뜻」

### 2-5. 십이운성 12단계의 «단계 이름 뜻» (강도값은 조견표로 갔다)
장생=태어남 / 목욕=활동과 성장 / 관대=발색(發色) / 건록=자아 실현 / 제왕=삶의 주인 / 쇠=마무리 / 병=쇠약 / 사=죽음 앞둚 / 묘=죽음 / 절=돌아감 / 태=잉태 / 양=존재의 인정.
연령 구획(부분만 표기): 장생=유년기 · 관대=청년기 · 건록=장년기 · 쇠=말년기.

### 2-6. 사길신 / 사흉신 (판본 병기)
- 사길신 = **재관인식(財官印食)** — 재(정재+편재)·관(정관)·인(정인)·식(식신)
- 사흉신 = **살상겁인(殺傷劫刃)** 또는 **살상겁효(殺傷劫梟)** — 「술사에 따라 다름」. 살상겁인은 [양인] 포함, 살상겁효는 [편인] 포함.
- ⚠보드가 스스로 단 경계 문장: **「길신이라 해서 좋은 것만이 아니며, 흉신이라 해서 나쁜 것만이 아님. 사주팔자에 따라 길신이 격(格)을 파괴할 수 있고, 흉신이 격(格)을 이룰 수 있음.」**

### 2-7. 지지의 체(體)/용(用) 구분
보드가 지지 표에 **「체(본질:천간음양)」과 「용(쓰임:지지음양)」 두 행을 나란히** 두었다.
→ 운영자 260722 확정 「사해오자 = 체용 구분 채택」의 **보드 근거**다. 대격자(3371~)에도 「(체−)」·「(체+)」 표기가 칸마다 붙어 있고, 표 머리에 **「음영된 부분은 일지에 위치할 수 없음(‘체’ 기준, 일간과 일지의 음양이 같아야함)」**이라는 판정 단서가 있다.
⚠단 **어느 지지가 체로 무엇이고 용으로 무엇인지의 12칸 대응은 (y,x) 덤프에서 재조립이 불가능**했다(음/양 문자열 24개가 라벨 없이 나열돼 있다). 대격자의 「(체±)」 표기로 역산은 가능하나 이번엔 하지 않았다.

### 2-8. 황도·자전축 (보드가 스스로 적은 천문 배경)
- 「황도 = 지구의 태양 공전 운동을 태양의 관점이 아닌 **지구의 관점**에서 나타낸 것 … 지구의 관점에서 생각한 **오만한** 경로」
- 「황도에서, 지구가 기울어진 쪽을 북반구로 설정하면 태양의 고도가 높을 때 > 북반구 > 여름 / 낮을 때 > 겨울 (실제로는 태양의 고도가 높고 낮은 게 아니라, 지구의 공전 방향이 다른 것임)」

### 2-9. 통변 자세 (보드 첫 줄)
- 「수덕(修德)하면, 난지자(難知者) 수(壽)라 — 도계 박재완. 덕을 쌓는 자세로 살아가고, 나에게 불리한 시기를 아는 사람이 진정 부귀장수 할 수 있다.」
- 「재물을 잃으면 조금 잃은 것이고, 명예를 잃으면 많이 잃은 것이고, 건강을 잃으면 모든 것을 잃은 것이다.」
