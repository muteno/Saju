# 경계의 폭 — 축자 근거집

운영자 1-41 «경계는 선이 아니라 구간이다»를 코퍼스로 받치기 위한 축자 모음.
**결론을 저장하지 않는다. 원문 조각과 para_id만 남긴다.**

출처종 표기: `순수웹` = HM- PL- SG- MT- DR- (웹 교재 원문) / `웹적재전사` = DT- CT- ST- CHO- (유튜브 자동전사가 «웹» 칸에 적재된 것).
※ 자동전사는 오탈자가 있다(휘신=희신, 귀신=기신, 조우=조후, 심강=신강, 대혼=대운, 청간=천간 등). 축자는 원문 그대로 옮기고 괄호로 교정만 붙였다.

## A. 강약(신강/신약) — 경계가 딱 떨어지지 않는다

### A-1. 강약은 2분법이 아니라 8단계 스펙트럼이다 ★
- `CT-P077-03` · 웹:초코서당 · 웹적재전사 · 「신강 신약이 살아가는 법(Live 편집본)」
> 심강(신강)한 사주 그리고 신약한 사주 / 실은 사주가 이 두 개만 있는 건 아니죠 / **엄청나게 많은 스펙트럼이 있습니다** / 극신약한 사주가 있죠 / 그리고 신약한 사주가 있고 / **중화신약**한 사주가 있고요 / 중화사주가 있고 / **중화신강**한 사주가 있고 / 그냥신강한 사주 / 그리고 극신강한 사주 / 전항(전왕)사주 / 이렇게 제가 스펙트럼을 굳이 / 일간의 힘의 강약에 따라서 단계별로 나누면 / 하나 둘 셋 넷 다섯 여섯 일곱 여덟 / **여덟 개로 나오네요**

→ 1-41의 «무지개 7개 색»에 대응하는 웹 축자. 이분법을 명시적으로 거부하고 8단계를 놓는다. «중화신약»·«중화신강»이라는 **겹치는 구간 이름**이 실제로 있다.

### A-2. 0~100점 척도에서 50점 근처는 판정 불능 ★
- `CT-P039-16` · 웹:초코서당 · 웹적재전사 · 「내 사주 용신 확인법!」
> 만약에 어떤 극신약한 사주가 있습니다. / **얘는 제가 0점이라고 해볼게요.** 그 신강하고 신약한 정도가요. / **극신강한 사주는 반대로 100점**이 되겠죠. / 그런데 어떤 사주를 보니까 **딱 50점**인 거예요. / **이러면 억부용신을 잡기가 정말 힘들어집니다.** … 자 이런 사주가 완전히 50점짜리 사주입니다 / 이런 사주를 딱 만나면 이게 심각한지 심각한지(신강한지 신약한지) 잘 모르겠어요

### A-3. 점수 자체를 믿지 말라 (철공소 만세력 점수 언급)
- `CT-P064-09` · 웹:초코서당 · 웹적재전사 · 「알파고는 사주 상담을 할 수 있을까요?」
> 저는 중화라고 써 있잖아요 중화가 아니고 좀 신강한 사주인 겁니다 / 그래서 **이 점수만 가지고는 판별하기 좀 어려운 게 있어요** … **그래서 이 점수를 너무 믿으시면 안되지만** 어느정도 청구(참고)는 될 수 있을 것 같아서 이 만세력을 보여드립니다

→ 기확보한 «철공소 점수제»를 만든 쪽이 아니라 쓰는 쪽에서 남긴 신뢰도 하한 진술.

### A-4. 중화사주는 신강/신약 구분이 «모호»하다 (2회 반복)
- `CT-P021-17` · 웹:초코서당 · 웹적재전사 · 「사주를 풀이하는 일반적인 순서와 방법」
> 이게 좀 쉬운 것 같아도 **중화사주들은요 그 신강하고 신약의 구분이 좀 모호해요** / 그러면 대세운의 유불리를 파악하는 게 어렵습니다 / 반대로 신강한 분, 신약한 분들은 대세운에 따른 유불리가 정말 확실하게 드러나요.
- `CT-P024-24` · 웹:초코서당 · 웹적재전사 · 「사주의 핵심은 대운이다」
> 사실 저도 사주를 보잖아요 / 한 15개 중에서 / **한두 개 정도는 헷갈려요** / 특히 중화사주분들 / **중화사주는 신강하고 신약의 구분이 되게 모호하거든요** … 제가 확실치가 않으면 상담비를 안 받아요 … **근데 모르면 모른다고 하는 게 맞다고 봐요**

→ «모르면 모른다»가 웹 저자 입에서 나온다. 1-41의 «정의 못해»와 직접 겹친다.

### A-5. 애매한 사주가 «되게 많다»
- `CT-P083-06` · 웹:초코서당 · 웹적재전사 · 「내 사주 신강 신약 여부 5초만에 알아내기」
> **애매한 사주들 되게 많아요** … 그런데 이거는 과연 극신강한 사주일까? 일간이 자기의 주체성을 담보할 수 있을까에 대해서 **저는 약간의 의문이 있습니다**

### A-6. 강약 판정 요소의 가중치 자체가 구간이다 ★
- `MT-BASIC-P052-01` · 웹:명리학탐구 · 순수웹 · 「052.사주명리의 기초(2)」
> 사주팔자의 8글자의 각 글자의 힘의 크기가 1이라고 볼때, 모친궁인 **월지는 2-4배의 힘**을 갖는다고 **보기도 합니다.**

→ 기확보한 점수제들(도화도레 월지30/110, 플러스 월지30/100, 명리학탐구 월지25/100, 철공소 월지25)의 «월지 가중치»가 웹 원문에서는 **단일값이 아니라 2~4배 구간**으로 적혀 있다. 점수제들의 수치가 서로 갈리는 이유가 여기서 설명된다.

### A-7. 중화사주는 정의상 «존재하지 않는다»
- `CT-P077-04` · 웹:초코서당 · 웹적재전사
> 엄밀하게 말해서 / **중화사주란 없다** / 중화사주란 없습니다 / 왜냐면요 / 중화사주의 조건이 되게 까다롭기 때문이에요
- `CT-P174-04` · 웹:초코서당 · 웹적재전사 · 「사주팔자는 아무런 잘못이 없다」
> **모든 사람은 사주가 치우쳐져 있을 수밖에 없어요** / 왜냐하면 사주 팔자는 말 그대로 8개인데 음향(음양)과 오행은 10개잖아요 / 균형이 안 맞죠 두 개가 부족하니까 / 그래서 모든 사람은 중화사주가 있을 수가 없고요 / 엄밀한 의미에서 **어느 정도 치우쳐져 있습니다**

→ «중화 = 50점»이라는 중간점이 실체가 아니라 극한값이라는 진술. 경계선이 실물이 아니라는 취지.

## B. 시각·시진 경계 — 폭이 실제로 존재한다

### B-1. 시주 경계는 보정 없이는 정할 수 없다 (사공) ★
- `SG-COMMON-P002-02` · 웹:사공 · 순수웹 · 「대한민국 광역시, 시/군 균시차 보정 (수정본)」
> **시주(時柱)가 바뀌는 경계에 해당하는 태어난 시각(예: 11시 30분 출생)의 경우**, 태어난 지역에 따른 균시차를 보정하면 더욱 정확한 시간을 산출할 수 있습니다. / [예시] 11시 33분 부산 출생 / 부산은 오(午)시가 11시 30분에 균시차 +6분을 보정하여 **11시 36분에 오(午)시로 바뀜** / 보정 전: 오(午)시 / 보정 후: 사(巳)시

→ 같은 시각·같은 날에 태어나도 **지역에 따라 시지가 달라진다**. 시진 경계선이 전국 공통 상수가 아니라 −11분 ~ +14분의 지역 분포를 갖는 값이다(표: `SG-COMMON-P002-03`).

### B-2. 보정 미적용 시 오차 폭 최대 1시간 45분 ★
- `CHO-STORY-P007-10` · 웹:초코서당 · 웹적재전사 · 「야자시/조자시에 대한 모든 것 (1)」
> 지역별 시차는 최대 약 30분 정도, 썸머타임은 1시간, 균시차는 16분 정도 오차가 날 수 있습니다. / 즉, 이러한 부분들을 제대로 반영하지 않는다면, **실제 태어난 시간이 최대 1시간 45분이나 차이가 날 수 있는 겁니다.** … 어이없게도 실제 태어난 시간은 자정 00시 25분이 아니라 **밤 10시 40분이 될 수도 있습니다.**

### B-3. 경계시 출생자는 두 가지 사주를 «동시에» 놓고 본다 ★★
- `CHO-STORY-P007-12` · 웹:초코서당 · 웹적재전사
> 저의 경우, / **자시의 경계시에 태어난 내담자와 상담을 할 때, 시간에 대한 보정치를 적용했음에도 불구하고 / 1) 자시(子時) / 2) 해시(亥時) / 두 가지로 시간을 놓고 사주를 세우는 경우가 있습니다.**

→ 1-41의 «범위를 겹쳐놓으면 돼»의 실물 사례. 한 사람에게 두 개의 명식을 겹쳐 놓는 실무.

### B-4. 시진 경계 논란의 원인이 보정 누락이라는 진단
- `CT-P125-12` · 웹:초코서당 · 웹적재전사 · 「야자시 가지고 그만 싸웁시다」
> 내담자가 자기 태어난 시간을 제대로 모를 수도 있고 / 지역보정을 안 했을 수도 있고 / 그리고 썸머타임 적용을 안 했을 수도 있으니까 / 그런데 / 균시차를 꼭 적용해야 한다
- `CT-P125-14` · 웹:초코서당 · 웹적재전사
> 균시차가 제가 제일 많이 차이가 나면 / 16분 차이 난다 했죠 / 부산 같은 경우 이게 6분을 더 해줘야 되고 … 인천이면 마이너스 3분 해줘야 되거든요 / 그러면 가장 차이가 많이 날 때 / **마이너스 19분 차이가 날 수 있죠** … 밤 11시 50분에 태어났다 / 이런 경우도 정말 정말 드물지만 / **전날 해시로 봐야 되는 경우도 있을 거예요**

### B-5. 시진 채택 여부 자체가 유연하다는 주장의 존재
- `CT-P125-12` · 웹:초코서당 · 웹적재전사
> 내담자에 따라 / **야자시 조자시를 유연하게 적용해야 하는 경우도 있다**고 주장하는 분도 있을 거예요 / 근데 전 이것도 / 틀린 말은 아니라고 보는데

### B-6. ★ 반대 판본 — «경계는 선이다»라고 명시하는 웹 저자
- `HM-P265-01` · 웹:현묘 · 순수웹 · 「지지의 비밀 (시간의 분절)」
> 우리의 상식을 비웃듯, / **시간은 흘러가지 않고, 정확하게 분절되어 있습니다.** / **우주에 곡선, 애매한 선은 존재하지 않습니다.** / **우주는 아날로그가 아니라 디지털입니다.** / 사주적으로 새해는 흘러가듯 도래하는 것이 아니라, / **정확하게 입춘 절입 시점을 기점으로 나뉩니다.**

→ **1-41과 정면으로 어긋난다. 병기 필수.** 웹 안에서 «구간파(초코서당·도화로운·도화도레·사공)»와 «분절파(현묘)»가 갈린다. 갈림 자체가 값진 수확이다.

## C. 대운·세운 — 언제부터 작용하는가

### C-1. 대운은 1년 전부터 바뀌는 «경향성» (기확보)
- `DR-P027-09` · 웹:도화로운 · 순수웹
> 대운이 바뀌는 시점에 놓여있고, / **대운은 1년전부터 바뀌는 경향성이 존재하는데요.** / (예: 2023년에 대운 바뀜 -> 2022년 하반기부터 변화 시작)

### C-2. ★ 폭이 «1년~2년»의 구간으로 적힌 신규 축자
- `DT-P127-13` · 웹:도화도레 · 웹적재전사
> 저는 개인적으로 내가 대운이 언제 바뀌는지를 알고 / **내가 대운이 바뀌는 1년 전부터 2년 전부터는** / 좀 조심하면 좋다라고 말씀을 드렸어요.

### C-3. 오행운도 1~2년 선행 구간을 갖는다
- `DR-P318-08` · 웹:도화로운 · 순수웹
> 토 오행을 잘 활용하고 싶은 분들은 / 지금은 관심이 없더라도, **운이 들어오기 1~2년 전부터** / 미리 부동산 공부를 해주시면 좋습니다.
- `DR-P318-10` · 웹:도화로운 · 순수웹
> Tip 2) 토 기운이 들어오기 전에 파이프라인 구축 … **토 운이 들어오기 1~2년 전부터** / 파이프라인을 마련하는 것이 좋습니다.

### C-4. 교운기는 «연말과 연초»에 걸친 구간
- `DR-P320-05` · 웹:도화로운 · 순수웹 · 「2024년 신년운세ㅣ교운기」
> 교운기란, 운이 바뀌는 시기를 뜻하며 **보통은 연말과 연초를 의미합니다.** / 교운기는 운이 들어가고 나갈때, / 즉 **2023년 하반기와 2024년 상반기에** / 운이 바뀌는 시기를 뜻합니다.

→ «12월 31일에 끊기는 게 아니다»(1-41)와 정확히 같은 취지. 다만 **정량 폭은 «하반기~상반기»라는 반년 단위 서술뿐**이고, 「대운 2~3년 전 / 세운 2~3달 전」이라는 정확한 수치 문구는 **코퍼스 웹·전사 어디에도 없다**(전수 검색 결과).

### C-5. 운의 전환은 시점이 아니라 «서서히»
- `CT-P081-03` · 웹:초코서당 · 웹적재전사 · 「삼재 초간단 해결법」
> 수술을 한 날, 다음 날부터 대운이 바뀐다고 보기보다는 / **그날을 기점으로 점점 서서히 바뀌지 않을까 저는 그렇게 생각을 합니다.** … **저는 서서히 바뀔 거라고 생각을 해요** / 수술한 시점을 기준으로

### C-6. ★ 반대 판본 — 대운은 «들어오는 것»이 아니다
- `HM-P273-02` · 웹:현묘 · 순수웹 · 「현묘의 묘운력 (2) 대운은 들어오지 않는다.」
> "내년부터 대운이 들어온다~~~~" … 대운이 어디서 들어옵니까? / 밖에서 주어지는 겁니까? … 아니죠. / **대운은 내 것입니다.** … **들어오는 게 아니에요. 원래 내 거예요.**

→ «언제부터 작용하는가»라는 질문틀 자체를 기각하는 판본. C-1~C-5와 병기.

## D. 궁·시기 배정 — 나이 경계도 폭이다

- `MT-BASIC-P052-01` · 웹:명리학탐구 · 순수웹

- `DR-P005-02` · 웹:도화로운 · 순수웹
