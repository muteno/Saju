## ② 함지살 — 훑은 문단 9 (광역 채굴 14)

### ②-1 조견표 ✅ **함지살 성립 조건** (적기 구역)

`SG-SINSAL-P012-10` (사공, 도화 1부) — 축자:
> *「삼명통회에 따르면 함지살의 경우 도화살(년살)보다 **조건이 더 까다로운데 일지 도화가 있는 주(柱)에
> 삼합국의 오행이 도화가 있는 주(柱)의 납음오행과 같아야 함지살이 성립**됩니다.」*

같은 문단에 **작동 예시**까지 있다(축자):
```
◎ 乙 ◎ ◎
◎ 酉 ◎ 子
◎ 水 ◎ ◎
→ 년지 자수 기준, 일지 유금 도화살 성립
→ 을유의 납음오행이 수(水) 함지살 성립
```
⚠**전제 노드가 필요하다** — 이 조건은 **납음오행**을 입력으로 쓴다. 지도에 `납음(오행)` 노드가 없다
(현묘 위원이 B9로 이미 올린 후보 · 전 코퍼스 48문단). **납음 없이는 함지살 조견표가 계산 불가**다.

### ②-2 관계 (이명이지 별칭이 아니다)
`SG-SINSAL-P012-04` 축자: *「**연해자평과 삼명통회에서는 도화살을 함지살(咸池殺)이라고 합니다.** 다른 고전에서는 목욕(沐浴), 패신(敗神), 패욕살(敗浴殺), 나형(裸形)도 같은 말로 혼용」*
그런데 **같은 저자가 바로 아래에서 조건을 갈라 놓는다**(②-1) — 즉 **고전에서는 이명이고 삼명통회 엄밀 기준으로는 하위 개념**이다.
`SG-SINSAL-P012-03`이 도화 계열 전체를 위계로 정리한 축자:
```
왕지(도화, 가도화) / 도화살(12신살 년살, 함지살, 진도화) / 목욕(패욕살, 패신, 나형, 나체도화)
/ 홍염살 / 월공 / 천간 도화(壬壬, 癸癸)
```
→ 담을 것은 **`함지살 ─관계(이명·조건강화)→ 도화살`** 이지 별칭 병합이 아니다.
저자 stance도 있다: *「현대에는 함지살을 엄격하게 적용하지 않습니다. 따라서 함지살도 도화살, 년살과 동일하게 보시면 됩니다」* → **stance 병기**(정본 승격 금지).

⛔**처분(이사/병기)은 운영자 승인 사안**이라 손대지 않았다. **근거만 올린다.**

### ④-3 ⛔별칭 금지 — 「제살」을 수옥살에 붙이면 안 된다

## I. 못 한 것 / 안 한 것 (정직하게)

1. **길흉·발현 서술은 캐지 않았다.** 조견표(입력→글자)까지가 «적기» 구역이라는 지시대로 했다.
   분량으로는 이 13노드 문단의 절반 이상이 「이 살 있으면 이렇게 산다」다.
2. **⑬ 월률분야 297문단 중 사령·당령 축만 훑었다.** 「지장간 자체」의 297문단 전수는 안 봤다
   (`여기·중기·정기` 노드가 이미 받는 구간이라 중복이라고 판단했다 — **확인은 못 했다**).
