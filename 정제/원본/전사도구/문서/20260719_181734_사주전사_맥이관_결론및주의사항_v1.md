## 2. 놓치면 안 되는 것 (중요도 순)

### ⛔ ① 엔진을 그대로 돌리면 기존 데이터가 깨진다 — 최우선

지시문 §B 엔진과 지금 폴더는 **파일명 규칙이 다르다.**

| | 형식 |
|---|---|
| 현재 폴더 | `20240421_제목_영상ID.md` |
| 엔진이 만드는 것 | `001 - 제목 [영상ID].md` |

엔진은 재개할 때 대괄호 `[영상ID]`만 찾는다. 실측 결과
**기존 259개 중 엔진이 건너뛸 수 있는 파일 = 0개.**

그대로 돌리면 이렇게 된다:
1. 이미 끝낸 **113개를 처음부터 다시** 전사 (수십 시간 낭비)
2. 이름이 다른 **중복 파일**이 폴더에 뒤섞임
3. `index.md` · `index_categorized.md` · `dashboard.html` · `categories.tsv`가
   가리키는 파일명이 전부 어긋나 링크가 깨짐

**→ 반드시 엔진을 폴더 규칙(파일명 + 헤더 형식 + 재개 인식)에 맞춘 뒤 실행할 것.**

### ⛔ ② 홍염 프리미엄 53개는 지금 계정으로 불가능하다

원드라이브의 `youtube_cookies.txt`로 직접 접속 테스트한 결과:

```
ERROR: This video is available to this channel's members
       on level: 홍염🌺 : 멤버십 전용 프리미엄 사주 콘텐츠
```

쿠키 자체는 살아 있지만 **그 등급 멤버십에 가입돼 있지 않다.**
기계 성능·설정 문제가 아니라 **권한 문제**라, 맥이든 윈도우든 못 받는다.
필요하면 홍염 등급을 결제한 계정으로 쿠키를 다시 뽑아야 한다.

### ⚠️ ③ 복제팩 문서의 "1080 = 4.8배속"은 실제보다 부풀려져 있다

`whisper유튜브채널전사_복제팩_v1.md` §6-b에 적힌 4.8배속은 실제와 다르다.
어제 진짜 돌린 기록을 역산하면 **3.36배속**이다.

이 문서 숫자를 믿고 비교하면 "윈도우가 더 빠르다"는 반대 결론이 나온다.
**앞으로 기계 비교는 문서값이 아니라 실측으로 할 것.**

### ⚠️ ④ 짧은 영상으로 속도를 재면 안 된다

같은 맥·같은 엔진인데 측정값이 2배 차이 났다.

| 측정 대상 | 결과 |
|---|---|
| 2.7분 영상 | 2.88배속 ❌ |
| **14.1분 영상** | **5.52배속** ✅ |

짧은 영상은 모델 로딩·워밍업 같은 **고정 비용이 시간의 절반**을 먹는다.
이 채널 평균 길이는 33분이므로 **10분 이상 영상으로 재야 실제 값**이 나온다.
(실제로 이것 때문에 "1080이 더 빠르다"고 한 번 잘못 판단했다.)

### ⚠️ ⑤ turbo 모델은 쓰지 말 것 — 빠르지만 고유명사가 깨진다

`large-v3-turbo`는 **30배속(1.7시간)**으로 5배 이상 빠르다. 하지만 같은 영상 첫 3줄에서 이미:

| large-v3 (정본) | turbo |
|---|---|
| 조국혁신당 | **초**국혁신당 ❌ |
| 범야권 | **법략권** ❌ |

사람 이름·정당명·사주 전문용어가 핵심인 채널이라 이 오류는 치명적이다.
**게다가 이미 끝낸 113개가 large-v3로 만들어져서, 섞으면 품질이 들쭉날쭉해진다.**
→ large-v3 유지가 맞다. (급할 때만 검토, 지금은 아님)

### ⚠️ ⑥ 맥이 자면 작업이 멈춘다

9시간짜리 작업이라 도중에 맥이 절전되면 중단된다.
반드시 `caffeinate`로 묶어서 실행할 것. (중단돼도 재실행하면 이어가긴 한다)

### ⚠️ ⑦ 쿠키 파일은 원드라이브에 두면 안 된다

`youtube_cookies.txt`는 **유튜브 로그인 실물**이다. 지금 회사 원드라이브
(`OneDrive-GS칼텍스예울마루`)에 있어서 동기화·공유 대상이 된다.
복제팩 §8-a도 명시적으로 금지하고 있다. 로컬로 옮기는 걸 권장.

## 4. 맥 환경 — 어떻게 구축했나 (재현용)

이 맥에는 brew·ffmpeg·node·yt-dlp가 전혀 없었고, 시스템 파이썬도 3.9.6(구버전)이었다.
**brew 설치는 관리자 암호를 요구**하므로 우회했다. 관리자 권한 0회로 구축 완료.

| 문제 | 해결 |
|---|---|
| Python 3.9.6 (너무 낮음) | `uv`로 Python 3.12 독립 설치 (`~/.local`, 암호 불필요) |
| ffmpeg 없음 (mlx-whisper 필수) | `imageio-ffmpeg` 파이썬 패키지의 번들 ffmpeg 7.1(arm64)을 venv에 연결 |
| brew 없음 | 아예 안 씀 |

- 설치 위치: `~/.claude/skills/whisper/`
- 실행 래퍼: `~/.claude/skills/whisper/run.sh` — **반드시 이걸로 실행**해야 ffmpeg를 찾는다
  (`python`을 직접 부르면 ffmpeg를 못 찾아 실패)
- 모델: `mlx-community/whisper-large-v3-mlx` (2.9GB, fp16 정식본 — 양자화 아님, 품질 손실 없음)
- Metal GPU 실측 6.2 TFLOP/s 정상 동작 확인

> **Node.js는 설치 안 했다.** 멤버십 영상 전용인데 ②번 이유로 어차피 못 받으므로 불필요.
