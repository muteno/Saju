# 유튜브 계정 쿠키 — 넣는 법

멤버십(유료) 영상을 받으려면 **그 채널에 가입한 계정의 쿠키**가 필요하다.

## ⚠️ 쿠키 파일은 이 폴더(클라우드)에 두지 마세요
쿠키는 비밀번호 없이도 **구글 계정 전체(Gmail·드라이브·유튜브)를 여는 열쇠**다.
회사 OneDrive에 두면 동기화·백업을 통해 남에게 노출될 수 있다.
→ 실제 파일은 **맥 안의 로컬 금고**에만 둔다:

```
~/.whisper_cookies/            ← 여기가 금고 (외부 동기화 안 됨)
   ems1130g.txt                ← 계정별로 파일 하나
   회사계정.txt
```

## 넣는 순서
1. 크롬에 확장 **"Get cookies.txt LOCALLY"** 설치
2. 그 계정으로 youtube.com 로그인 상태에서 → 확장 아이콘 → **Export**
3. 받은 파일을 금고로 옮기기 (터미널):
   ```bash
   mkdir -p ~/.whisper_cookies
   mv ~/Downloads/*cookies*.txt ~/.whisper_cookies/계정이름.txt
   ```
4. 전사 실행기에서 **[3] 멤버십 포함 시도** 선택

## 쿠키가 죽는 경우 (실측 경험)
- **2스트림이 같은 쿠키를 동시에 쓰면 유튜브가 세션을 끊는다** → 멤버십 작업은 1스트림 고정으로 해결함
- 시간이 지나거나 다른 기기에서 로그아웃하면 만료 → 그럴 땐 위 순서로 **새로 뽑으면 됨**
- 공개 영상만 받을 땐 쿠키를 아예 안 쓴다(`--no-cookies`) → 쿠키가 헛되이 소모되지 않음
