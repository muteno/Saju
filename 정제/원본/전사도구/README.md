# 전사 프로그램 — 이 폴더 안내

> 유튜브 채널을 **로컬 Whisper large-v3**로 전사하는 도구 일습. 맥(M5) 전용.
> **실제로 도는 원본은 `~/.claude/skills/whisper/` 에 있고, 여기는 보관·인계용 사본**이다.
> (여기 파일을 고쳐도 실행에는 반영 안 됨 — 고치려면 원본을 고치고 여기로 복사)

## 쓰는 법 (이것만 알면 됨)
- **방법 A (웹, 추천):** 브라우저 **http://localhost:8765** → "새 전사 작업"에 링크 붙여넣기
  → `① 채널 확인` → `② 시작`. 기계(맥/윈도우) 선택 가능 — 윈도우를 고르면 실행 대신
  1스트림 규칙이 박힌 지시서 파일을 문서/ 폴더에 만들어 준다(윈도우 PC로 가져가서 쓰는 용도).
  다른 전사가 돌고 있으면 자동으로 잠긴다(동시 실행 사고 방지).
- **방법 B:** 바탕화면 **`유튜브채널전사.command` 더블클릭** → 링크 붙여넣기 → `[1] 3개 시험` 또는 `[2] 전체 시작`
- 진행 확인: 브라우저 **http://localhost:8765** · 맥 뚜껑 열어두기(또는 외장 모니터 연결 유지) · 전원 연결
- 멤버십(쿠키) 작업은 무조건 1스트림 — 그리고 쿠키는 **시크릿 창에서 로그인→내보내기→창 닫기**로 만든 것만 오래 산다.

## 폴더 구성
| 폴더 | 내용 |
|---|---|
| `엔진/` | 실제 전사 코드. `whisper_channel_generic.py`(범용·표준) · `whisper_saju_mac.py`(사주 전용) · `normalize_text.py`(인코딩 통일) · `board_server.py`(진행보드) |
| `실행기/` | `유튜브채널전사.command`(더블클릭) · `run_job.sh` · `run_hongyeom.sh`(멤버십) · 재시도·보드 스크립트 |
| `문서/` | **전체인계서**(가장 중요) · 결론및주의사항 · 진행현황 |
| `로그/` | 지난 작업 기록 보관 |
| `설정/` | 진행보드 설정(board_config.json) · 홍염 대상 ID 목록 |

## 핵심 규칙 (피 흘려 얻은 것)
- **재개**: 중단돼도 같은 명령 다시 = 안 끝난 것만 이어감 (완료 판정 = 파일 머리말의 `Whisper` 표기)
- **2스트림**이 최적 (3개는 메모리 초과로 오히려 느려짐) — 단 **멤버십 작업은 1스트림**(쿠키 세션 충돌)
- **속도**: 전사만 7.85배속 · 다운로드 포함 실효 5~6배속 (윈도우 1080은 3.36배속)
- **모델은 large-v3 고정** (turbo는 5배 빠르지만 고유명사 파괴 → 기각)
- **끝나면 반드시 품질 스캔**: 같은 줄 4회 이상 반복 = 무음/BGM 구간 오류 → 해당 영상만 재전사
- 파일은 **UTF-8+BOM+CRLF** 규격 (윈도우·안드로이드·iOS 전부 안 깨짐)
- 쿠키(`~/.whisper_cookies.txt`)는 **클라우드에 두지 말 것** — 구글 계정 전체를 여는 열쇠
