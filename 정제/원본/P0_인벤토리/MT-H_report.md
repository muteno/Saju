## 2. 특이 발견 (다음 배치 교훈 포함)

1. **메타줄 포맷이 저자별로 다름 → 스키마 주의.** 사공(sajustudy)은 `작성일 · 분류 · 원문 URL`(URL 있음). 플러스명리학(saju.sajuplus.net)은 `작성일 · 댓글 N · 조회 N`으로 **원문 URL이 없음** → MT-BASIC 전 포스트 `url:""`. 후속 단계는 MT-* 계열에 URL을 기대하지 말 것.
2. **원문 번호 결번(016·076)은 커버리지 구멍이 아니라 원본 그대로.** post_id에 소스 번호를 보존(…P015→P017, P075→P077). 헤더의 "84개 글" 실측 일치.
3. **실명·역사 명식 20개 = P4 역추론 골든 은행 후보(성향→원국).** 사공: 김연아·송혜교·봉준호·설리·박보검·율곡이이·바흐·손예진·제니·송중기·전지현·마르크스·니체·이창호·박나래·유희열·조성진·피카소·유시민·원빈·아이유·스티브잡스·워런버핏·무라카미하루키·빌게이츠·세종대왕·유영철·빌클린턴·제프베이조스·일론머스크·김봉진 등. 플러스명리학: 명태조 주원장·조선 세조·대한항공 조중훈. (`실명명식` flag로 태깅)
4. **stance 축 신호 8개 확보(프로젝트 stance 지도용).** 사공 = 화개 지장간 입묘 **부정**("여러 학파가 주장하는 화개 지장간의 입묘 작용은 일어나지 않습니다"), 신살 사용 여부·종격 회의를 stance:기타로. 플러스명리학 = **정자시 채택 vs 야자시/조자시**(stance:자시인시), 한국 표준시(동경135도) 비판, 종격/특별격 용신 회의(억부 우선). 두 저자 모두 종격이론에 회의적 = 교차 확증.
5. **결정론 논증 21개 = L1 기계검증 후보.** 백호 7종·괴강·양인·파의 1~10 순환·삼합 파생·대운 순역(양남음녀)·월두법/시두법(간합→월/시천간 산출)·순중공망·천월덕 삼합양간 등 60갑자/삼합 기반 결정 규칙.
6. **개운/직업(업상대체)이 두 코퍼스의 공통 실전 축.** 사공 신살론은 신살마다 `직업·개운법`을 체계적으로 제시(kind 개운 15), 플러스명리학은 행운론(색상·음식·취미·후천수) 별도 편. 운영자 철학의 "환경 조언" 초점과 정합.
7. **사공의 상담윤리 게이트 통일 목소리.** "~살 단어 사용 자제", "무조건 좋다 해석 지양", "좋다나쁘다 길흉 단순접근 금지" → `게이트` flag. 플러스명리학도 "사주 보는 것은 좋고 나쁨을 아는 게 아니라 대책 강구"라는 게이트 문장 포함.
8. **명식 표기 이질성:** 사공은 도식형 명식(◎ 자리표시 + 한자), 플러스명리학은 익명 간지 4자 나열형(예 `을기병기 / 해사인해`). 둘 다 가상/실명 명식 풀이(kind 사례)로 P2 케이스 재료 가치 높음. 특히 MT-BASIC 043~050·077~086은 궁성·용희신·대운까지 이어지는 완결형 원국해석 = 케이스 은행.
9. **MT-BASIC은 완결 커리큘럼 아크.** 001 연재선언 → 002~035 기초이론(음양오행·천간지지·합충형·십신) → 037~042 기세판단 → 040·072~075 용신 → 055 십이운성 → 056~063 신살/길신 → 064~068 조후 → 069~071 일간/띠 → 077~086 실전 사주풀이+종합풀이(capstone). W1 커리큘럼 스파인 도출에 참조 가치.
10. **교차 확증 지점:** 두 파일 모두 신살(백호·양인·괴강·공망·도화·역마·화개·천을·천덕·월덕·문창·학당)을 다룸 — 사공은 신살당 1편 심화, 플러스명리학은 1편에 다수 요약. 동일 신살의 정의·조견표 대조 가능(단, 플러스명리학이 사공보다 흉의 위주 서술 경향).
