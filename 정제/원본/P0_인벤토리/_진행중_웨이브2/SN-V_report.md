### ③ 용신 추출·대세운 해석 절차 — ★이 배치 최대 수확
저자는 '용신'이라는 말을 쓰지 않고 **"약(藥)으로 쓴다"**로 운용한다. 그런데 **처방 우선순위표와 판정 절차가 통째로 노출**된다.
- **수다(水多) 처방 우선순위(1094)**: **갑목 1순위(부작용 없음) > 무토 제방(반드시 화 동반, 홀로면 역효과) > 병화(서서히 말림) > 정화(무토에 힘 실어 제방) > 을목(차선)**. **일간별 예외**: 무기토일간은 갑목 **금지**(수생목→목극토), 병정화일간은 갑목 **무조건 1순위**.
- **ST-P1084**(1084 L124·139): `기토 같은 경우에는 약한 경금하고 신금을 모두 다 보호하고요` / 무토는 경금만(신금은 깨짐) / 과열이면 `수라는 오행도 필요합니다`.
- **ST-P1088**(1088 L226–228): 물이 병화를 막는 명식에 `약으로 쓸 수 있는게 뭐가 있냔 말이죠. 맞습니다. 바로 감목입니다` = 통관·설기 처방의 실물.
- **판단 유닛 원형 3건** — 조건→연결(chain)→결론이 말로 다 나온다:
  1. **1072「운이 흘러가는 방식」= 운 해석 결정론 모델.** 지장간 중기 **계절 역행** → **방합=땅의 질서, 삼합=하늘의 질서**(`삼합이라는 거는 지장간의 중기가 같은 오행들끼리 뭉쳐있는 거로구나`) → **인오술↔신자진 음양 한 쌍 → 사건은 2년 주기로 출렁임** → 천간은 2년마다 상생 → **교운기: 전년 말 + 연초 3~4개월은 앞뒤 세운이 침범**(사람들이 1년·3년으로 착각하는 이유).
  2. **1078「인성운인데 왜 합격을 못하죠?」= 합격운 판정 절차.** 구조(강약) → 유통(식상생재/관인상생) → **자리**(연월=간판·큰 조직 / 시주=친한 사람). **진짜 인성 합격운의 조건은 연월 지장간 통근 또는 관인상생뿐**(L109–116).
  3. **1079「동업을 하고싶어하는 사주」= 동업 판정 절차.** ①식상 사용 ②일간 힘 ③비겁 **위치**(월주=선배·조직/시주=아랫사람) ④겁재가 재성 흐름을 막는가 ⑤**비겁다자+재성 고립 = 절대 금지** ⑥시주 관 과다 = 규모 확장 금지·사업체 분리 ⑦일지–시지 충·격각 = 부하 스트레스.
- **대세운 절차 완성형 3종(1103–1110 구간)**:

  - **1108 = 충 해석 알고리즘**: 충 확장 판정 → 자리별 영역(연월=공적) → 규모 판정(원국·대운 보유 여부) → **시점 특정**(천간 임수 올라오는 4월 임진월).
  - **1105 = 절기 전환(대한) 판독**: 축중 신금 + 사축합 → 원국 지지군별 분기.

- **ST-P1101**(1101 L199–224): 동업 갈등 상담 실황 — 명식으로 취향 추정 → 처방(커플 방석) → 며칠 뒤 결과 회신까지 **완결형 사례**.

## §3 특이 발견
1. **1072가 배치 최대어.** 운이 흐르는 방식을 저자가 통째로 공개 — 지장간 중기 역행 → 삼합=하늘 질서 → 인오술↔신자진 음양쌍 → **2년 주기 사이클** → 천간 2년 상생 → 교운기 3~4개월 침범. 근거가 지장간 구조라 저자 관법과 자기정합적이고, **L2 운 해석 엔진에 그대로 넣을 수 있는 결정론 모델**이다.
2. **1078·1079가 '판단 유닛'의 완성형 원형.** 증류공백진단이 지목한 "이론과 해석 사이의 빈 칸"이 이 두 편에 통으로 있다 → **P2 판단 유닛 시범 제작 1순위 추천.**
3. **1094+1095+1099 3부작**(수다 진단 → 갑목 끌어오기 → 병화 끌어오기)은 2·3편이 **1편 댓글 질문의 답**이라 명시된다. 코퍼스 안에 "이론 → 사용자 질문 → 처방 확장" 사이클이 남아 있어 chain 재구성에 유리.
4. **개운법이 오행 물상 사전으로 완비**: 갑목=여성·아동·자연·동물·측은지심·관목 화분·초록·숫자3 / 병화=백화점·카페·미용실·필라테스·방송·패션·남쪽·붉은색·숫자7·신축 / 임수(회피)=유흥가·외진 곳·구축·숫자1. **병화 vs 정화 판별 기준까지**(정화=고급·매니아·소수 예약제). 1074는 오행별 상권 + **오행 숫자(1·6수, 2·7화, 3·8목, 5·0토, 4·9금)** 격자.
5. **날짜 예고 + 판별 조건이 쌍으로 제시된다**(1073·1077·1080·1110). 예: 10/24 병인일은 병임충 보유자에게, 10/25 정묘일은 정계충·정화 통근자에게 더 크게 온다 → **프로브 은행에 (날짜 · 원국 조건 · 예상 사건) 3연 세트**로 뽑을 수 있다.
6. **1081 = 궁합 계산 로직 직결 재료**: ①상대 글자는 내 십성으로 작용(`정화는 정화일 뿐입니다. 정화라는 에너지는 변함이 없다`) ②상대가 내 좋은 기운을 극하면 차단(연간 무토 → **출생연도 끝자리 8**) ③**상대의 대운도 내가 끌어온다**.

14. **1107이 이론 문서 최고가치** — "천간 우선 인식론": 천간=크게 인식·규모 큼(시간時干이 미래라 가장 크게 느껴짐), 지지=2순위, 지장간=있어도 부정. 여기서 **여명 식상(자식)이 천간이면 자식만 보이고 정관(남편)이 연주 지장간이면 남편이 안 보인다**는 육친 응용까지 전개 — 억부·격국 없이 자리론만으로 통변하는 저자 관법의 골격.
15. **끌어오기 3부작(1103 임수·1104 계수·1106 신금) = 물상→행위 매핑 격자.** ★**경금/신금 판별 기준이 반복 제시**(들어올리면 경금, 기구를 쓰되 들지 않으면 신금 / 타악기=경금·현악기=신금 / 은하수=경금·별=신금 / 자동차=경금·부품=신금) → 물상 유닛의 판별 조건으로 그대로 승격 가능. 양간/음간 총론도 확보(1104 L104 `양간은 조금 더 반경이 넓고 두리뭉실합니다`, 음간은 응집).
16. **게이트 문장 추가 3건**: `물론 명리하게 세계에서는 탁한 물이라고 나쁘고 청한 물이라고 좋다고 판단하지 않습니다`(1104 L80) · `이거는 좋고 나쁨의 문제는 아닙니다`(1107 L188) · **보편 서술의 한계 고백** `명식마다 다를 수밖에 없는데 이거를 최대한 우리 구독자분들이 보편적으로 보시게끔 하려면 어떻게 해야 되나 늘상 고민`(1110 L377–379, L4 헤지 문형 재료).
17. **개인정보(이름·이메일·전화) 해당 문단 0건** — 1109는 저자 본인 가족사라 `개인정보` 플래그 미부여.
