## 3. 작업 방식·재현 정보

- 도구 = `scratchpad\dt2b.py` (`dump idx a b group` = 캡션을 g줄씩 묶어 시작줄 번호와 함께 출력 / `emit idx < table` = `시작줄|kind|subj|gist|quote|flags` 표를 받아 posts·paras JSONL 생성).
  - **emit이 저장 전에 자체 검사**: quote가 해당 문단 줄 범위 안에 공백무시 부분문자열로 존재하는지, gist 40자·quote 120자 초과, 문단 시작줄 1 여부, 범위 역전. 실패 시 저장하지 않고 오류만 출력 → 그래서 최종 282/282가 통과했다.
  - post 메타(title·date·url·video_id·membership)는 **파일 헤더에서 스크립트가 직접 파싱**(재입력 없음 → 오탈자·호환한자 손상 원천 차단).
