1. **★유령 저자(제자 분업 집필) 발견.** 각 글 맨 끝에 `< ○○일주 원고 작성은 "OOO"님께서 도움을 주셨습니다. >` 크레딧이 붙는다. 파일 전체 24건, 내 범위 12건. **일간별로 담당자가 고정**: 갑=소금호수, 을=하늘담, 경=현온, 계=서정. 나머지 6일간(병·정·무·기·신·임)은 크레딧 없음(현묘 직필 또는 무기명). `sub_author`에 반영했다. → 저자 클러스터·교차 확증 독립성 보정에 직결되는 자료.
2. **십신 격자 = L1 결정론 검증 후보 60개.** 일간 10종 × (병화·오화) 십신 배정이 30편 전부에서 완전 일치(갑=식신/상관, 을=상관/식신, 병=비견/겁재, 정=겁재/비견, 무=편인/정인, 기=정인/편인, 경=편관/정관, 신=정관/편관, 임=편재/정재, 계=정재/편재). flags `결정론` 60건. 기계 검증 즉시 가능.
3. **1.병오년의 의미(31줄)는 30편 축자 동일 boilerplate.** 배너 2종도 동일(파일 전체 60회 반복 실측). **P2에서 1회만 증류하고 29회는 중복 계상 금지** — 안 그러면 병오년 총론이 30배 가중된다.
