**1. 환절기 토 정량 규칙 — 질적 확보 / 정량 미확보 (감시 지속).**
453(「토를 어떻게 볼 것인가」)이 산책처럼의 토(土) 관법 전 강의다. 핵심: ①무기토는 계절 없음(중앙에서 순환 중재) ②무토=양양·음음 연결 / 기토=양음·음양 연결 ③**"무기토는 뜨거우면 힘이 강하다"**(12운성으로도 증명 — 무토 사화 건록·오화 제왕) ④**지지 속 무토를 계절 기운으로 배정**: 인중무토=수기운·차갑다 / 진중무토=화기운=오리지널무토 / 사중=목이나 오리지널 / 신중=화기운 / 술중=수기운·차갑다 / 해중=금기운·춥다 ⑤기토: 오중=힘셈, 미중=수기운 불러옴, 축중=화기운 불러옴. **→ 도화도레와 동일하게 조토/습토·계절 기운을 '질적으로' 배정할 뿐 점수화(정량) 규칙은 없음.** 정량 배점은 여전히 미발견.
