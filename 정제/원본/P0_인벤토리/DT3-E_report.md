  - **술토·미토 = 조토(물기 없는 토)**: `이번 달은 술토도 여러분 물기가 없는 토거든요` `미토도 물기가 없다`(DT-P243-07). 조토라 축미·진술충미로 만나면 수(水) 기운까지 손상. 미토는 `가뭄에 완전히 말라` 물·금 증발(DT-P237-23).
  - → **조토(미·술)/습토(진·축) 물상 구분이 생극 판단에 실제로 쓰인다.** 단 "몇 점" 같은 정량 규칙은 이 5편엔 없음. 전사 잔여분 계속 감시.

★**2. 자형(自刑) 사용 확인 — 오오자형(午午自刑).** `55자형이 엄청 강해지는`(DT-P237-27 / DT-P239-12, "5화"=오화·"55자형"=오오자형 오전사). 오화가 원국+운으로 2~3개 겹치면 자형이 강해져 건강(휘병·심혈관)으로 발현. → 운영자 "자형 기본 ON" 결정의 실사용 근거.

★**3. 병존(竝存) = 역마성 판정(도화도레 관법).** `미토도 역마성이 있긴 해요` — 미토 병존이 커지면 인신사해 생지 역마처럼 **①사람이 많아짐 ②지리적 이동/변화** 두 갈래로 발현(DT-P243-11). 병존을 신살(역마)로 해석하는 관법.

★**4. 도화도레 관법 자기 선언(243 인트로).** `제가 가지고 있는 사주 관법, 임상자료, 사주자료들, 자평진전, 저천수 같은 고전을 다 섞어서 말씀드리고 있단 말이죠`(DT-P243-02, 저천수=적천수 오전사). → **도화 관법 = 자평진전+적천수 고전 + 임상 혼합**. 관법 프로파일 자산.

## 코퍼스 구조 발견 (P1/P2 설계 직결)

1. **홍염 프리미엄(237·239·243) = 지지(일지/월지) 격자**, 공개 운세(238·244) = **일간 격자**. 도화 공개=일간 기준 / 멤버십=일지·월지 기준이라는 채널 축 분리가 을미월에도 유지됨.
2. **공개 운세(238·244)의 일간 섹션은 완전 규칙 구조**: 도입 → 운세 문장 1/2/3 → 사주팔자/일주별 팁 → **`도하도르가 ○○일간이라면` 활용법 4가지** → 도화지 뉴스레터 안내(보일러플레이트). 홍염 멤버십·도화지 안내 블록은 매 섹션 축자 반복 → **P1 접기 대상**.
3. **일간 순서가 두 편에서 다름**: 238(갑오월) = 계임신경기무정병을갑(오행 페어 묶음), 244(을미월) = **갑을병정무기경신임계(천간 표준 순서)**. → v2.1 "집필 순서=교육 설계도" 적용 시 편별 실측 순서 사용.
4. **을미월 키워드 = 인본주의/사람 연**: `사람 때문에 웃고 사람 때문에 울 수 있는 그 기질이 더 강해지는 달`(DT-P244-02). 연애·커뮤니케이션·거래처가 주제. 갑을병정 일간에게 "27·28 대비 스피치 연습" 조언.
5. **수(水) 순환 강조**(243 을미월 개요): 오행 개수가 아니라 `수목화 또는 금수목 또는 토금수처럼 이렇게 잘 순환이 되게 중요합니다` — 단순 다과가 아닌 순환 구조로 본다는 방법론(DT-P243-03).
6. **적천수 고전 인용 3건**: 화치승용(火熾乘用, 진토 — 237·239), 간목생화 타버림(甲木生火, 인목 — 237). `적천수`(오전사 "저천수/차주 고서") 플래그.
7. **실명명식 1건**: 237에서 윤석열·이재명·한동훈 정치인 사주 언급(DT-P237-07) — 명식 캡처 아닌 구두 언급.
