## ① 감시 항목 (운영자 즉시 보고 대상)

### 🔴 시간 보정(30분·경도)·서머타임·절입 시각·야자시/자시·대운수 계산·지장간 비율 = **3편 전부 0건**
제목이 "만세력 보기"라 L1 계산 규격이 나올 것으로 기대했으나, 1151의 실제 내용은 **만세력 화면을 읽는 법(자리 명칭 + 궁위 해석)** 뿐이다. 계산층 언급은 아래 절기 대응 하나뿐.
- 저자 본인이 후속 예고: `1151:515` **"만세력에 대한 거는 한 번 더 나올 겁니다"** → **초보자용 강의 후반부(8~20편)에 계산 규격이 나올 가능성 높음 = 추적 표적.**

- `1152:132-133` `물론 24절기하고 똑 떨어지진 않아요 / 한 닷새에서 열흘 정도씩 차이가 납니다` (동일 수치 재확인)

### 🔴 환절기 토 — **정량 배점 여전히 미발견, 단 질적 규정은 이 3편이 가장 명확**

### 🟢 지장간 — 구성은 나오나 **비율(23/23/54 등) 수치 0건**
1152에서 낭독된 구성(실측): 인목=무토·병화·갑목 / 묘목=갑목·을목 / 진토=을목·계수 / 사화=무토·경금·병화 / 오화=병화·기토·정화 / 미토=정화·을목 / 신금=무토·임수·경금 / 유금=경금·신금 / 술토=신금·정화(경금 없음 명시 `1152:443`) / 해수=갑목·임수 / 자수=임수·계수 / 축토=신금·계수.
- **초보 단순화 규칙(stance)**: `1152:175-177` `일단은 이 무토하고 / 기토 같은 건 다 빼고 / 생각하시면 좋겠어요` → 지장간의 무·기토는 제외하고 읽으라는 저자 고유 지침.

### 🔴 해석 공식의 명시적 선언 (P2 판단 유닛 직결)

### 🟡 저자 자기 명식 (확인필요)
`1151:35-38` 만세력 예시로 **연=무오 / 월=갑자 / 일=병인 / 시=무자** 를 띄운다.

### 🟡 관법·stance 신규 3종
1. **관점 혼용 금지 게이트** — `1151:349` `그 척도 안에서만 연산하시는 그런 습관을 들이시면` : ①일간만 나 / 나머지는 환경, ②팔자 전체가 나 — 두 관점 다 유효하나 **한 번에 하나만 적용**. 규모(천간>지지)와 정신/현실 척도를 섞는 것이 초보 오류라고 명시.
2. **3층 우주론(통설과 다름)** — `1152:81-85` `천간은 하늘을 나타내고요 / 지지는 인간을 나타냅니다 / … / 지장간은 땅을 나타냅니다`. 통설(지장간=지지 속 천간)과 층위 배정이 다른 **저자 고유 규정**.
3. **사화=남성성 / 해수=여성성** — `1152:454` `화하고 금은 남성성이에요` + 수·목=여성성, 해수·사화는 갑목/임수·병화/경금이 다 **양간이라 동작이 커서 크게 발현**, 진토는 을목·계수라 음간이라 약하다(`1152:459-463`). 타 저자 코퍼스에 없는 독자 축.

### 🟡 궁위(자리)론 총람 — 1151의 본체 (P2 정의 유닛 대량)
- 규모 = 오른쪽 위(연간)→왼쪽 아래(시주 지장간) 대각선, 규모 크다 = **타인의 눈에 잘 보인다**(`1151:112`).
- 연주 = 대과거(=내가 기억 못 하는 과거)·조상궁·간판(외모/첫인상/직업)이나 **본인 체감은 가장 약함**.

- 시주 = 가까운 미래·자식·**은밀한 것을 공유하는 사람 4종**(아끼는/의지하는/손아랫사람/보살피는). 미래라서 원망하지 못한다.

## ③ 특이 발견

1. **이 3편이 저자 커리큘럼의 정본 축이자 해석 공식의 선언문이다.** 만세력(자리) → 천간(연령대) → 지지(계절감+지장간). 저자의 판독 공식은 명시적으로 **"지장간 속 천간들의 성정 + 그 달의 계절감(온도)"** 단 두 요소(`1152:236`)이며, 십성·용신·격국·강약·십이운성은 3편 512~581줄 전체에서 **0회**. 프로파일의 "공식 거리두기·지장간 최우선"이 강의 원본으로 확증됐다.
2. **천간을 인생 연령대(영유아→노년)로 통째 매핑**하는 것이 이 저자의 암기·해석 장치다(`1153`). "글자 뜻을 모르겠으면 그 연령대의 보편적 특징을 떠올려라, 그게 곧 정답"(`1153:502`) — 사전형 암기를 대체하는 **생성 규칙**이라 P2 화법 유닛으로 가치가 크다.
3. **제목이 '만세력 보기'인데 계산 규격이 없다.** L1 감시 항목(시간보정·서머타임·절입시각·야자시·대운수)이 전무하고, 저자가 후속편을 예고(`1151:515`)했다. → **초보자용 강의 8편 이후를 계산 규격 추적 표적으로 등재.**
4. **저자 명식 추정치 갱신**: 무오년·갑자월·병인일·**무자시**(`1151:35-38`, 만세력 예시로 사용). 기존 기록과 일치하며 시주는 신규.
5. **통설과 갈리는 지점 2개**(P1 stance 축 후보): ①지장간=땅, 지지=인간이라는 3층 배정 ②사화=남성성/해수=여성성. 둘 다 타 저자 코퍼스에서 본 적 없는 독자 규정이라 관법 프로파일 비교표에 신설 행이 필요하다.
