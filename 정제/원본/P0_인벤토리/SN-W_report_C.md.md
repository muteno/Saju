# notes_C — 산책처럼 사주 인덱스 1135~1144 (10편)

## ① 감시 항목 발견

### 환절기 토(진술축미) — 질적 규정 확보, 정량 배점은 여전히 없음
- **1136 / 129~133** `진토는 봄토고요 진중에 개수가 있기 때문에 우리가 습토라고도 이야기를 하죠` / `술토는 가을토입니다` / `가을토고 그 안에 정화가 있습니다` / `그래서 조토라고 우리가 이야기를 합니다`
  → 진토=습토(계수 근거)·술토=조토(정화 근거). **선택 규칙까지 명시**: 1136/141 `경금 주변에 뜨거운 글자들이 많아서 너무나 건조해지는 상태` → 진토로 토생금, 1136/144 `그럼 조토인 술토를 사용해서 토생금을 해주는 게 맞겠죠`. 계절 요인 병기(1136/147 `근데 진토는 봄입니다 술토는 가을이고요`).
- **1136 / 118~127** 미토 = 12지지 중 가장 뜨거움. `이 미토는 대단히 뜨거운 글자입니다`(119) / `아마 12지지 중에서 가장 뜨거울지도 모르겠습니다`(120) / 근거는 지장간 정화+을목 / **결론 = `청간신금을 잘 생하지 못합니다`(127)** → **조토불생금**을 산책처럼도 채택(도화도레 DT-P225와 동일 결론, 근거 서술은 지장간 논증).
- 정량 배점(몇 %·몇 점)은 이번 10편에도 **없음**. 감시 유지.

### 신강약 판정 — 통근을 계절로 감쇄하는 관법(신규 축)
- **1141 / 119~163** 갑목일간 인월 통근인데 실제로는 약하다: `막상 이런 분들 만나서 대화를 나눠보면`(136) / `생각만큼 그렇게 고집이 강하지도 않고`(137) / 이유 = `인월은 추워요`(140) `추위에 엄청 약합니다`(142).
  **추위에 약한 일간 명시 목록** = 1141/144~148 `감목 / 을목, 병화, 정화 / 무토, 기토 / 거의 다네요 / 가불병정 무기` (=갑을병정무기). 반례 = 묘월(양력 3월) 통근이면 `확실히 달라요`(157).
  → **통근/득령을 점수로만 세지 말고 월지 계절(한난조습)로 감쇄**하라는 규칙. 기존 도화도레·초명 점수제와 **다른 축**이므로 관법 프로파일 분기 후보.
- **1143 / 109~133** 신약 판정을 원인별로 씀: `특히 이제 관위강에서`(113) `관위강에서 신약해진 경금일관하고 신금일관분들`(114) → **"관왕(官旺)으로 신약"**이라는 원인 표기. 1143/154 `관이 강했던 신약한 임계수일관분들` 동일 문법. → **신약을 단일 스칼라가 아니라 (원인 십성 × 신약)** 쌍으로 다루는 실측 사례.
- **1143 / 134~138** `무기토일관은 물기운이 많아지면 더 신약해지거든요` → 재다신약의 오행 버전(무기토×수).

### 지장간 — 저자 관법의 최상위 근거(전 편 관통)
- **1136 / 59~113** 지지의 생극은 지장간·삼합으로 판정: `지지는요 / 상생상극의 원리를 그렇게 잘 따르지 않습니다`(61~62), 인목+자수 → `그 전에 병인충이 존재한다는 거죠`(78, **병임충 오전사**), 신금+오화 → `이도 역시 물과 불의 충돌이다`(88), 사화+묘목 → `목과 금의 충돌로 이어진다는 거죠`(100).
  **대체 절차 제공**: `지장감 보시는 게 어려우시다 / 그러면은 삼합으로 만들어 보시면 바로 나와요`(177~178).
  **예외(상생상극이 그대로 성립)** = 왕지끼리 = 유금+자수(금생수), 묘목+오화(목생화) → `그래서 우리는 이 둘을 보고 파한다라고 얘기를 하는 겁니다`(191). **파(破)의 원리를 "생이 너무 강해서 훼손"으로 설명** — 타 저자 코퍼스에 드문 해석.
- **1140 / 39~48** 3층 구조 선언: `이 양이 뜻하는 게 청간입니다`(41) / `그리고 음이 뜻하는 게 지장간입니다`(42) / `그 사이에 지지가 사람입니다`(46). → 지장간=음=땅.

### 십성 조합 공식(코퍼스 공백 항목) — 2건 회수
- **1138 / 104~118 군겁쟁재**: `우리가 흔히 얘기하는 군겁쟁제, 군비쟁제`(105) + **저자 고유의 층위 해석** = 재성이 천간·비겁이 지지면 `이 사람은요. 모릅니다`(108) `나랑 같은 선상에 재석만 먼저 들어오거든요`(109) → 당사자가 탈재를 자각하지 못한다.
- **1143 / 94~108 상관견관**: 신유일주 + 사화 정관 → `겉으로 봤을 때는 상관경관이에요`(100) 이나 지장간에서는 `갑경충을 하고 있습니다`(106) → 갑목=정재·경금=겁재 → **결론 발화 = 이성과 금전거래 금지**. 겉(십성)/속(지장간)이 다른 2층 판단의 실물.

### 대운·세운·월운 해석 절차
- **1143 / 14~43** 월운 강도 판정 규칙: 세운 글자(병오)와 **합·충·격각을 이루는지**로 임팩트를 잰다 → 계사는 무관 → 약함. **선행 유입 규칙**: `이렇게 작용력이 큰 운들은요 / 가보월 들어오기도 전에 조금 한 템포 빠르게 치고 들어오는 경향이 있거든요`(27~28), 경계 = `양력으로 5월 21일부터는`(32, 소만). → **월운 경계를 절기 중간(소만)에서 미리 넘긴다**는 관법. L2 월운 계산에 직접 영향.
- **1141 / 44~58** 대운 체감의 월지 보정: `겨울 대운이라고 누구나 다 똑같은 겨울 대운이고 여름 대운이라고 누구나 똑같은 여름 대운이 아닌 겁니다`(51). → 대운 해석은 (대운 간지 × 월지 계절) 상대값.

### 궁위·연령 대응(결정론 규칙)
- **1135 / 74~83** `일지가 대략 우리 사회에서는 지금 35세에서 45세를 뜻합니다`(78) / `이 시지는요 / 45세에서 55세를 뜻하거든요`(81~82). → 궁위→연령 구간 매핑. 배우자궁 불안정을 **시기별로 쪼개 예측**하는 데 사용.
- **1135 / 29~53 결정론 격자**: 일지를 월지·시지가 건드리는 3형태 = 형살·충·격각. **격각 4종 = 해유·사묘·신호·인자**(생지+왕지 개입, 34~38), **충 4종 = 사해·인신·자오·묘유**(양간 충돌, 124~128), **형살 = 인사·사신**(양간). 술미·축술·진술·축미는 음간 충돌이라 규모 작음. **양방향(월지+시지)이면 "대단히 불안정"**.

### 자시·야자시 / 십이운성 / 공망 / 자형 / 격국·투출 / 대운수 / 지장간 비율
- 이번 10편에 **직접 언급 없음**(0건). 저자는 십이운성·격국·용신 공식을 쓰지 않는 관법이 일관됨.
- 다만 **공식 거리두기 축자**를 새로 확보: **1140 / 239~248** `특히 수학 공부할 때 공식만 달달달 외워서 시험 볼 때 대입하려고 하면`(240) `조금만 변형이 돼도 문제를 못 풀잖아요`(241) `그거를 암기하시기보다`(246). **1136 / 24~38** `저는 개인적으로 맞으면 장땡이다 그렇게 생각을 합니다`(29) + 다양성 존중(`자신은 있지만 명리학의 세계는 워낙에 넓고 깊기 때문에 / 다양성을 존중하는 것 뿐입니다` 39~40).

### 저자 자기 명식·관법·계보
- **1142 / 19~20** `저는 4월달이 물기운이 좀 많은 달이었거든요` / `근데 물기운이 저한테는 많이 힘든 기운이라` → **저자에게 수(水)가 기신**. 기존 확보된 저자 명식(병인/갑자/무오, 병화일간)과 정합(병화일간에 임진월=수 과다).
- **1142 / 84~86, 1137 / 109~110** 학원 강사 이력 재확인.
- **1144 / 109~123 ★관법 핵심**: `이 사주 팔자라는 게 결국에는 일간이 나고 일간을 제외한 나머지 7글자는 / 나를 둘러싼 환경들이잖아요 여기서 이제 환경들이라는 것은 나를 둘러싼 사람들이라고도 얘기할 수 있다`(119~120) + **임상 기록** `저를 둘러싼 사람들 중에서 딱 한 사람을 찝어가지고 쭉 제 명식으로 따라가 본 적이 있어요`(121) → `내가 행복하고 잘 될 때 이 사람은 건강이 상하거나 일이 너무 안 풀리고`(122). **운영자 2원칙(환경)의 저자판 + 명식=관계망 모델**.
- **1140 / 94~118 ★신규 결정론 축**: `여기서 주의하실 점이 남성성은 화하고 금입니다`(99) `그리고 여성성은 수하고 목입니다`(100) — **통설(목화=양/금수=음)과 별개의 제2축을 명시적으로 병존**시킴(`둘 다 맞는 관점입니다` 104). 대표 글자 = **해수(갑목+임수)=여성성, 사화(경금+병화)=남성성**. 성별에 따라 같은 명식도 발현이 다르다(`그 사람이 여성불이냐 남성불이냐에 따라서 발현되는 것은 정말 하늘과 땅끝 차이입니다` 97).
- **1138 / 14~28 ★인식 계층 이론(저자 고유)**: `우리의 유전자가 일간과 같은 천간에 있는 것들을 우선적으로 인식합니다`(22) → 지지 → `지장간에 있는 것은 거의 인식을 못하다가 어떤 특정한 사건이 생기면 인식하게 되더라`(28). **십성을 "강약"이 아니라 "자각 여부"로 읽는 프레임** — 상담 화법·가설카드에 직결(같은 십성도 층위에 따라 본인이 모른다).
  또 **십성보다 오행 우선 선언**: `저는 십성으로 보는 건 사실 그렇게 좋아하지 않습니다 왜냐하면 십성이 자극적이다 보니까 / 오행이 어찌 보면 더 중요한데 그걸 자꾸 놓치게 되거든요`(17~18).

## ③ 특이 발견
1. **저자의 "인식 계층" 이론(1138)이 가설카드 설계에 직접 쓰인다.** 같은 십성이라도 천간이면 본인이 자각(→ 성향 질문으로 확인 가능), 지장간이면 자각 못함(→ 성향 질문이 실패하고 **사건 질문**으로만 잡힌다). 즉 프로브를 던질 때 "이 글자가 어느 층에 있나"로 **질문 유형을 갈라야** 한다는 규칙이 코퍼스에서 나온 것 — 계산분기 카드/Q-카탈로그에 반영 가치가 높다.
2. **월운 경계가 절입이 아니라 '큰 운의 선행 유입'으로 흔들린다(1143).** 5월 21일(소만)부터 갑오월 기운을 쓰라는 지시는 결정론 엔진의 월주 경계와 어긋난다 → **L1은 절입 그대로, L2에 "선행 유입" 보정 필드**를 두는 설계가 필요. 저자 고유 규칙이므로 관법 프로파일에 귀속.
3. **격각(隔角)이 이 저자의 주력 도구.** 타 저자 코퍼스에서 얇았던 개념인데 1135·1143에서 4종(해유·사묘·신호·인자)을 결정론 격자로 명시하고 배우자궁·직장궁 판정에 실사용. **개념지도 '격각' 항목의 자료량이 이 배치로 크게 채워질 것.**
4. **1137·1140이 같은 '음양' 주제의 2판본**(1137=가지려함/지키려함 응용편, 1140=정의편). 중복이 아니라 상보적이나, P1 반복 접기 때 정의 블록(양=밝음·건조 / 음=어둠·습)은 **양쪽에 중복 등장**하므로 대표 1 + 반복수 처리 대상.
5. **1139는 순수 매장 공지**(산책학교 대구, 대구 중구 태평로 50). 1138 말미(239~249)에도 같은 공지가 예고로 붙어 있어 **공지 중복 세트**. 상담료·연락처 실값은 본문에 없음(더보기·게시판 참조라 텍스트 결손).
