# SN-W / D 담당 (인덱스 1145~1150) 작업 노트

대상 6편 = 1145 충과 격각이 많은 사주 · 1146 삼합의 원리 · **1147~1150 초보자용 강의 1~4(음과 양 / 생의 원리 / 오행의 성질 / 극의 원리)**

---

## ① 감시 항목 발견

### 저자 자기 명식 (기존 프로파일 확증)
- **1145 / 79~83줄**: `실제로 저 같은 경우도 지지만 보면 오화가 있고 자수가 있습니다` / `그리고 잇목이 있고 또 자수가 있어요`(잇목=인목) → 지지에 **인·자·오**. 본인이 `여기는 좌우충이고 여기는 인자격각, 생자왕제격각이고 / 또 여기도 인자격각`(84줄 앞)이라 셈. **CLAUDE.md에 기록된 산책처럼 명식(병인/갑자/무오)과 지지가 정확히 일치** → 프로파일 확정 근거.
- **1145 / 84~178줄**: 자기 명식 발현 서사(휘둘림 → 고집불통 → "경청하되 휘둘리지 말자"). 저자 본인 사례로 충·격각 해석을 검증하는 구조 = 역추론 자산은 아니나 (원국→성향) 매핑 실증.

### 저자 관법·계보 (기존 "공식 거리두기" 확증)
- **1146 / 29~37줄**: `그냥 공식만 달달달 암기하고 / 적용하려고 그러면 / 문제를 조금만 꼬아서 내도 적용이 안 됩니다` → **원리주의 = 이 저자의 일관된 관법**. 이번 6편 전체가 "암기 말고 원리" 구조.
- **1148 / 359줄 ★**: `그래서 명리학에서 사주팔자가 있다고 해서 우리의 운명이 정해진 게 아니거든요` + 운명을 바꾸는 두 힘 = **화(감정)·수(성찰)**. → **운영자 해석철학 1원칙(명=기질, 운명 아님)의 저자판. 보드 [1부-보완] 게재 후보.**
- **1149 / 34~39줄**: `모두가 양면성이 있다 / 그리고 사실 좋고 나쁨은 없다` → 오행 5종 전부 장·단점 병기로 강의. **L4 게이트 문형 재료**(귀천·길흉 단정 금지).

### 환절기 토 (정량 배점 여전히 미발견 — 단 질적 근거 3건 신규)
- **1148 / 84~98줄 ★stance**: `오행이지만 / 실체가 있는 것은 / 사행이다` — **토는 실체가 없다(사계절만 실재)**. 단 `내가 사주원국에 토가 있다 / 실체가 없다는 얘기랑은 완전히 다른 얘기예요`, `어떻게 보면 토야말도 거의 주인공격이거든요`로 즉시 보정.
- **1148 / 154~168줄**: 화→금 직행 불가 논증 = `여름의 기운은 너무 뜨겁다 보니까 / 여리여리한 금속한테 열을 가하면 / 금속이 부러져버립니다` → 토가 흡수·중화 후 가을로. **조토/습토 구분이나 배점은 없음. 감시 유지.**
- **1148 / 329줄 + 1149 / 248~252줄**: 토 = **광명지심**(중심 지키는 마음) — 오행 성질 체계의 일부로만 다룸.

### 신강약 (배점 없음, 그러나 원리적 기반 발견)
- **1150 / 214~247줄 ★**: `고통의 크기가 상대적인 거라는 거죠`(10억 중 만원 강탈 vs 전 재산 만원 강탈) → `이렇게 극의 원리는요 / 절대적이지 않고 상대적입니다` + `나중에 여러분들이 명식을 판단하고 ... 이게 대단히 중요한 역할을 해요`.
- **1150 / 249~283줄**: `a가 b를 극한다` → **B가 허약 = 고통 / B가 튼튼 = 뿌듯함**(세금 비유). `물론 명리적으로 이 사주가 지금 튼튼하다 아니다 / 이걸 가지고 판단할 수도 있겠죠`. → **신강약을 점수가 아니라 '극을 견디는 체력'으로 정의하는 관법.** 배점표는 없음.

### 미발견(이 6편에는 없음)
자시·야자시 · 십이운성 · 공망 · 자형 · 격국/투출 · 대운수 · 지장간 **비율 수치** · 역추론/콜드리딩 실전.

### 신규 관법 요소 (기존 4저자 코퍼스에 얇은 것)
- **격각(隔角) 체계 — 1145 / 24~28줄 ★결정론**: `삼합을 만들었을 때 서로 반대되는 글자들의 충돌` 중 **생지-왕지 격각 4종만 채택** = `인자격각, 그리고 신호격각, 그리고 해유격각, 그리고 사묘격각 이렇게 4개`(신호=신오). 성립조건 = **나란히 붙어 있을 것**(29~33줄). 작동 기제 = 운에서 반합이 오면 생지가 왕지를 서포트해 충돌(39~53줄, 인자격각+오화운 → 인오합 → 오·자 충).
- **'많다'의 정량 기준 — 1145 / 149~158줄 ★수치**: 한 군데면 무방, **두 군데 이상 = 많다**, 세 군데 = 정말 많다.
- **충·격각의 해석축 = 길흉이 아니라 '변화량'** (1145 / 54~78줄): `충이나 격각이 나빠서 그런 게 아니고요 / 변화를 일으키는 데 초점이 있다`. 게이트 문형 후보: `금이 가고 깨져가지고 안 된다. 이렇게 생각하지 마십시오`(159~163줄).
- **삼합의 원리 = 지장간 중기 동일 오행 — 1146 / 199~218줄 ★결정론·별점**: `이 삼합이라는 에너지는요 중기가 같은 오행인 것들끼리 묶어놨다`. 여기+본기(1·3열) = 계절 순환 = **땅의 질서**, 중기(2열) = **하늘의 질서**. 왕지 중기 공란은 빈 게 아니라 `갑목이 을목으로 변하는 중`(144~158줄)이라 표기 불가한 것.
- **하도/낙서 수리 논증 — 1150 / 34~63줄 ★결정론·수치**: 하도(1·6수 3·8목 5·10토 4·9금 2·7화)에서 **화(2·7)와 금(4·9)의 자리만 교환하면 낙서 = 상극 순환**이 된다. `4하고 9가 낙서에서는 위로 올라갔습니다`. → 생/극이 같은 수 배열의 두 배치라는 기계 검증 가능한 논증.
- **극(剋) = 제어가 아니라 '필요로 하다' — 1150 / 104~127줄 ★별점**: `극한다라는 건 사실 필요로 한다라고` + `내가 돈을 극하는 게 되버려요 / 우리는 돈을 필요로 한다`. → **재성 해석(나→돈)의 원리적 정의. 십성 유닛 chain 재료.**
- **오행 성질 5덕 체계 — 1149 전편 ★결정론**: 목=측은지심 / 화=사양지심(개인보다 전체·명예·명분·예의) / 토=광명지심(중재) / 금=수호지심(정의·고치려 함) / 수=시비지심(지혜·개인). 각 오행마다 장점·치명적 단점 쌍으로 제시. **목만 단점이 치명적이지 않다**는 서열 주장(94~158줄).
- **프로브 후보 2건**: ①1149 / 309~323줄 `사주원국에 금이라는 오행을 갖고 계신 분들이 있으면요 / 타인에게 자꾸 조언을 합니다` → 조언 배틀 여부로 금 발현 확인. ②1149 / 369~388줄 화·수 혼재 명식 = `모두를 위할 것이냐 / 아니면 나 개인을 위할 것이냐`가 인생 테마.
- **출생월 결정론 — 1147 / 279~303줄 ★결정론**: `양력으로 7월에 태어난 사람` → 양기 정점을 지나서 `의외로 안 그러신 분들이 더 많습니다 / 반대로 좀 더 사색적이고 철학적`. 1월생도 동형. 가장 강한 때는 **정점 직전(6월·12월)**. → 검증 가능한 주장이므로 P4 후보.
- **천간지지 = 한 기둥 위아래가 음양 한 쌍 — 1147 / 304~328줄**: `이 자리랑 바로 밑에 있는 이 자리 / 음과 양의 관계다 / 두 개를 합쳐서 하나다`. 간지 동주 해석 원칙.

## ③ 특이 발견

1. **1147~1150은 이 저자의 커리큘럼 정본이 맞다.** 본인이 `초보자용 강의 리뉴얼`이라 밝히고(1147-14~23) 화이트보드 대신 컴퓨터로 촬영, `1, 2년은 계속 걸어놓는 거니까`라며 정본화를 명시. 순서 = 음양 → 오행/생 → 오행 성질 → 극 → (예고) 만세력·천간·지지·지장간. **v2.1 "저자 집필 순서 = 교육 설계도" 규칙의 5번째 저자 스파인.**
2. **정의가 서사·비유로만 전달되고 수치가 거의 없다.** 6편 통틀어 수치 플래그는 하도 수 배속·격각 "두 군데"뿐. 이 저자는 배점·비율표를 안 쓰는 계열 → 신강약·환절기 토 배점을 이 채널에서 기대하기 어려울 수 있음(잔여 인덱스 판단 참고).
3. **P2 '판단 유닛' 재료로서의 가치는 chain의 앞부분(왜 그런가)에 몰려 있다.** 예: 삼합=중기 동일 오행, 극=필요로 하다, 고통은 상대적 → 결론이 아니라 **연결 논리**를 공급한다. 증류공백진단 문서가 지목한 "이론과 해석 사이"의 정확히 그 구간.
4. **1145는 저자 본인 명식으로 자기 이론을 검증하는 유일한 편.** 원국(인·자·오 = 충1+격각2) → 생애 패턴(휘둘림) → 대처법까지 완결. **(원국→성향→처방) 3단 쌍이 온전한 사례로 P4 역방향 시험 문항 후보.**
5. 1149에 사단(측은·사양·시비) + 광명·수호가 섞인 5덕 체계가 나오는데, 유교 사단칠정 용어를 오행에 배속한 것이라 **출처 계보 추적 대상**(초명·강헌 계열 용어인지 확인 필요).
