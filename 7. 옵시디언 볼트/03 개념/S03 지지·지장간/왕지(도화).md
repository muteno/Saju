# 왕지(도화)

> [!abstract] 정의
> 자·오·묘·유(子午卯酉) 네 글자를 묶는 분류 이름. 계절의 기운이 왕성한 자리라는 뜻이며, 삼합국에서 가운데 글자 자리를 맡는다. 신살 이름으로는 도화(桃花)가 이 자리에 대응한다. 보드는 왕지를 「순수한 성향 — 해당 오행의 지장간으로만 구성」이라고 적는다.

**🌱 어디서 나오나** — 열두 지지 표의 분류 칸에서 나온다. 네 방합국의 가운데 글자, 네 삼합국의 가운데 글자가 모두 왕지다. 방합국 조견표는 「월지에 왕지가 위치할 때 진방합이라 하고 세력이 더 강하다」는 성립요건을 달아 두었다.

**⚙️ 어떻게 산출되나** — 고정 명단이며 다른 표의 인덱스 키로 쓰인다 — 지장간 일수 배분(왕지 10/20, 중기 없음), 지지충(자오·묘유 = 왕지끼리의 충), 파(자유·오묘 = 왕지파), 형(자묘형), 십이신살 산출 조건이 모두 이 분류로 갈린다.

**🌿 무엇을 낳나** — 십이신살 넷이 왕지 자리에서 나온다 — 재살(반대 삼합국의 왕지) · 년살(이전 삼합국의 왕지) · 장성살(현재 삼합국의 왕지) · 육해살(다음 삼합국의 왕지)이고, 역마살도 반대 삼합국의 왕지다. 대표 예로 사유축(금국)을 기준지로 삼으면 장성살 = 유금(酉)이다. 또 왕지가 충·형을 받을 때 「가도화살이 진도화처럼 발현」한다는 전환 규칙이 왕지 절[1906]과 십이신살 절[3410] 두 곳에 같은 취지로 적혀 있다.

**⚖️ 갈리는 것** — 왕지의 지장간 칸 수가 판본마다 다르다 — 보드 판본은 2칸(중기 없음, 예: 자 = 임10/계20), 웹 일수 판본은 3칸(10/10/10)이다. 오화만은 세 판본 모두 3칸으로 적되 일수가 10/10/10과 10/9/11로 갈린다.
