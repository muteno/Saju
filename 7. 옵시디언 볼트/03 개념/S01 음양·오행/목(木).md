# 목(木)

> [!abstract] 정의
> 위로 뻗어 오르고 나아가는 기운. 오행 다섯 중 첫 번째로 놓이며, 봄에 배속된다.

**🌱 어디서 나오나** — 계절에서 나온다. 보드의 계절-오행 배속표가 「성장기(봄) 1 목(木)」으로 순번까지 붙여 둔다. 물상으로서의 나무가 먼저 있고 거기서 성질을 뽑은 것이 아니라 운동의 방향이 먼저라는 서술이 코퍼스에 있다 — 「제가 사주에서 목은 나무가 아니라고 했던 거고요, 정확하게는 목은 시작하는 기운이에요, 분출하는 기운이에요」.

**⚙️ 어떻게 산출되나** — 어느 글자가 목인지는 조견표로 확정된다. **천간** 갑(甲)·을(乙). **지지** 인(寅, 생지·계절의 시작)·묘(卯, 왕지·계절의 절정). 그밖에 목이 «나오는» 자리가 둘 더 있다 — 고지 미(未)가 목의 묘지이고(미: 여름 → 이전 계절: 봄, 목의 묘지), 육합 인해(寅亥)의 합화 오행이 목이다. 보드 배속표는 목에 다음 값을 건다 — 방위 동(東) · 오상 인(仁) · 상징색 초록색 · 장기 간(간·쓸개) · 물상 나무(양) / 풀·꽃(음) · 숫자 3·8 · 본질 「양(+), 생성의 방향」.

**🌿 무엇을 낳나** — 목이 생하는 것 = 화(火). 목이 극하는 것 = 토(土). 목을 생하는 것 = 수(水). 목을 극하는 것 = 금(金). 하위로 갑목·을목·인목·묘목이 매달리고, 위로는 오행(총칭)에 말려 올라간다. 합화·삼합(해묘미)·방합(인묘진)의 결과 오행으로도 나온다.

**⚖️ 갈리는 것** — 상징색이 갈린다 — 보드는 초록색, 코퍼스에는 「오행 목木이 연두색이라고 주장하는 근거는 바로 오행 수水 때문입니다」처럼 연두를 드는 관점이 있다.
