# 통변 순서

> [!abstract] 정의
> 원국의 여덟 글자를 어느 자리부터 어떤 차례로 읽어 나가느냐를 정한 절차. 결과가 아니라 «읽는 동선»을 규정하므로, 같은 원국이라도 순서가 다르면 무엇을 먼저 말하게 되는지가 달라진다. 코퍼스에서 이 절차를 명시적으로 적어 둔 저자가 일곱이고, 방법론 보드에도 한 벌이 따로 있다.

**🌱 어디서 나오나** — S13 자리(궁위)와 S05 십성 위에 얹힌다. 순서의 뼈대는 **자리**(일간 → 일지 → 월지 → 나머지)이고, 십성·신살·십이운성·용신은 그 자리에 겹쳐 읽는 렌즈로 들어온다. 보드는 이 구조를 「사주를 푸는 과정」 표로 못 박아, 6단(본질-일간 / 나-일주 / 에너지-월지 / 조화 / 흐름 / 궁합)마다 하위 항목을 배정한다 — 1단은 일간 특성 하나뿐이고, 2단에 일지·지장간·투출·통근·길성/신살, 3단에 월지·격국·월일지 관계, 4단에 조후·십성·신강신약·용신(용희한 3 : 기구 2), 5단에 대세운 유불리·합충형해파·십성길성신살, 6단에 궁합이 들어간다.

**⚙️ 어떻게 산출되나** — 산출식이 아니라 열거된 목록이다. 코퍼스의 판본을 그대로 옮기면 — ①초코서당은 「일간 → 일지·일주 → 월지·월주 → 각 주의 간지와 일·월지 지장간 투출 여부 → 신강·신약과 조후 → 용신·기신·구신·한신 → 대세운 유불리」 일곱 단계로 적는다. ②도화로운은 「일간 > 일지 > 월지」 셋으로 줄인다. ③도화도레는 「일간, 일지, 월지, 오행, 배치, 십성, 배치, 합충」 순으로 적고 **공망을 맨 마지막에 둔다**고 밝힌다. ④플러스명리학(정통명리학 계열)은 자리가 아니라 **월지에서 출발한다** — 「월지 격 판단 → 월령(월지 지장간에서 투출한 글자) 용신 확정 → 병(病)과 약(相神) → 천간 생극제화 → 지지 형충회합 → 월지 십성에 따른 대운 방향」이며, 이 계열은 「신강신약에 따른 용희신을 적용하지 않는다」고 스스로 명시한다. ⑤사공은 자리 순서 대신 작업 단계 다섯으로 나눈다 — 「1. 사주팔자 작성 2. 사주구조 분석 3. 십성 집중 분석 4. 행운 분석 5. 질의응답」이며, 통근·투출에는 별도의 5단 하위 순서를 둔다(통근/투출 여부 → 천간 십성과 통근한 지지의 십성 → 통근한 근묘화실 → 통근한 지지의 형충회합 → 통근한 천간과 육친).

**🌿 무엇을 낳나** — 상담 방법 나머지 넷이 전부 이 순서 위에서 돌아간다. 문진·질문지는 순서를 시작하기 전에 놓이고, 프로브는 각 단계에서 읽은 것을 확인하는 되물음이며, 질문 재구성은 마지막 단계(질의응답)를 답할 수 있는 형태로 바꾸는 일이다. 그리고 순서는 **금지선의 집행 도구**이기도 하다 — 「일간부터 본다」가 지켜지면 신살이나 공망 한 글자로 결론을 내는 화법이 구조적으로 뒤로 밀린다.

**⚖️ 갈리는 것** — ①**출발점이 갈린다** — 일간 출발(초코서당·도화로운·도화도레)과 월지 출발(플러스명리학 계열)이 정면으로 다르고, 사공은 자리 대신 작업 단계로 축을 바꾼다. ②**순서의 지위 자체가 갈린다** — 사공은 「사실 어느 수준에 도달하면 사주 통변 순서가 그리 중요하지 않습니다 … 통변 순서는 술사의 성격과 스타일에 가장 많이 좌우되기 때문에 정답을 논하기가 어렵습니다」라고 적고, 같은 글에서 「이렇게 순서를 나누고 구분한다는 것 자체가 억지일 수 있습니다」라고 다시 못 박는다. ③**같은 저자 안에서도 화법이 갈린다** — 사공은 순서 대신 쓸 수 있는 질문 아홉 개를 병기한다(질문자는 어떤 사람인가 / 무엇을 추구하는가 / 살아온 또는 살아갈 환경은 어떠한가 / 현재는 무엇을 하는가 / 미래는 무엇을 할 것인가 / 어떤 사람을 만나는가 / 어떤 문제가 발생할 수 있는가 / 문제가 있다면 어떻게 해결해야 하는가 / 질의응답). ④보드의 6단 표는 6단(궁합)을 순서 안에 넣지만, 코퍼스 판본 다섯 중 궁합을 순서에 넣은 것은 없다.
