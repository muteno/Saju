# 캐릭터 레퍼런스 — 여기에 원본 1장씩

표정·장면 시트 생성 레일(`.github/scripts/gen_chef_faces_v1.py`)이 **이 폴더의 PNG를 첨부**해
`/v1/images/edits`로 같은 캐릭터를 유지한 채 표정·장면만 갈아 끼운다. 레퍼런스가 없으면 시트마다
다른 사람이 나오므로, 파일이 없으면 스크립트가 **명시적으로 중단**한다.

## 파일명 계약(고정)

| 파일 | 캐릭터 | 배정 |
|---|---|---|
| `noona.png` | 은백발 기센 언니 도사 | 남성 사용자 상담 |
| `doryeong.png` | 갓 쓴 흑발 도령 도사 | 여성 사용자 상담(운영자 "메인이 1번") |
| `dongja.png` | 백발 동자승(백사) | 배정 미정 |

## 왜 운영자가 직접 올려야 하나

세션 채팅에 첨부한 이미지는 **컨테이너 디스크에 남지 않는다**(260726 실측 — 첨부 후 파일 검색 0건).
그래서 세션이 그 그림을 파일로 저장할 방법이 없다. 이 폴더에 커밋해 주면 그때부터 레일이 돈다.

## 권장 규격

- PNG · 정사각에 가까울수록 좋다(시트 격자가 안정된다) · 긴 변 1024px 이상
- 배경은 단색이거나 단순할수록 좋다(표정 시트가 배경까지 따라 그리지 않는다)
- 인물이 화면의 60% 이상을 차지하는 상반신 컷이 표정 계승에 제일 유리하다
