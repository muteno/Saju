## 2. 찾아온 외부 기틀 (인터넷)

【바인딩】 디자인 = **확립본 없음**이 이 레포의 빈칸이었다. 그 빈칸을 채울 외부 정본을 가져왔다.

| 기틀 | 가져온 것 | 출처 |
|---|---|---|
| **Apple HIG** | 최소 텍스트 = **Caption 2 = 11pt** · 최소 탭 타깃 = **44×44pt** · 8pt 그리드(4pt 세분) · 원칙 = Clarity·Deference·Depth · 색은 hex 아닌 **의미 토큰**으로 설계 | superdesign.dev(Apple 디자인 시스템 정리·복사용 DESIGN.md) |
| **Liquid Glass**(WWDC25) | **반투명 판을 두 겹 쌓지 마라** · **유리 안 버튼은 불투명 채움으로** · 컨트롤은 콘텐츠 위에 떠 있고 **콘텐츠가 주인** · 유리는 장식이 아닌 기능 레이어 · 접근성(투명도 축소·고대비) 존중 | Medium/Supercharge/createwithswift 정리 |
| **Material 3** | 최소 탭 타깃 **48dp** · **8dp** 기준 그리드(아이콘·타입은 4dp) | m3.material.io / Android 접근성 문서 |

**두 시스템이 합치하는 축을 하한으로 채택**: 탭 44(HIG, M3보다 낮은 쪽) · 그리드 8/4 · 텍스트 11pt. 우리 앱은 이미 MUI(spacing 8px) + 44px 원형 버튼이라 **구조는 맞고 하한만 새고 있었다.**

## 3. 적용 — 하한 미달 실측 후 수선

찾은 기준으로 7화면을 실측했다(추측 0).

### 3-1. 가독 하한(11pt) 미달 — 19건
| 미달 크기 | 어디 | 처리 |
|---|---|---|
| **7.98px** | 대운 레일 타일의 극성+오행 첨자(`size 38 × 0.21`) | 첨자 **끔**(`showPolarity={false}`) — 아래에 십신·12운성 텍스트가 이미 있다 |
| **9.12px** | 대운 레일 타일 한자(`38 × 0.24`) | 하한까지 **clamp**(뜻이 있는 내용) |
| **9.66px** | 원국표 타일 극성+오행(`46 × 0.21`) | 하한까지 clamp — **색은 오행만 인코딩하고 음양(+/−)은 색으로 표현되지 않아** 원국표에선 정보다 |
| **10px** | 원국표 행 라벨(십성·천간·지지…) | → 11 |
| **10.5px** | 출처 줄 · 12운성 · 12신살 · 열 라벨 · 오행 스트립 판정 · 준비중 배지 | → 11 |
| **9px** | DosaChat 진행 표지·주제 복귀·mini 라벨 | → 11 |

`theme.ts`에 **`tokens.minFont = 11` · `tokens.minTap = 44`** 를 근거 주석과 함께 박았다 — 값의 단일 출처.

### 3-2. 탭 타깃(44) 미달 — 4건
| 크기 | 어디 | 처리 |
|---|---|---|
| 50×20 · 122×20 | 로그인 하단 링크(회원가입 / 아이디·비번 찾기) | `minHeight 44` + 좌우 패딩(글자 크기 무변경) |
| 88×26 | 리포트 카드 `더 보기 / 접기` 칩 | `minHeight: tokens.minTap` |
| 259×35 | `에니어그램 테스트로 검증하러 가기` · `출생 시간 입력하러 가기` | MUI `size="small"`이 35px로 깎던 것 → `minHeight: tokens.minTap` |

※ 오탐 제외: 리스트 행 내부 텍스트(부모 행이 타깃) · 탭 라벨 span · 이름표.

### 3-3. 게이트화 (재발 차단)
`scripts/smoke.mjs`에 **하한 감사**를 넣었다 — 대표데이터(`?qa=1`) 3화면에서 ① 11px 미만 텍스트 0 ② 44px 미달 탭 타깃 0을 assert. 값은 `theme.ts` 토큰이 정본.

**게이트가 즉시 작동했다**: 1차 수선 후 돌리자 `[analysis] 44px 미달 1건: 259x35 "에니어그램 테스트로 검"`을 잡아냈다 — 내가 놓친 MUI `size="small"` 케이스다. 이게 게이트를 문장 대신 코드로 두는 이유다.
