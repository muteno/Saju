## (A) 제1 핵심명령 — 계승 또는 갱신, 둘 뿐

> ⛔ **이 레포 UI의 *모든* 디자인 값(색·간격·radius·blur·곡선·모션·그림자·크기·타이포 등)은 「루트 디자인 토큰」을 [계승]하거나 [갱신]한다 — 둘 중 하나로만. raw 값 임의 창작·제각각 재설계 절대 금지.**
> 「루트 디자인 토큰」 = **값 SSOT = `app/src/index.css`의 `:root`**(+ §2 예외 2축).
> 컴포넌트는 토큰이 아니라 **§4 부품 인벤토리** 정본을 계승한다(별개 축).
>
> ⚠️ **우선순위 = 디자인 *내용* 축 한정**: 이 절은 "raw 금지·계승/갱신 2택"의 선언일 뿐, 레포의 **§0/A/B/C/D 실행절차·기틀검증을 대체·완화하지 않는다**(별개 축 = 중첩). 구체 충돌 시 `CLAUDE.md`가 우선.
>
> - **① [계승] = 항상 디폴트(안 물음)**: `var(--토큰)`으로 가져다 쓴다. **정확한 토큰이 없어도 가장 가까운 토큰을 자동 계승**(안 물음). 재설계·raw 창작만 금지.
> - **② [갱신] = 운영자 승인 필수 · 2티어**: 값 미세조정 = 승인 후 편입 / 토큰 신설·삭제·구조 변경 = 기틀 → 확인+교차검증까지가 승인의 일부. 승인 후에만 편입(→ 거울 동조 → §4 등재 → `npm run verify` → 락 갱신).
> - **③ 근접 토큰조차 없어 [갱신]이 불가피할 때만 묻는다**: 「[갱신](신설)할지 / 어떤 근접 토큰을 [계승]할지」 두 선택지를 제시하고 답을 받는다. ⚠️ 정확히 안 맞는다고 바로 묻지 마 — 근접 계승은 자동이다.
> - **⛔ 예외(= 이 명령 대상 아님 · 정당 raw)**: 기하·수학값(중앙 `-50%`·원 `50%`·빈 진행바 `0`)·애니 키프레임 안무 `%`값·1회성 광학 보정 px·OS/서드파티 강제(`env()`·벤더 프리픽스)·컴포넌트 로컬 스택 z-index·아직 토큰이 없는 축·자기완결 템플릿(플레이그라운드 HTML = 토큰 참조 불가 → 값 복사가 곧 계승).
> - ⚙️ **강제 경계(정직)**: 기계가 하드차단하는 것과 소프트룰(세션 준수에 의존)을 명시 구분한다 → §6. **게이트 초록 ≠ 규칙 완전 준수.**

## §3 ⚠ 거울 드리프트 — 실측 적발 3건

`theme.ts`의 `modeColors`는 MUI `palette`로 주입되는 **hex 복사본**이라, CSS 토큰이 바뀌어도 **조용히 옛 값을 유지**한다. 260726 실렌더 대조 결과:

| MUI palette 키 | `theme.ts` 값 | 대응 CSS 토큰 | CSS 값 | 상태 |
|---|---|---|---|---|
| `background.default` | `#f3f3f5` | `--c-page` | `#eef0f6` | ⛔ **불일치 · 실제 body에 칠해지는 중** |
| `text.secondary` | `#6b6b72` | `--c-ink-sub` | `#5b6070` | ⛔ 불일치 |
| `divider` | `#e7e7ec` | `--c-border` | `#e2e4ee` | ⛔ 불일치 |
| `primary.main` | `#22409e` | `--c-primary` | `#22409e` | ✅ |
| `background.paper` | `#ffffff` | `--c-card` | `#ffffff` | ✅ |
| `text.primary` | `#1b1b1f` | `--c-ink` | `#1b1b1f` | ✅ |

**실렌더 증거**: `/?qa=1&view=input`에서 `body` 배경 = `rgb(243,243,245)`(=`#f3f3f5`) — CSS `--c-page`(`#eef0f6`)가 **적용되지 않고 있다**. 반면 `.MuiOutlinedInput-notchedOutline`은 `rgb(226,228,238)`(=`#e2e4ee`)로 CSS 토큰을 따른다(그쪽은 `styleOverrides`가 `var(--c-border)`를 직접 쓰기 때문).

→ **같은 화면에 두 팔레트가 공존**한다. palette 경유 요소는 옛 값, `var()` 경유 요소는 새 값.

**수선 (260726 적용 완료)**: `modeColors` hex 복사본을 제거하고, palette가 **CSS 토큰 실값을 읽어** 채우도록 바꿨다(`theme.ts`의 `cssToken()`).

⚠ **`var(--x)` 문자열 참조는 불가**로 판명됐다 — 1차 시도에서 palette에 `'var(--c-primary)'`를 넣자 MUI가 색을 파싱하지 못해 **error #9로 앱 전체가 죽었다**(실렌더 적발: 입력 화면 미렌더). palette 값은 MUI가 `alpha()`·`darken()`으로 계산하므로 실제 색이어야 한다. 그래서 **참조 대신 읽기**로 간다 — 값의 출처는 여전히 `index.css :root` 하나뿐이라 거울은 무손실이고, 못 읽으면 키 자체를 넘기지 않아 hex 복사본이 생길 자리가 없다.

**수선 후 실측**: `body` 배경 `rgb(238,240,246)` = `#eef0f6` = `--c-page` 일치 · 옛 palette hex 화면 잔존 **0건** · MUI 에러 0.

## §6 강제 경계 — 무엇을 막고 무엇을 못 막나 (정직)

**기계가 하드차단** — 신토큰 무단 추가(T1) · MUI palette hex 재발(T2) · raw 값 총량 증가(T3) · 11px 미만 글자·44px 미만 탭(기존 smoke 하한 감사)

**소프트룰(세션 준수에 의존 · 기계가 못 잡음)**
- 승인을 실제로 받았는지 여부 — 세션이 락도 갱신할 수 있다
- 토큰이 **있는데도** 근접 계승 대신 다른 토큰을 쓴 경우
- 토큰이 없는 축(지속시간·눌림·z)의 raw — baseline 안에서는 통과한다
- 의미색 오용(오행 색을 오행 아닌 데 쓰기)

→ **게이트 초록은 "위반이 늘지 않았다"는 뜻이지 "규칙을 지켰다"가 아니다.**
