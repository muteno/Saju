# F01 후속 — 합·충 총칭의 범위와 보충 오탐

2026-09-23 · 사용자 원문 38 · 기준 main `5a6e4cd8ad02a54a5ac7e0b09664c4e237630bb4`(PR #184).

두 총칭의 **검토상 정의·하위 구분·인식/제외 조건을 기록**했다. 총칭 신규 노드와 로컬 구어 8개는 실행에 넣지 않는다. 실제 적용은 기존 `충을`·`충이 일어`가 **보충 내부에 들어 있는 경우만 제외**하는 수정이다. 개념지도와 뉴런 매칭에 같은 위치별 검사를 적용한다. 현재 271개 사전·P2·D5·앱 계산·58항목 연구 그래프·학습 상태는 유지한다.

## 인식 조건·제외 조건과 보류 해소 조건

로컬 8개 표현은 `합을 하 / 합을 해 / 합이 돼 / 합이 되`, `충을 하 / 충을 해 / 충이 돼 / 충이 되`다. [측정 기록](data/foundation_general_measurement.json)은 단순 부분문자 일치와 왼쪽 단어 경계가 있는 일치를 **탐색 후보**로만 센다. 공백 유무만으로 의미 검수를 통과시킨 것이 아니다.

1. **단어 경계:** 결합·종합·보충 안의 부분문자는 총칭 근거가 아니다. 붙여 쓴 천간합·육합·자오충 등의 하위 용어를 오탐으로 삭제하지 않고 기존 하위 노드에 남긴다. 붙여 쓰기·전사 오류는 별도의 검토 대상으로 둔다.
2. **문맥:** 명리 관계를 논하는 실제 절과 참여 글자/범위를 확인한다. 같은 문단 어딘가에 `사주`가 있다는 조건만으로 일상적 결합·합계 등을 통과시키지 않는다. 총칭만 식별된 경우 하위 종류는 미상으로 둔다.
3. **언급/성립 구별:** `합을 하려고`, `충을 하거나`, `합이 되지 않는다`도 관계를 논하는 문헌이지만 해당 원국에서 관계가 성립했다는 라벨은 아니다. 부정·가정·시간 범위를 보존해야 한다.
4. **기존 구성 보존:** 긴 별칭이 오행·일지·천간충 등의 짧은 구성 개념을 가리지 않는지 두 빌더에서 같은 입력으로 측정한다. 총칭에 하위 이름을 모두 넣어 모든 동시출현을 늘리는 방식은 채택하지 않는다.
5. **적용 전 계약:** 새 노드를 넣을 때는 271개를 보존하는 현재 검사 계약을 별도의 후속 판정 형식으로 확장해야 한다. 원래 해시·판본 스냅샷을 새 값으로 바꿔 통과시키지 않는다. `충을`·`충이 일어`의 총칭/하위 배정과 D5 인용 자격까지 확인한다.

이번에는 2·3·5를 충족한 실행 경로가 없으므로 두 총칭의 신규 배정을 보류한다. 다음 담당자는 이 이유를 지우고 8개 표현을 단순 추가하지 않는다. 원문 접근/사용자 승인 대기 때문에 멈춘 것이 아니라 현재 적용 기준을 아직 만족하지 못한 판정이다.

## 실제 수정과 전후 측정

`build_neuron_map.alias_occurrence_allowed()`는 기존 별칭 `충을`·`충이 일어` 앞에 `보`가 붙은 **그 위치만** 제외한다. 개념지도도 같은 함수를 사용한다. `보충`이 한 번 나왔다는 이유로 문단 전체를 제외하지 않으므로, 뒤에 따로 나오는 `충을`·`자오충`·`묘유충`은 유지된다. 이 수정은 전체 단어 경계/의미 판별기가 아니며, 기존 지지충의 총칭 오분류는 후속 검토 대상으로 남는다.

측정은 기준 커밋의 실제 두 빌더와 수정한 두 빌더를 같은 입력으로 실행한다. 기존 개념지도 소스가 수정된 뉴런 코드를 잘못 불러 비교하지 않도록 전(前) 코드는 전(前) 뉴런 모듈에 연결한다. 입력이 비어 있거나 사전 내용이 달라지면 측정을 중단한다.

```bash
python docs/knowledge-model/foundation_review.py --check
python -m unittest discover -s docs/knowledge-model -p 'test_foundation_review.py' -v
python docs/knowledge-model/measure_general_terms.py --output /tmp/general-terms.json
SMOKE_CHROMIUM=/tmp/chromium npm run verify
```

신규 회귀는 실제 보충 원문, 반복 보충, 같은 문단의 실제 충 보존, 자오충/묘유충 보존, 오행·일지 보존, Unicode 정규화, 두 빌더의 배정 일치를 다룬다. 최종 전후 측정은 아래와 같다. 검색 변화는 해석 정확도나 확률 학습 결과가 아니다.

## 최종 측정과 검토 기록
