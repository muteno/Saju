# 문맥에 따라 관계가 달라지는 사주 지식망: 수학적 설계

작성일: 2026-09-22  
상태: 구현 방향 제안. 실행 가능한 첫 비교 모델은 `conditional_model.py`; PSL·factor graph·GATv2 전체 구현과 사주 예측 정확도 검증은 아직 수행하지 않았다.

## 1. 보존할 의도

키워드에 성격 문장을 하나씩 붙이는 사전을 넘어, **어떤 키워드들이 함께 있고 어느 위치·시점·대운·세운 문맥에 놓였는지에 따라 여러 해석의 지지도가 달라지는 구조**를 만든다. 옵시디언처럼 보이는 연결망은 이 구조를 이해하는 표현 방식이며, 옵시디언에서 파일을 열어 보는 것이 제품 목표는 아니다.

개별 키워드의 이름으로 결론을 정하지 않고 구성의 조합과 정도, 시점, 추가 관측을 함께 평가한다. 사용자 설명 중 예시는 원문 기록에 보존하며 이 문서의 규칙이나 학습 라벨로 삼지 않는다. 동시에 복수 해석이 성립할 수 있으며, 새로운 변수가 들어오면 추정값을 다시 계산한다. 문헌을 많이 모으는 목적은 조건·예외·경쟁하는 해석을 풍부하게 확보하는 데 있다.

다음은 이 프로젝트를 위해 제안하는 수학적 표현이다. 인용 논문들이 사주에 대한 예측 타당성을 검증했다는 뜻은 아니다.

## 2. 0~1로 표현하는 값의 의미를 구별한다

다음 값은 모두 0~1로 표현할 수 있지만 의미가 다르다.

| 값 | 질문 | 학습·검증에 필요한 것 |
|---|---|---|
| 추출 신뢰도 | 문장에서 이 관계를 제대로 추출했는가? | 사람이 검토한 문장과 관계 정답 |
| 문헌상 지지 | 이 조건에서 해당 해석을 출처가 지지하는가? | 조건이 명시된 문헌 주장과 반례, 출처 계보 |
| 개념 활성 정도 | 현재 입력에서 특정 속성을 어느 정도로 표현하는가? | 명시적인 측정·변환 규칙 |
| 해석 적합 확률 | 지정한 평가자가 이 해석을 적합하다고 평가할 가능성은? | 평가 기준이 고정된 독립 전문가 라벨 |
| 사건 발생 확률 | 정해진 기간에 관측 가능한 사건이 발생할 가능성은? | 실제 사건·비사건 기록, 관측 기간과 누락 여부 |

현재 자료만으로 우선 학습할 수 있는 대상은 개념·관계·문헌 주장이다. 문헌의 반복 횟수는 사건 발생 횟수가 아니다. 같은 저자의 블로그·영상·재인용을 여러 독립 관측으로 세지 않는다. 경험적 발생 확률이 필요한 단계에서는 별도의 결과 라벨과 검증 표본을 연결한다.

십신의 정의나 날짜 계산처럼 선택한 체계 안에서 결정되는 사실은 정확하게 계산한다. 해석을 연속적으로 표현한다는 이유로 모든 기초 정의에 임의의 불확실성을 넣을 필요는 없다.

## 3. 기본 식: 고정된 선이 아니라 문맥 함수

원국의 표현을 \(x\), 시점 \(t\)에서의 대운·세운 등 문맥을 \(c_t\), 해석 목표를 \(Y_k\), 학습 파라미터를 \(\theta\)라 두면:

\[
p_{k,t}=P(Y_k=1\mid x,c_t,\text{상호작용};\theta)
\]

`Y_k=1`은 목표 라벨의 정의다. 예컨대 ‘평가자가 이 해석을 적합하다고 판단함’일 수 있다. 출력 \(p_{k,t}\)는 0 또는 1로 강제하지 않는 연속값이다. 성향의 정도 자체를 목표로 삼는다면 향후 순서형·연속형 결과 모델을 별도로 정의한다.

관계 레코드에는 단일 숫자 `probability: 0.8`만 저장하지 않는다. 다음 항목이 필요하다.

```text
관계: 입력 개념들 → 목표 해석
조건: 위치, 동반 개념, 활성 정도, 대운/세운, 관측 시점
함수: 문맥에서 점수 또는 확률을 계산하는 방식
근거: 원문 위치, 저자 묶음, 지지 주장, 예외와 반대 주장
상태: 추출 후보 / 검토됨 / 학습됨 / 검증됨
불확실성: 미입력 변수, 표본 수, 검증 범위, 모델 버전
```

두 노드를 잇는 선만으로 충분하지 않은 관계는 **여러 입력이 함께 참여하는 요인(factor)** 으로 저장한다. 여러 개념과 시간 문맥이 함께 작용하는 조합을 하나의 관계로 표현할 수 있다. 이를 세 개의 독립적인 고정 확률로 쪼개 곱하면 원래의 조건을 잃는다.

## 4. 비교할 네 가지 접근

| 접근 | 표현하는 것 | 이 프로젝트에서의 용도 | 판단 |
|---|---|---|---|
| 상호작용을 포함한 로지스틱 모델 | 입력 및 조합별 점수를 합쳐 조건부 확률 계산 | 작은 자료에서 문맥 변화와 근거 기여를 확인 | 현재 실행 기준 모델 |
| 조건부 factor graph / Markov logic 계열 | 여러 변수와 고차 조합이 만드는 결합 분포 | 해석 사이 의존성·충돌·공통 조건을 함께 추론 | 첫 모델과 비교할 확장 후보 |
| PSL / HL-MRF | 연속 활성값과 가중 soft rule, 그 값들에 대한 확률 밀도 | 강약·부분 성립·규칙 충돌을 연속적으로 표현 | 문헌 규칙망에 유력한 비교 후보 |
| 문맥을 입력한 GATv2 | 입력 노드에 따라 달라지는 이웃 정보 가중 | 충분한 라벨 이후 복잡한 연결 패턴 학습 | 데이터가 축적된 뒤 검토 |

### 4.1 현재 실행 기준: 문맥과 상호작용을 포함한 로지스틱 모델

이 프로젝트의 제안식:

\[
p_{k,t}=\sigma\!\left(b_k+\sum_i w_{ki}x_i+\sum_j v_{kj}c_{t,j}
+\sum_r\gamma_{kr}\phi_r(x,c_t)\right),\qquad
\sigma(z)=\frac{1}{1+e^{-z}}.
\]

\(\phi_r\)는 문헌에서 추출한 조합 조건이다. 특정 입력값이 유지되더라도 동반 입력과 시점 조건이 바뀌면 이 항의 활성도가 달라진다. 세 개 이상의 입력을 묶는 상호작용도 가능하다. 계수를 새로 학습하지 않아도 문맥이 바뀌면 출력이 달라지고, 관측 자료가 축적되면 계수 자체를 다시 학습할 수 있다. 두 변화는 구분해 기록한다.

현재 `conditional_model.py`는 입력 활성도 0~1과 `null` 미상 상태를 받는다. 상호작용은 관련 활성도의 곱으로 구성하며, 이는 이 시범 모델이 선택한 결합 함수다. 그 곱을 ‘서로 독립인 사건 확률의 곱’으로 해석하지 않는다. 학습되지 않은 계수나 필수 미입력 값이 있으면 확률을 만들어 내지 않는다. 시연용 임의 계수는 명시적인 시연 옵션에서만 쓴다.

비배타적인 해석은 각각의 sigmoid 값으로 둔다. 독립적으로 출력한다는 구현 선택이 실제 해석들의 통계적 독립성을 입증하는 것은 아니다. 서로 배타적이고 빠짐없이 정의된 대안만 softmax로 정규화한다. 현 학습 함수는 비배타 후보의 이진 라벨 또는 명시된 연속 검토 라벨을 BCE로 학습한다. 연속 검토 점수의 평균을 학습할 때 그 값을 사건 확률로 동일시하지 않는다.

장점은 입력·조합별 기여를 확인할 수 있고 작게 시작할 수 있다는 점이다. 모든 조합을 자동 생성하면 파라미터가 폭증하므로, 초기에 근거가 있는 상호작용만 등록하고 규제·검증으로 복잡도를 통제한다. 로지스틱 확률 모델의 고전적 원자료는 [Cox, 1958](https://rss.onlinelibrary.wiley.com/doi/abs/10.1111/j.2517-6161.1958.tb00292.x)이다. 위 사주 변수와 조합 설계는 본 프로젝트의 제안이다.

### 4.2 조건부 factor graph: 조합 자체를 연결 단위로

제안하는 일반형:

\[
P(\mathbf{Y}\mid x,c_t)=\frac{1}{Z(x,c_t)}
\exp\!\left(\sum_r w_r f_r(\mathbf{Y}_{S_r},x,c_t)\right).
\]

요인 \(f_r\) 하나가 여러 해석과 입력을 동시에 참조할 수 있다. 여러 구성과 시간 문맥이 함께 있을 때 달라지는 효과나 두 해석의 충돌을 한 관계로 표현한다. \(w_r\)는 그 자체로 확률이 아니며, 전체 분포를 정규화하고 주변화해야 목표 확률을 얻는다.

[Kschischang·Frey·Loeliger의 factor graph 논문](https://www.mit.edu/~6.454/www_fall_2000/chanal/factor.pdf)은 함수의 분해 구조와 sum-product 메시지 전달을 다룬다. 순환 없는 구조와 순환 있는 구조의 추론 특성은 다르므로, 촘촘한 연결망의 계산 비용을 고려해야 한다. [Richardson·Domingos, 2006](https://homes.cs.washington.edu/~pedrod/papers/mlj05.pdf)의 Markov logic은 논리식에 가중치를 붙여 확률적 모델을 구성한다. 원자 명제가 이진이어도 그 명제에 대한 주변 확률은 연속적으로 달라질 수 있다. 이진 변수 사용 자체가 사용자에게 단정적인 답을 강제하는 것은 아니다.

### 4.3 PSL / HL-MRF: ‘부분적으로 성립한다’를 직접 표현

HL-MRF의 기본형은 \(y\in[0,1]^n\) 위의 밀도다.

\[
p(y\mid x)\propto\exp\!\left[-\sum_r w_r\{\max(\ell_r(y,x),0)\}^{q_r}\right],
\quad w_r\geq0,\quad q_r\in\{1,2\}.
\]

PSL은 이런 모델을 논리 규칙으로 작성하는 언어다. 참·거짓 사이의 정도와 규칙 위반을 연속적으로 다룬다는 점에서 사용자의 ‘무지개’ 표현과 접점이 있다. 단, **MAP 해로 얻은 노드 값 0.7은 자동으로 현실의 사건 확률 70%가 되지 않는다.** 값의 의미와 밀도의 의미를 별도로 정의해야 한다. [Bach 외, 2017, 원문](https://jmlr.org/papers/volume18/15-631/15-631.pdf).

이 프로젝트에서는 같은 검토 사례로 로지스틱 모델과 PSL을 비교하고, 부분 성립을 표현하는 장점이 실제 오류 감소·설명 가능성으로 이어지는지 확인한 뒤 도입한다. 이름에 ‘확률’이 있다고 바로 채택하지 않는다.

### 4.4 GATv2: 연결의 중요도를 입력마다 조정

[Brody·Alon·Yahav, ICLR 2022](https://arxiv.org/abs/2105.14491)는 기존 GAT의 제한을 분석하고 질의 노드에 따라 이웃의 중요도 순위가 달라질 수 있는 GATv2를 제안한다. 사주 적용은 별도 설계다. 원국·대운·세운 문맥을 노드 또는 메시지에 명시적으로 넣어야 하며, GATv2가 시간 문맥을 자동으로 알아내는 것은 아니다.

attention 값은 정보를 섞는 가중치다. ‘사건이 일어날 확률’이나 ‘이 근거가 진실일 확률’로 표시하지 않는다. 최종 해석용 출력층과 독립적인 확률 검증이 필요하다. 초기 자료가 대부분 문헌인 상황에서는 먼저 문헌 관계와 평가 라벨을 정리하는 편이 구현·검증 범위를 명확하게 한다.

## 5. 대운·세운과 추가 변수

한 사람의 여러 시점을 별개의 문맥 \(c_t\)로 표현한다. 입력에는 어떤 달력·절기·운 계산 정책을 사용했는지 버전을 남긴다. 대운 전환 전후 값을 비교할 수 있지만, 단순 전후 차이를 대운의 인과 효과로 부르지 않는다.

현재 구현은 이미 제공된 시점 특성을 조건으로 넣는 수준이다. 시계열 전체를 학습하는 동적 모형은 아직 아니다. 추후 충분한 연속 관측이 있으면 잠재 상태 \(z_t\)와 전이 \(P(z_t\mid z_{t-1},x,c_t)\)를 도입할 수 있다. 이 역시 사전 가정과 데이터 비교가 필요하다.

시각 미상, 모호한 강약, 불확실한 사건 시점은 0으로 채우지 않는다. 초기에는 결과를 보류하고 필요한 입력을 드러낸다. 후속 모델에서는 가능한 입력에 대한 분포를 정의한 뒤 주변화할 수 있다. 범위를 정하지 않은 ‘알 수 없음’에 임의의 숫자를 주지 않는다.

## 6. 데이터를 늘리는 경로와 평가

1. 블로그에서 개념·조건·예외·관계 주장을 먼저 추출한다. 저자·원문·위치·재인용 계보를 보존한다.
2. 전사본은 블로그의 조건을 보완하는 자료로 사용한다. 음성 인식 오류와 같은 저자의 반복 설명을 구분한다.
3. `원국 표현 + 시점 문맥 + 후보 해석 + 근거 + 평가자 판단`으로 검토 사례를 만든다. 미평가 사례는 부정 사례로 바꾸지 않는다.
4. 학습·검증·최종 평가 자료를 분리한다. 동일 인물의 여러 시점이나 동일 저자의 재인용이 서로 다른 분할에 섞이지 않게 한다. 시간 예측은 미래 정보를 입력에 포함하지 않는 별도의 시간 순서 평가를 한다.
5. 문헌 추출 정확도, 전문가 판단 예측, 실제 관측 결과 예측을 각각 보고한다. 세 성적을 하나의 ‘사주 정확도’로 합치지 않는다.

모델을 비교할 때는 기본 발생률만 쓰는 모델, 단일 키워드 모델, 상호작용 모델, 시간 문맥을 추가한 모델을 같은 평가 자료에서 비교한다. 추가 변수가 정확도를 높였는지는 이 비교로 판단한다. 더 많은 글이나 더 복잡한 그래프만으로 향상을 선언하지 않는다.

이진 목표에는 log loss와 Brier score를 사용하고, 예측 구간별 실제 라벨 비율을 함께 확인한다. 표본 수와 출처·시간 범위를 보고한다. [Guo 외, 2017](https://proceedings.mlr.press/v70/guo17a.html)은 모델 출력의 자신감과 실제 정답 빈도가 다를 수 있음을 다루며 온도 보정을 평가한다. 이 프로젝트에서 보정 방법은 별도 검증 자료로 비교하고 최종 평가 자료로 고르지 않는다. 보정만으로 잘못된 목표 정의나 편향된 표본을 해결할 수는 없다.

## 7. 구현 순서와 완료 기준

| 단계 | 만들어야 하는 결과 | 완료 기준 |
|---|---|---|
| 개념망 | 출처가 붙은 개념·관계·조합 조건 | 원문으로 역추적, 동의어·충돌·미상 구분 |
| 현재 기준 모델 | 문맥 + 상호작용 입력, 근거별 기여, 미학습 보류 | 시연 숫자와 학습 결과의 명확한 분리 |
| 검토 데이터 | 독립 평가 라벨과 출처·인물·시간 묶음 | 중복·누수 점검, 평가 기준 고정 |
| 모델 비교 | 로지스틱 대비 PSL 또는 factor graph | 분리된 평가 자료에서 개선 여부 확인 |
| 대규모 확장 | 필요할 때 GATv2 및 LLM 연결 | 단순 모델 대비 이득과 계산 비용 보고 |

LLM은 문헌의 관계 후보를 추출하고, 계산된 결과·근거·미입력 조건을 사용자에게 설명하는 역할부터 맡긴다. 정리되지 않은 문헌을 LLM에 넣고 답변에 퍼센트만 붙이는 구현은 이 아젠다의 완료 상태가 아니다.
