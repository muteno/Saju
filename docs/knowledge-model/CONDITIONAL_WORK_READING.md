# 조건부 일·재능 풀이 — 갑목 천간 재성·관성 비교

기준: PR226 병합 `dde2be8f9a9cfb07fdc19fd887e274ee02f5b26f`. 평가 시점은 2026-09-29. 아래 날짜는 성인이 되는 합성 달력 입력이며 실제 개인 사례·학습 정답이 아니다.

## 실제 실패와 이번 범위

기존 `contextReading.js`는 식신과 상관을 식상으로 묶었다. 양력 1980-02-11 04:00(경신·무인·갑인·병인)과 06:00(경신·무인·갑인·정묘)은 같은 갑인일주이며 강약 묶음도 신강이다. 두 입력의 핵심 ‘식상과 재성이 겉에서 함께 보여…’ 문장은 같았다. 천간 식신이 편관을 제어하는 설명 후보와 단순 식상 공존을 구별하지 못했다.

이번 구현은 **갑목 일간의 원국 천간 재성·정관/편관과 식신/겁재 합의 대응 조건** 한 묶음이다. 다른 일간에 원문 예시를 자동 일반화하지 않는다. 삼합·통근 강도·용신·대운·세운의 실제 작용은 미구현이며, 기존 미상/개인출력 보류를 해제하지 않는다. 원국 관찰·강약·지장간·충합파형 자료는 그대로 보존한다.

## 재사용 자료와 별도 구현 가정

- `data/foundation_claim_links.json`의 `generation_definition`, `generation_planes`를 참조했다. 정본 문맥은 `정제/원본/P0_인벤토리/webtxt_v1/사주공부-명리 중급 글모음.txt`의 994~1060줄, 특히 1021~1041의 갑목 천간 예시다. 재성→편관, 겁재의 합, 식신의 제어, 정관 문맥이 서로 다르다.
- `generation_hidden`과 `generation_year`의 기해일주/2020년 정묘 세운은 이 모델에 섞지 않는다. 천간 우선은 이번 관법의 범위이며 지지 해석 전부를 부정하지 않는다. 원본 주장 목록의 `inference_enabled=false`·원문 미상/보류는 변경하지 않는다.
- **구현 가정:** 세 천간의 기호 존재와 기존 천간합표로 비교할 후보를 고른다. 원문 예시의 길흉·폭력·성공 문장을 개인에게 전달하지 않는다. ‘과제 증가’, ‘직접 실행’, ‘역할 조율’이라는 생활 언어로 경험에서 비교할 가설을 만든다. 자리 인접성·계절·실제 힘·용신·합화의 성립을 전부 계산한 것이 아니다.
- 비교 순서는 점수 합산이 아니다. 필수 조건 미충족은 제외, 미상은 보류, 대응 조건이 있으면 단독 과제 증가 후보를 낮추고 대응 후보를 선택한다. 정관·편관이 모두 충족되면 동률 후보를 함께 남긴다. 반복 글자는 추가 점수로 세지 않는다.
- `context_query.py`의 참/거짓/미상 `all/any/not` 계약을 작은 JS 순수 함수로 옮겼다. Python과 같은 입력으로 직접 비교한다. 연구 코드 전체를 앱에 이식하거나 미학습 점수를 확률로 표시하지 않는다.

## 사용자에게 이어지는 경로

`buildContextReading → decision(후보별 조건/반대조건/판정) → blocks → ReportBundle → 일과 재능 카드/직업상담 근거/요약`으로 연결한다. 현재 대상 입력은 기존 넓은 계열 종합문을 후보별 핵심 해석·이유·대안으로 대체하고, 그 후보를 구별하는 질문 하나를 고른다. 강약·관계의 질문 문구는 내부 관찰 객체에 남지만 화면에서 모두 반복하지 않는다. 대상 밖은 기존 설명을 유지한다.

생성된 직업 답변에도 앱이 선택한 핵심·이유·대안과 질문을 유지한다. 앱 소유 질문은 하나이며 공급자가 별도의 질문을 만들거나 의역하는 기존 경로까지 전체 질문 하나로 제한한 것은 아니다. 모의 생성답변은 외부 공급자 의미 품질의 검증이 아니다. 외부 공급자 호출 없이 결정론 설명과 소비 계약을 검증한다. 자유 질문은 기존 대화 범위·재시도·미상 처리를 유지한다.

직업상담에서 방금 표시한 질문 하나에 명확하게 답한 경우만 로컬 수정한다. ‘맞아요/네’, ‘반대예요’, ‘경험이 없어요/경험 없어요’, ‘말하고 싶지 않아요/답하지 않을래요’를 구별한다. 앞선 질문과 현재 후보가 다르거나 복수 선택 질문·다른 주제·복합 자연어이거나 단순한 ‘아니요’이면 경험 없음과 반대 경험을 자동 분류하지 않고 기존 상담 경로로 보낸다. 고정 질문 뒤의 앱 소유 안내만 예외적으로 건너뛴다. 화면에 아직 표시되지 않은 질문은 대화에 없으므로 답의 대상으로 쓰지 않는다.

| 경험 답 | 수정 | 보존 |
|---|---|---|
| 일치 | 자기보고 범위에서 후보 유지 | 질문 전 후보/설명, 적중률 미측정 |
| 반대 | 후보 낮춤, 반대 경험을 명시 | 원국 관찰, 최초 풀이와 사후 수정의 차이 |
| 경험 없음 | 개인 적용 보류 | 경험 없음≠반례≠능력 부재 |
| 미응답 | 확인되지 않은 상태 유지 | 동의/반대로 바꾸지 않음 |

영구 경험 저장·복합 자연어의 구조화·개인 확률 학습은 하지 않는다. 이 수정 객체의 최초/사후 판단을 테스트하며 화면에는 수정 이유를 보여준다. 다음 일반 대화에는 화면에 보인 수정 문장이 기존 최근 대화로 전달된다.

## 검증과 한계

- 계산: 기존 계산 정책을 변경하지 않는다. 달력/엔진 필수 검사와 KB110 비교에서 계산·Brain·일진·정곡 및 생시미상8 전체동일을 확인한다. 달력 전체 범위의 독립 정확도 인증은 아니다.
- 조건: 참/거짓/미상 계약, 성인 달력 대조, 식신/상관 구별, 겁재 합, 후보 병존, 자리 범위·부재·무관 변화·중복·피드백과 원래 관찰의 보존을 검사한다.
- 완성 풀이: 결정론 핵심·이유·대안을 전후 문장과 화면에서 직접 검토한다. 실제 공급자 의미 품질·명리 전문가의 독립 평가는 미검증이다.
- 실제 개인 적중률: 미측정. 학습적격0, probability=null 유지. 관리9/20을 올리지 않는다.

PR225 당시7검사·원래 측정 해시는 그대로 두고 세 고유 소스의 최소 고정판으로 재현한다. 새 현재 검사는 위 조건과 실제 소비 경로를 별도로 검사한다. 과거 문구가 맞는지와 현재 후보 판단이 맞는지를 섞지 않는다. 전체 새 소스 사본은 추가하지 않는다.

최종 검사·독립 검토·전후 화면·병합 영수증은 이번 PR 본문이 정본이다. 다음 단일 실행은 `FOUNDATION_HANDOFF.md` §5.1을 따른다.
