## 2. 조건과 예외

- 정의의 대상은 일간만이 아니라 년·월·일·시의 각 천간이다. 같은 오행과 같은 글자를 구별한다. 8예시는 열 라벨이 없어 년월일시 순서를 새로 붙이지 않는다.
- 통근의 존재, 뿌리의 강도, 재관 등을 감당한다는 해석은 다른 층이다. 원문의 강약 비교와 장생/록왕·묘고/여기를 숫자 가중치로 바꾸지 않는다.
- 乙–戌·丁–丑은 해당 지장간에 같은 오행이 없다는 본문 예외다. 모든 음간의 통근을 부정하지 않는다. 다음 문단의 음간 장생 예외와 ‘뿌리가 명확하다면’ 단서까지 보존한다.
- 월령만으로 강약을 단정하거나 형충 개고가 있어야 묘고 뿌리를 쓴다는 이론에 대한 저자의 반론을 보존한다. 사공의 고전 인용·번역·의역·요약은 독립4지지가 아니다. 고전 원판·번역 정확도는 독립 검증하지 않았다.
- 수용/감당 문장의 역명제, 미상=무근, 무근=개인 실패, 통근=재관 존재/성공으로 바꾸지 않는다. 동주·인접·거리 임계값·발현 시점은 미확정이다. 생시 미상이나 지장간 판본 미정인 개인 입력을 이 자료로 계산하지 않는다.

## 4. 조회와 검증

```bash
python3 docs/knowledge-model/rooting_candidate_review.py --check
python3 docs/knowledge-model/rooting_candidate_review.py --candidate legacy_candidate_e6ae40a2c5f49866760a
python3 -m unittest discover -s docs/knowledge-model -p 'test_rooting_candidate_review.py'
python3 docs/knowledge-model/p2_d5_review.py --check
npm run verify
```

별도 읽기 전용 조회는 후보를 특정 원문과 연결하고 매번 전체 조건·예외·비교판본을 함께 반환한다. 기존 `knowledge_query.py`의 출력과 기본그래프58/132/11·조건8·출처조회10/52는 그대로다. 새 검사기는 검토판 canonical JSON, 입력 LF 정규화 해시, 원본 레코드, 글/문단 색인, DOCX 문단을 검증한다. 의미를 자동으로 판정하는 검사가 아니며 검토판 변경은 새 원문 검토와 명시적 판본 갱신이 필요하다.

신규11회귀는 필수 Python discover에 포함된다. 후보/출처/식신/그룹/개인적격 변조, 원문/DOCX 교체, 경로 탈출·CRLF·다른cwd/ASCII 콘솔, 결과 사본·읽기전용을 검사한다. 기존 D5 차단25/3과 면제1, 생시미상·강약교정·현침 보류 계약을 유지한다. `--check` 성공은 출처 검수 재현이며 개인 적용·학습 적격0, probability=null이다.

착수 전체 검사에서 Python240·앱17·실제 Chromium은 통과했지만 루트 dist 복사에 `File exists`가 발생해 전체는 실패했다. 과거 생성 폴더를 보존 이동한 뒤 같은 전체8게이트를 재실행해 통과했다(Python251·원국Node9·엔진19·앱17·실제Chromium, 보고된skip0). 최종 커밋 훅에서도 같은 복사 충돌로 커밋이 차단됐다. 실패 뒤 동일 rm/cp 단계를 따로 실행하면 성공하여 순간 충돌의 근본 원인은 확인하지 못했다. 생성폴더를 다시 보존 이동하고 동일 최종 훅을 재실행하며 실패를 통과로 세거나 코드/게이트를 완화하지 않는다. 최종 필수검사·원격 최신head·병합 영수증은 해당 PR을 따른다.

## 6. 다음 작업과 완료 범위

[기본 풀이 계획](BASIC_READING_PLAN.md)의 대표 문장 묶음을 시작한다. 60일주/402초안 전체를 한 번에 승인하지 않고, 기존 문장→원문→조건·예외·반론→실제 앱 출처 연결을 추적하는 형식을 먼저 검수한다. `basic_reading_findings.json`, `dosa-app/kb/distilled/ilju`, `report.js`, `app/src/data/saju.ts`를 대조해 오류 유형을 대표하는 작은 묶음을 선정한다. 원문이 없는 문장은 보류하고 기존 첫 출처 대표 부착을 문장별 근거로 오인하지 않는다.

통근4후보 검수만으로 완료기준13 전체를 채우지 않는다. [관리 진행률](PROJECT_PROGRESS.md)은 PR #208 병합 확인 기준 **9/20=45% 유지**다. F01/F02 잔여와 전체 계산정책·60일주·학습/평가는 미완료다. 원문·조건·해석의 근거 연결을 앞으로의 앱 적용 전제에 포함한다.
