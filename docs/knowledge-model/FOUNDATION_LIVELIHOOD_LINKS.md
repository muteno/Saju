조건표는 도화로운 원문1932–1955행의 진술이다. 다음 표에서 추가 천간은 기본 해당 조건과 별개다. 지지는 특정 주로, 천간은 특정 자리나 거리에 한정하지 않는다. 비교는 원문의 해당 지지/추가천간을 설명한 ‘이 경우’ 범위로 남긴다.

| 일간 선택지 | 지지 글자 | 강한 발현을 설명하는 추가 천간 | 더 유효하다는 일간 비교 |
|---|---|---|---|
| 甲·乙 | 辰 | 戊 | 미명시 |
| 丙·丁 | 丑 | 辛 | 丁 |
| 戊·己 | 丑 | 癸 | 己 |
| 庚·辛 | 未 | 乙 | 辛 |
| 壬·癸 | 戌 | 丁 | 癸 |

`야쟈시 적용X`는 출처의 입력 지시로 조회된다. 앱의 자시 정책으로 채택하지 않으며 수치·확률·운 적용은 미명시다. 원문 좌표의 화면 방향이나 ‘일주’ 소제목만으로 새로운 자리 제한을 만들지 않는다.

직업·신신병존·노력·좋은 운·재성입묘·묘지·시지·화개·입묘·형·합거 등 기본노드에 없는 항목은 이름과 역할, `node_id=null`을 보존한다. 대응 노드 신설과 전역 별칭 추가는0개다. 기본 `충` 노드는 지지 충이며 화개 토의 경계와 인접 丑/未 예시 문맥에 한해 참여개념으로 연결했다. 조건 성립을 판정한 것이 아니다.

## 3. 구현과 보존 계약

- 기존 `foundation_claim_links.json`·schema3·여섯 주제 ClaimIndex는 바이트 그대로다. 새 schema1 catalog/검증기를 `foundation_claims.load_index()`에서 합성한다. 실패한 입력은 조용히 `not_found`로 돌아가지 않는다.
- 주제/주장 ID·출처·참여자/역할/null·다섯 조건표와 해당 연결노드를 유한 검수 계약으로 고정한다. 원문과 판정 파일 해시, 원문 줄·인용·그래프 식별도 검증한다.
- 공통 참여개념은 해당 두 조회 결과를 합친다. 반환된 다른 참여개념을 다시 따라가지 않는다. 예를 들어 일간은 관살혼잡+재고귀인이고, 그 결과에 신금이 있어도 활인업을 연쇄로 끌어오지 않는다.
- 과거 여섯 주제의 원래 회귀21개는 기존 ClaimIndex에 같은 기대값을 유지한다. 신규9개는 실제 기본 loader/CLI·공유조회·186기본조회·기존6주제 동일·조건표·미연결·원문 변조·비활성·반환본 독립성을 검증한다.
- 자연어 설명의 의미를 코드가 완전 판정하지는 않는다. 조건/예외 문장 수정은 원문 검수와 회귀 갱신이 필요하며, 구조 검사가 정확도 인증은 아니다.

### 원격 저장 제약

자동 승인 검토의 파일 공개 제한으로 기존 `dosa-app/STATUS.md`와 `WORK_CHECKPOINT.md`는 기준본 그대로 둔다. 이번 세션만 담은 별도 체크포인트도 운영 기록·로컬 경로·브랜치·검증 기록의 공개 승인 확인이 필요하다는 사유로 거절되어 원격 변경에서 제외하고 로컬에 보류한다. 거절된 파일은 재시도하거나 다른 경로로 보내지 않는다. 기존 이력 파일 갱신 규칙은 변경하지 않았으며 이번에는 해당 항목이 미이행이다. 기능/자료와 검증 결과의 변경은 없다.

## 6. 다음 재개점

**진도화·가도화**의 정의·자리/시간/발현·저자별 이견부터 검수한다. 기존 우선6판정의 두 행과 근거를 읽고, 사공의 미사용/출처미상 기준·자미두수 언급을 사주 규칙으로 합치지 않는다. 기존8주제·186기본조회·검색282개를 보존하고 없는 참여개념은 미연결로 남긴다.

활인업·재고귀인의 원국 적용·직업/재물 결과·강도 수치·좋은 운 기간·ASR 교정은 후속 근거가 필요한 보류다. F01 의미 검수, F03 강약/자시/자리·시간 판본, F04 P2 12개·D5 인용 자격, 기본 풀이·실제 학습/보정은 아직 남아 있다. 전체 프로젝트 완료로 해석하지 않는다.
