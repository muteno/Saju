# F01 지장간 겹침 수정 → 여기·중기·정기 검수

2026-09-23 · 기준 main `13255abe7512e7ac265a4cc3ec3814f2de11aa36` (PR #188).

자리 별칭과 지장간 표기가 한 글자를 공유할 때 두 개념을 함께 보존한다. 단계 명칭은 정의·부재·부정·일상어·문헌 수치의 차이를 검수했다. 이는 기존 주제 검색의 보강이며 관계 판정이나 학습 결과가 아니다.

## 1. 지장간 겹침의 최소 수정

기존 뉴런 검색은 `시지장간`에서 `시지`, `연월지장 간`에서 `월지`를 먼저 소비한다. 다음 검색이 소비한 구간 뒤에서 시작해 겹치는 `지장간/지장 간`을 놓쳤다. 원문은 검토 자료의 `hidden_overlap_hour_branch`·`hidden_overlap_month_branch`에 있다.

`build_neuron_map.py`는 수락한 자리 별칭 `연지/년지/월지/일지/시지`의 마지막 ‘지’에서 두 기존 지장간 표기를 확인해 함께 회수한다. 사전의 실제 등록값을 사용하며 새 별칭이나 문단 ID 예외는 추가하지 않는다. 다른 별칭의 겹침 우선순위는 그대로다. 개념지도는 원래 각각 검색하므로 변경하지 않았다.

원문2구절은 동일 영상의 중복 사본까지 포함해4행이다. 자리·정인·오행 등 이미 찾던 개념을 지우지 않는지, 다섯 자리·두 표기·NFD 입력과 부정문·유사 문자열을 회귀 검사한다. 부정문에서 지장간을 찾는 것은 주제의 언급이며 실제 포함/관계가 참이라는 판정이 아니다.

## 2. 명칭·단계·구성을 구분

원문 위치·해시·인용은 [검토 자료](data/foundation_taxonomy_review.json)에 있다. 보드는 보존 추출본이며 현재 Figma를 새로 동기화하지 않았다. 줄 번호는 검사기의 `str.splitlines()` 기준이다.

| 근거 ID | 확인한 내용 | 적용 범위 |
|---|---|---|
| `hidden_board_chen` | 진의 을/계/무를 여기/중기/정기로 구분하고 고지의 투출 강도 순서를 설명 | 특정 구분의 문헌 주장. 모든 지지의 보편 가중치로 확대하지 않음 |
| `hidden_hyeonmyo_stages` | 초기(여기)·중기·정기(본기), 정기가 해당 지지를 대표한다는 설명 | 명칭 대응과 단계 역할을 보존. 세 단계를 같은 뜻으로 합치지 않음 |
| `stages_choco_names` | 여기는 이전 달의 기운, 중기는 초기와 정기 사이, 본기는 지지를 대표하는 기운이라고 설명 | 초기↔여기, 정기↔본기와 한자 餘氣/本氣 확인 |
| `candidate_054`·`stages_zi_no_middle` | 자의 임/계와 초기10일·중기 없음·정기20일, 正氣 표기 | ‘중기’가 검색돼도 실제 구성에 중기가 있다는 뜻이 아님 |
| `stages_negated_exposure` | 초기 무토·중기 임수·정기 경금이 투관하지 않았다는 전사 | 단계 언급과 투간/투출의 부정을 함께 보존. 원문 표기를 교정하지 않음 |

현재 `여기·중기·정기`는 다섯 표현 `여기/중기/정기/본기/正氣`를 찾는 하나의 검색 묶음이다. 역할이 다른 세 단계를 의미 동의어로 승인한 것이 아니다. 엔진 `HIDDEN_STEMS`의 마지막 원소가 본기라는 계약은 유지한다. 두 원소 목록에서 두 번째를 무조건 중기로 해석하면 자의 ‘중기 없음’과 충돌한다. 단계별 구조화에는 빠진 단계와 실제 구성의 구분이 필요하다.

`초기/餘氣/本氣`는 이번에 전역 별칭으로 추가하지 않는다. 원문에서 명칭 대응이 확인돼도 `초기`의 모든 발생이 지장간을 뜻하지 않으며, 현재 검색되지 않는 행 수는 곧바로 누락 정답 수가 아니다.

## 3. 같은 글의 수치도 그대로 합치지 않음

초코서당은 인월을30일로 보고 초기7일·중기7일·정기16일을 설명한다(`stages_choco_in_period`). 이어지는 작용력과 문말의 기간 요약을 구별해 보존한다.

| 같은 원문의 위치 | 실제 서술 | 처리 |
|---|---|---|
| `stages_choco_myo_ratio` | 묘의 초기33%·정기67% | 저자가 제시한 작용력 |
| `stages_choco_wang_ratio` | 묘·유·자의 초기30%·정기60%, 뒤에서는 오를33/30/37%로 구분 | 앞의 묘 비율과 불일치하며30+60은90. 임의로33/67이나30/70으로 교정하지 않음 |
| `stages_choco_period_summary` | 생지7/7/16일, 왕지10/20일, 고지9/3/18일 | 앞서 명시된 오의 예외와 함께 읽어야 하는 요약. 왕지 전부가 두 단계라고 확정하지 않음 |

이는 원문의 내부 불일치를 확인한 것이며 어느 수치가 정답인지 결정한 결과가 아니다. 기간·구성·작용력·투출 강도·학습 확률은 구별한다. 엔진 정본이나 관찰 어댑터를 수정하지 않았고, 월률분야·사령/F03의 계산 판본 검토로 연결한다.

## 4. 기존 문맥 필터의 오탐과 혼합 용례

`여기/정기/본기`는 문단 어디에든 다른 단계 명칭이나 지장간 등이 있으면 통과한다. `중기/正氣`에는 이 동반어 필터가 없다. 동반어도 부분문자로 검사하므로 일상어끼리 서로 조건을 충족할 수 있다.

| 근거 ID · 문단 | 검수 결과 | 필요한 구분 |
|---|---|---|
| `stages_periodic_here` · `CT-P005-07` | 자동차 관리 비유의 ‘정기적으로’와 ‘여기저기’가 서로 통과 조건이 됨 | 定期와 위치 표현은 지장간 단계가 아님 |
| `stages_emotion_here` · `ST-P0589-08` | ‘감정기복’의 정기와 위치 표현 여기가 함께 등장 | 사주 문맥이 있어도 그 부분문자는 正氣가 아님 |
| `stages_basic_here` · `DR-P625-07` | ‘여기서’와 실력의 ‘기본기’가 서로 조건을 충족 | 기본기의 본기는 本氣가 아님 |
| `stages_historical_middle` · `PL-SINSAL-P001-03` | 조선 중기 승려에 관한 서술 | 역사 시기의 중기는 단계가 아님 |
| `stages_historical_food` · `PL-JEOLGI-P014-03` | 조선 중기 문신과 추어탕 풍습 | 절기 글이라는 이유로 지장간 단계로 판정하지 않음 |
| `stages_mixed_here_middle` · `CT-P024-09` | 위치 표현 ‘여기서’와 실제 진토의 중기가 같은 문단에 있음 | 일상어가 있다고 문단 전체를 제외하면 실제 중기도 잃음 |

이 표는 실제 자료에서 확인한 사례이며 전체 검색 결과의 정밀도 추정이 아니다. 진토의 중기 전사에는 ‘개수/지장관’ 등의 표기가 있다. 문맥상 단계 논의는 확인했지만 음원 확인 없이 원문을 교정하지 않았다.

양쪽 빌더의 단계 검색 차이3행도 살폈다. 뉴런 검색이 먼저 `신중`을 소비해 뒤의 `중기` 부분문자를 가리는 경우다. `T-f0c939c1de-0002`·`T-09ccdde215-0001`의 ‘신중기도’는 종교적 문맥이며, `T-3b2e8d06e5-0000`의 ‘신중기현’은 별도 확인이 필요한 전사다. 근거는 `stages_prayer_overlap_one/two`·`stages_unverified_transcription_overlap`이다. 지장간4행과 달리 이3행을 실제 단계 누락으로 확정하거나 겹침 복구를 확대하지 않는다.

기존 별칭 삭제나 동반어 필터의 전역 축소는 이번에 적용하지 않는다. 단어 내부의 본기/정기를 제외해도 동반어 검사에 그 부분문자가 남으면 ‘여기’가 계속 통과하므로 두 경로를 함께 검토해야 한다. 후속 수정 조건은 **발생 위치마다 실제 단계 표기와 동반어를 확인하고, 일상어만 있는 문단·실제 단계와 섞인 문단·중기 없음·투간 부정을 모두 보존하는 비교표**다. 명백한 반례를 학습 정답으로 바꾸지 않고 재검수 대상으로 남긴다.

## 5. 전후 전체 측정과 검사

[재현 스크립트](measure_hidden_stages.py)는 기준판의 두 빌더·사전·필터와 현재판을 각각 읽고 동일 고정 코퍼스에서 모든 개념의 문단 ID 변화를 비교한다. 입력은 제목 포함·gist 제외이며 중복 사본을 독립 증거로 세지 않는다. 과거 PR #188의 측정 파일과 해시 검사는 유지한다.

[측정 결과](data/foundation_hidden_stages_measurement.json)는 **56,202행(웹21,251·전사34,951)**에서 다음을 확인했다. 전체271개 개념을 비교했고, 복구된4행 이외의 변화는 없다.

| 검색 | 뉴런 전 → 후 | 개념지도 전 → 후 |
|---|---:|---:|
| 지장간 | 3,682 → 3,686 | 3,686 → 3,686 |
| 여기·중기·정기 | 2,164 → 2,164 | 2,167 → 2,167 |
| 다른 개념의 문단 ID 변화 | 0 | 0 |
| 기존 문단 제거 | 0 | 0 |

지장간 추가 ID는 `ST-P1078-05`, `ST-P1078-10`, `T-53ebbe2d99-0000`, `T-53ebbe2d99-0003`이며 현재 두 검색기의 지장간 ID 집합이 같다. 단계 명칭의3행 차이는 위에서 검수한 기존 차이로 남는다.

| 단계 표현 | 부분문자 포함 행 | 기존 문단 동반어 조건 통과 행 |
|---|---:|---:|
| 여기 | 17,876 | 1,855 |
| 중기 | 443 | 443 (필터 없음) |
| 정기 | 651 | 415 |
| 본기 | 175 | 136 |
| 正氣 | 71 | 71 (필터 없음) |

같은 문단이 여러 표현에 포함되므로 합산하지 않는다. 이 표는 별칭의 문자/동반어 관측 수로, 겹침 처리를 마친 실제 노드 수나 의미 정답 수와 다르다. 미등록 `초기` 포함456행 중 현재 두 빌더가 단계 노드로 찾지 않는 행은138개다. 뜻이 다른 사례를 포함할 수 있어 추가 대상138개라고 확정하지 않았다. `餘氣`8행과 `本氣`5행은 모두 기존 표현을 통해 검색된다.

근거16구간을 더해151구간, 판정76·사전271·누적 적용 별칭4를 유지한다. 기준 및 중간 커밋 훅의 실제 Chromium 포함 필수8단계·Python132개(F01 22개)가 통과했다. 중간 검수 당시148구간 이후 차이3행의 근거를 추가했다. 최종 커밋 훅·최신 원격 head 검사·병합·main 일치는 [PR #189](https://github.com/muteno/Saju/pull/189) 영수증과 [체크포인트](WORK_CHECKPOINT.md)를 확인한다. 아직 끝나지 않은 절차를 성공으로 기록하지 않는다.

```bash

python3 docs/knowledge-model/foundation_review.py --check
python3 -m unittest discover -s docs/knowledge-model -p 'test_foundation_review.py'
SMOKE_CHROMIUM=/실제/브라우저/경로 npm run verify
```

새 체크아웃의 입력 생성은 [통근 문서의 명령](FOUNDATION_ROOTING.md#새-체크아웃에서-다시-측정)을 따른다. 다음 본문 검수는 월률분야·사령이며, 이 문서의 단계별 오탐 수정 조건도 인계한다. 사전271·판정76·누적 별칭4·학습 적격0·확률null을 유지한다.
