## 해석 이력 — 사용자 원문과 구별

- 초기 보조 구현은 천간·십신의 계산 규칙에 먼저 집중했다. 사용자는 기본 지식을 추린 뒤 관계망을 만드는 순서를 설명했다.
- 보조 작업이 옵시디언 파일 형식에 집중하자 사용자는 지식망의 형태를 비유한 것이라고 정정했다. 옵시디언 앱 사용은 요구사항이 아니다.
- 고정 간선 가중치로 이해할 여지가 있었으나 사용자는 주변 키워드 조합에 따라 매번 달라지는 관계 확률을 강조했다.
- 사용자는 연속적인 정도와 확률, 추가 변수, 대운 등 시간 맥락, 축적 문헌을 이용한 개선을 연결해서 설명했다.
- 11번 발언은 앞선 예시와 표현에도 모순 가능성이 있으므로 예시를 규칙으로 확정하지 말고, 개념적 의도와 이전 발언 전체를 보존하라는 요청이다.
- 조건부 로지스틱, PSL, 요인 그래프, GATv2, 활성값 표현, 평가 절차는 이를 구현하기 위한 보조자의 제안이다. 사용자 확정 지시나 유일한 정답으로 취급하지 않는다.

## 이어 쓰기 규칙

새로운 발언은 다음 번호로 추가한다. 기존 원문은 오탈자를 포함해 수정하지 않는다. 변경된 이해는 별도 해석 이력에 적고, 무엇이 사용자 발언이며 무엇이 구현자의 가정인지 표시한다. 해결되지 않은 모순을 임의로 단일한 규칙으로 합치지 않는다.
