## 기본 풀이 카드로 이어가는 기준

기초 카드는 개념 정의, 입력에서 확인한 구조, 조건부 해석 후보, 출처, 반론·미상, 검수 상태를 구별한다. 이번 live 참조는 그중 개념의 범위·설명·원문 위치를 보완한다.

- 음양은 기존 블로그의 상대성·대립·조화 정의를 사용하고 도식의 성향 단어를 개인 특성으로 자동 연결하지 않는다.
- 십신은 일간과 비교한 관계명과 분류 이유를 설명한다. 천간·지지 본기·개별 지장간 중 계산 대상을 남긴다.
- 인성은 생하는 관계와 편인·정인 구분을 설명한다. 존재나 수량을 유리함 또는 성향의 강도로 바로 변환하지 않는다.
- 지장간은 검수된 구성과 적용 범위를 설명한다. 순서·위치·표의 숫자를 작용 확률로 간주하지 않는다.

보드가 기본 개념의 기준 자료라는 사용자 지시는 유지한다. 동시에 보드는 운영자가 편집한 자료이므로 블로그·영상의 재인용을 독립 근거로 중복 가산하지 않는다. 원출처 계보를 확인하기 전까지 live 참조를 독립된 근거로 집계하지 않으며, 새 확률값을 부여하지 않았다.

### 조회와 재현

이 디렉터리에서 다음과 같이 조회한다.

```bash
python build_graph.py
python knowledge_query.py 십신
python knowledge_query.py 십신 --diagram-context
python -m unittest discover -p 'test_*.py'
```

기본 조회는 블로그·이전 보드·현재 보드 참조를 각각 반환한다. `--diagram-context`는 인용 노드에 직접 붙은 선(`direct_node_attachment`)과 인용된 섹션 안의 도식(`cited_section_context`)을 구분해서 보여준다. 같은 섹션에 있다는 이유로 개념 간 의미 관계로 추가하지 않는다. 서로 다른 스냅샷을 섞으면 조회를 중단한다.

새 보드 내보내기를 가져올 때는 `figma_ingest.py RAW_XML --board-key SEEnsqUToHwgVY5QZnYLeU --fetched-at YYYY-MM-DD --connector-details CONNECTOR_API_JSON`으로 구조를 재생성할 수 있다. 보드의 기초·심화 root ID가 바뀌면 허용 범위를 먼저 검토한다. 전체 원문은 출력 데이터에 포함하지 않는다. 검수 인용도 새 스냅샷과 대조한 뒤 `build_graph.py`를 실행해야 한다.

파서·조회 테스트 13개와 기존 연구 시제품 24개가 통과했다. 범위 밖 노드, 누락 끝점, 화살표 방향, 표 좌표, API 불일치, 스냅샷 혼용, 동음이의어와 문맥 선의 구분을 확인했다. 기본 풀이 앱의 새 성향 알고리즘이나 확률 학습을 완료한 결과는 아니다.
