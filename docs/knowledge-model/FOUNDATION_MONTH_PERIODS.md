# F03 월률분야·사령 기간 판본 검수

2026-09-28 · 기준 main `b83f8de4cd74c34a549644607f3789e58e7b90af` (PR #204).

원문23구간을 대조해 **기간3판본·작용력3표기·월지 밖 구성표**를 분리했다. 개인의 사령을 계산하는 정책은 보류한다. 사령/당령/득령, 기간/구성/작용력/학습 확률은 서로 다른 값이다. 기존 앱·연구 원국 계산·검색·문헌 판정은 수정하지 않았다.

자료: [검수 원문과 판정](data/foundation_month_period_review.json), [재현 비교](data/foundation_month_period_measurement.json), [검증/비교 CLI](month_period_review.py). 보존된 보드·웹·전사를 읽었으며 최신 Figma/웹 재수집이나 고서 전수 검수는 아니다. 같은 저자의 표와 서술을 독립 출처의 다수결로 세지 않는다.

근거 줄 번호는 기존 판정과 같은 **Python `str.splitlines()`의1부터 시작하는 좌표**다. 보드의 Unicode 줄 구분자도 세므로 GitHub의 LF 줄 번호와 다를 수 있다. `line_policy`를 명시하며 실제 구간·인용·전체 파일 해시를 함께 검증한다.

## 1. 원문과 판본

| 판본 | 확인한 내용 | 남는 한계 |
|---|---|---|
| 보드 `month_board_scope` | 월지 사령의 해당 지장간 기간과 욕지 제한 | 해당 구간에 기간표·절대시각 계산법 없음 |
| 사공 표 `period_sagong_table` | 12지지·33개 지장간/일수 칸. 중기 공란3개 유지 | 오10/9/11은 같은 글의10/10/10과 충돌 |
| 사공 서술 `month_sagong_scope/wu_table` | 생지7/7/16·왕지10/20·고지9/3/18, 오10/10/10 | 단계 길이만 비교. 표의 천간을 서술에 자동 복사하지 않음 |

| 석우당 전사 `month_mixed_solstice` | 동지 전 임/후 계 | 음원 미검수. 동지 순간 포함과10/20일 표의 동일성 미상 |

사공 원문은 2023-07-14의 **책 초고**이고 저자도 미정리 상태를 밝힌다. 82행 오의 두 단계 설명과 뒤의 세 단계 표/서술도 충돌한다. 초코의 1985년9월4일 신월 예시는 경금을 한 곳에서는 중기, 다른 곳에서는 정기로 부른다. 이 불일치를 출처 보정 없이 하나로 통일하지 않았다.

사공의 사령은 날짜별 글자, 당령은 그 글자가 천간에 드러나는 조건, 득령은 일간을 돕는 월지 정기다. 초코는 같은 천간이 있을 때 사령/당령이라고 함께 설명하고 기계적인 날짜별 영향력에는 반대한다. 보드의 엄격한 득령 조건도 별도로 남긴다.

## 2. 계산 경계: 확인된 것과 보류한 것

| 항목 | 직접 확인 | 개인 계산 정책 |
|---|---|---|
| 기준 길이 | 두 글 모두 한 달30일 | 실제 절기간 길이를30일로 바꾸는 방법 미상 |
| 절입 예시 | 초코는1985년8/7 오전8시~9/8 오후2시라고 적음 | 명시 시간대·절대UTC·시각 근거 미상. 실제 천문값 검증 아님 |
| 달력 예시 | 사공은22년9/8~10/7을 술월/한로~입동으로 서술 | 원문 날짜/절기 명칭을 보존. 외부 역서 대조와 교정 미실시 |
| 경과일 기산 | 사공의9/8~16,17~19,20~10/7은 날짜 예시 | 첫날 포함 예시는 있지만 일반적인 절입순간/자정·시간 소수 처리 규칙은 확정 불가 |
| 내부 경계 | 기간의 누적 합만 계산 가능 | 경계 순간을 앞/뒤 어디에 넣는지 미상 |
| 0·30 및 초과 | 정규화 정책 없음 | 이전/다음 월 연결·실제30일 초과 처리 보류 |

데이터의 여섯 `boundary_policy` 값은 모두 `null`이다. 이는 자료에 시간 설명이 전혀 없다는 뜻이 아니라 **완전한 실행 정책을 확정하지 못했다는 뜻**이다. 실제 출생 절대시각을 넣는 기능은 없다. 다음 검수에서는 시간대가 명시된 역서·판본별 기산법·경계 포함·30일 환산/초과 처리를 출처별로 먼저 확보해야 한다. 후보 개수는 확률의 분모가 아니다.

## 3. 같은 합성 입력으로 판본 차이 재현

실제 생년월일 대신 **구현자가 정한0~30 누적 길이 좌표**를 사용한다. 출력의 `axis=synthetic_30_day_offset_not_birth_time`은 실제 절입 이후 경과일이 아님을 명시한다. 생지=寅巳申亥·왕지=子午卯酉·고지=丑辰未戌의 비교용 배치를 쓴다. 서술판은 단계만 반환하며 사공 표의 천간을 다른 판본에 채우지 않는다.

| 午 합성 좌표 | 사공 표10/9/11 | 사공/초코 서술10/10/10 |
|---|---|---|
| 18.9 | 중기(己) | 중기(천간 미연결) |
| 19 | 중기/정기 양쪽 | 중기 |
| 19.5 | 정기(丁) | 중기 |
| 20 | 정기(丁) | 중기/정기 양쪽 |
| 0 또는30 | 바깥 경계 보류 | 바깥 경계 보류 |

내부 경계에서 양쪽을 반환하는 것도 출처의 확정 규칙이 아니라 비교용 보류 방식이다. 내부에서는 한 단계가 나와도 `personal_application=withheld`, `inference_enabled=false`, `probability=null`, `use_as_training_labels=false`가 유지된다. 새로운 사령 해석·득령 판단·학습 사례가 아니다.

12지지×26합성좌표 = **312행**, 원문23구간/주장11개를 기록했다. 검증은 원문 LF해시·구간/인용·출처 연결·과거 입력 해시, 표의 공란·합계, 오의 충돌, 묘의 합90, 소수 경계·잘못된 입력·정책 임의 승격 차단을 확인한다. 자연어 주장의 완전한 의미 검수와 고서의 정답 인증을 자동화한 것은 아니다.

## 4. 재현·검사와 다음 작업

```bash
python3 docs/knowledge-model/month_period_review.py --check
python3 docs/knowledge-model/month_period_review.py --branch 午 --synthetic-offset 19.5
python3 -m unittest discover -s docs/knowledge-model -p 'test_month_period_review.py' -v
npm run verify
```

새10회귀는 기존 Python 자동 발견으로 필수1번 게이트에서 실행된다. 원문·판본·코드가 바뀌면 `--check`가 실패한다. 과거 F03·시간대·소비48행·자리교정 측정은 변경하지 않고 새 판본에 별도 입력 해시를 담았다. `--write-measurement`로 과거 사실을 무심코 덮지 말고 변경 계약을 먼저 검수한다.

기준 검사에서 Python210·앱16은 통과했으나 기존 dist 충돌과 비어 있는 임시 브라우저 때문에 전체 exit1이었다. dist는 임시 경로로 보존 이동했고 실제 Chromium153·시스템 글꼴 설정으로 스모크를 통과했다. 검사기·앱 수정이나 게이트 생략은 하지 않았다. 최종 전체검사·독립검토·병합 영수증은 이 작업 PR에서 확인한다.

다음은 [인계 §5.1](FOUNDATION_HANDOFF.md)의 **현침살 판본·자리/발현 조건 검수**다. 기간 정책의 보류를 해소한 것으로 세지 않는다. 미상 보류, 강약 자리배점 계약, F01/F02 잔여·F04 P2/D5·기본풀이·실제학습은 유지한다.
