## 3. 구현·검증

기존 여섯 주제 catalog와 활인업·재고귀인 catalog/검증기는 동결했다. 기본 loader가 세 번째 층을 합성하며 catalog 누락이나 구조·출처·그래프 바인딩 변조는 오류로 중단한다. 자연어 설명의 의미 변경을 자동으로 차단하는 검사는 아니다. 주장마다 체계·출처상태·조건·예외·자리·시간·미상을 반환한다. 명시 anchor만 선택하고 반환된 다른 참여개념을 따라 연쇄 확장하지 않는다.

[전후 측정](data/foundation_peach_measurement.json)은 기준 commit의 실제 loader와 현재 loader를 동일 입력에서 호출한다. 기본186조회 본문 변화0, 기존8주제 ID/명칭16조회 전체동일, 공유조회에서도42주장과 판정·인용 순서 보존. 83개 기본 용어에는 새 주제 문맥만 추가됐다. 동결42파일과 원문 해시를 비교했다. 두 검색기가 바이트 동일이므로 전체 언급 코퍼스의 검색 재측정은 하지 않는다.

이전 claims21개와 livelihood9개 회귀는 원래 인덱스와 기대값을 유지한다. 새9개 회귀가 실제 기본 loader/CLI의 기존8주제·186조회 보존, 공유문맥 중복 방지, 출처별 표·미상·체계, 변조·누락·반환복사를 검증한다. 보드 열 범위는 독립 검토 지적을 반영한 추가 단언으로 검사한다. 자연어 의미를 완전 자동 인증하는 검사는 아니다.

```bash
python3 docs/knowledge-model/foundation_claims.py
python3 docs/knowledge-model/knowledge_query.py 진도화
python3 docs/knowledge-model/knowledge_query.py 가도화 --diagram-context
python3 -m unittest discover -s docs/knowledge-model -p 'test_foundation*.py'
python3 docs/knowledge-model/measure_peach_links.py
npm run verify
```
