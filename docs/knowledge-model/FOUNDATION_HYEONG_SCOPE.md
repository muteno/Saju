# 부분형·삼형의 전체 참여 자리 풀이

## 목적과 변경

사용자 원문83, 상시 목표71~73에 따라 생년월일시 입력이 바꾸는 실제 설명을 개선한다. 기준은 PR #224 merged/main `e7388c8f41b3f466f2a3cafb085c4f0140ded18e`, tree `4f87b07413a8b5b8f0236063482dcef3feba84eb`다. 같은 tree의 로컬 기준 commit은 `6b1825040ee3e7eb426fa464f89de9ec0f5c9055`이며 GitHub 병합 commit과 혼동하지 않는다.

기존 관계 목록에는 부분형/삼형이 있었지만 종합문에는 월일 충·육합·육합+파만 연결돼 있었다. `contextReading.js`의 `monthDayHyeong`은 기존 `detectRelations`에서 **월·일 두 자리가 모두 참여하는 부분형/삼형** 한 관계를 읽고, 실제 참여한 연·월·일·시 지지의 글자·본기·십신·주제를 모두 전달한다. `natal-work-context-v9`이며 관계표·강약점수·계산정책은 변경하지 않는다. 두 삼형 계열은 서로 겹치지 않으므로 월일이 모두 참여하는 대상은 최대 하나다.

부분/완전 여부는 기존 `partial` 판정을 따른다. 참여자리는 연→월→일→시로 설명하되 원래 relation.positions는 그대로 둔다. 같은 글자가 반복돼 자리가 세 개나 네 개여도 글자 종류가 두 가지면 부분형이다. 월일 같은 글자 역시 제3자리와 전체 관계를 이루면 전체 참여 범위로 읽으며 월일만의 독립형으로 표현하지 않는다. 자묘형·자형과 월일 중 한 자리만 포함한 형의 새 종합 설명은 이번 범위 밖이다.

## 실제 입력에서 달라진 깊이

모두 양력·여성·진태양시보정 끔·정자시 익일 전환 끔인 합성 검사용 입력이다. 실제 개인의 관측 정답이 아니다.

| 입력 | 기존 종합문 | 새 설명 |
|---|---|---|
| 2023-05-14 12:00 임신 | 월일 사신합+파 | 월巳·일申의 사신 부분형, 두 본기 주제 |
| 같은 날04:00 | 월일 사신합+파 | 시寅까지 참여한 인사신삼형. 시지 본기甲(식신)의 표현·실행 주제 추가 |
| 같은 날10:00 | 월일 사신합+파 | 월巳·일申·시巳의 사신 부분형. 세 자리지만 글자는 두 종류 |
| 같은 날16:00 | 월일 사신합+파 | 월巳·일申·시申의 사신 부분형. 반복申도 별도 자리로 유지 |
| 2024-01-08 12:00 /20:00 | 월일 축미충 | 축미 부분형 / 시戌까지 포함한 축술미삼형을 기존 충과 함께 표시 |

카드와 직업 근거 및 모든 자유질문 요약·순수 서버 프롬프트에는 사실·본기 해석·질문을 모두 보낸다. 생성 답변에는 **사실/범위 제한 안내**를 한 번 보존하며, 본기별 해석 전체를 생성 제공자가 반드시 재진술하는지는 보장하지 않는다. 기존 관계와 같은 전달 계약이다. 직업 상담은 첫/셋째 질문을 유지하고 둘째에 전체 참여 주제를 확인하는 질문을 붙인다. 총3항목이며 처음부터 분리·조정 불필요·경험없음과 반대 경험을 보존한다.

이는 **참여 범위와 구성 주제를 설명하는 깊이**의 개선이다. 부분형=삼형, 관계 중첩=강도합산/상쇄, 개인갈등·질병·성패·시기를 확정하지 않는다. predictionEnabled=false·trainingEligible=false·probability=null 유지. 개인 적중률은 미측정이다.

- 시작 기준 전체 `npm run verify`8단계 통과, 앱38/38·skip0 및 실제Chromium 홈/결과/KB 스모크 통과.

## 한계와 다음 작업

개인 적중률·실제 생성제공자의 의미해석 품질은 미측정/미검증이다. 기존 자유질문 전체질문복제 및 문장중간 잘림 중복은 기준판/현재에서 모두 재현된 미해결 한계다. 본기밖 글자의 힘, 원국관계의 개인효과, 대운·세운 개인풀이와 확률학습은 이번 범위 밖이다. [진행률](PROJECT_PROGRESS.md)은 완료9·진행7·대기4, 동일가중9/20=45%이며 정확도나 남은 시간 비율이 아니다.

현재 분석카드는 형의 새 설명으로 높이가 늘고(390px full 2083.984→2360.750px) 둘째질문도 길다. 후속은 기존조건을 계속 별도 안내로 붙이기보다 **월·시/강약/지장간/관계의 주제를 입력별 핵심 종합문과 간결한 경험질문으로 함께 읽는 경로**다. 조건을 버리거나 검증 안 된 새 판단으로 간결하게 만들지 않는다. [인계 §5.1](FOUNDATION_HANDOFF.md)에 실행·검증·미상보류·이전판 보존 조건을 남겼다. 공개거절 STATUS/WORK_CHECKPOINT는 변경·재전송하지 않았다.
