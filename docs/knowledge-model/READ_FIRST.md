# 다음 작업에서 먼저 읽을 문서

1. `USER_INTENT_LOG.md` — 사용자 원문과 방향 수정의 순서. 앞선 발언도 보존한다.
2. `PROJECT_AGENDA.md` — 현재 이해한 개념적 목표. 수정 가능한 해석 문서다.
3. `CURRENT_STATE.md` — 구현·검증된 범위와 아직 하지 않은 일.
4. `BASIC_READING_PLAN.md` — 일주·기본 성향 풀이를 첫 사용 가능한 단계로 만드는 순서.
5. `FIGMA_LIVE_REVIEW.md` — 현재 보드 직접 연결과 검수 결과. `FIGMA_FOUNDATION.md`는 이전 추출본 연결 이력.
6. `MATHEMATICAL_DESIGN.md` — 검토한 수학적 방법과 구현 후보.

이 프로젝트는 주변 키워드 조합·여러 변수·대운과 시점에 따라 관계와 해석의 정도가 달라지는 모델을 목표로 한다. 사용자 발언의 예시를 정답 데이터로 쓰거나, 단어쌍에 영구적인 확률을 붙이는 방식으로 목표를 축소하지 않는다. 특정 앱 형식은 목표가 아니다.

원본 문헌, 원문에서 추출한 주장, 구현 가정, 학습한 매개변수, 실제 검증 결과를 구별해서 이어간다. 현재 실행 코드는 비교와 검증을 시작하기 위한 시제품이며 완성된 사주 예측 모델이 아니다.
