# F01 월률분야·사령 — 범위·판본·검색 검수

2026-09-23 · 기준 main `f96a7e2bd8606dd32899164a887a46fc17a9abb4` (PR #189).

월지의 기간 구분, 다른 자리의 지장간 구성, 사령·당령·득령은 저자별 정의를 보존한다. 현재 `월률분야·사령` 노드는 관련 표현을 모은 **검색 묶음**이다. 다섯 별칭이 의미 동의어이거나 하나의 계산 규칙이라는 승인이 아니다. 이 노드는 기존76차이 목록 밖이므로 판정 행이나 번들 포인터를 새로 만들지 않았다.

## 1. 원문 정의와 적용 범위

기존 [단계 검수](FOUNDATION_HIDDEN_STAGES.md)의 묘33/67 대30/60, 오의 예외도 유지한다. 원문에 부족한 시간대, 일수 기산점·첫날 포함 여부, 절입 순간/자정 경계, 실제 절기간 길이를30일로 환산하는 방법을 임의로 채우지 않는다.

`dosa-app/engine/src/tables.js`의 `HIDDEN_STEMS`는12지지의 **구성·순서**를 담고 마지막 원소가 본기라는 계약이다. 오 `[병,기,정]`, 신 `[무,임,경]`, 자 `[임,계]`는 사령 기간이나 확률을 저장한 값이 아니다. `manseryeok.js`의 절입으로 연·월주를 구하는 계산과도 별개다. 이번에 엔진·관찰 어댑터는 변경하지 않는다.

F03에서 필요한 입력은 월지, 출생 절대시각/시간대, 실제 절입 시각, 적용 문헌·판본, 기간 경계 정책, 해당 지장간과 원국 천간의 대응이다. 기간표를 선택하기 전에 위 불일치와 미상을 해결하고 같은 입력의 판본별 차이를 측정한다. 학습 적격0·확률null을 유지한다.

## 3. ‘사령부’만 공용 제외, ‘사령관’은 보류

기준판 뉴런 검색에는 사령부/사령관/사령탑을 주변3글자 창에서 제외하는 검사가 있었지만 개념지도는 이를 호출하지 않았다. 사전에도 이 세 제외 표현이 없었다.

원문에서 `사령부`는 뇌하수체 비유(`month_hq_body`), 통근의 천간/지지 협력 비유(`month_hq_rooting`), 월지·일지의 터전 설명(`month_hq_positions`)으로 쓰인다. 이 글들이 사주와 무관하다는 뜻은 아니다. 그 부분문자만으로 날짜별 사령을 언급한 것으로 배정하지 않는다.

**실제 수정:** `alias_occurrence_allowed()`에 사령부의 해당 발생만 제외하도록 옮겼다. 두 빌더가 이미 이 함수를 사용하므로 같은 좁은 기준을 적용한다. 뉴런의 종전 사령부 주변창 검사는 제거하고 사령관/사령탑 정책은 그대로 유지한다. 한 문단의 다른 사령·당령·인원용사, 부정문, 월지·일간·오행 등 다른 개념은 보존한다. 붙여 쓴 `사령부사령`·`사령사령부`에서도 각각의 발생을 따로 처리한다. 사전 추가/삭제0.

### 넓은 제외를 채택하지 않은 근거

| 근거 | 실제 문맥 | 판단 |
|---|---|---|
| `month_commander_history` | 역사 속 군 사령관 | 실제 사령 용어와 다름 |
| `month_commander_trine` | 삼합에서 자수의 역할을 사령관/본부로 비유 | 월령분일용사의 조건으로 승격하지 않음 |
| `month_commander_topic_only` · `T-5c1fad8dc1-0000/0001` | 월지·태어난 달/날·해당 글자와 ‘월지사령관’, 이어 용신 설명 | 사령관 안의 사령을 전부 제외하면 이 관련 설명도 개념지도에서 잃음. 뉴런의 기존 누락도 의미상 안전 승인 아님 |
| `month_mixed_solstice`·`month_mixed_chen` | 실제 사령과 사령관 비유가 같은 문단에 있음 | 단어가 있다고 문단 전체를 제외하지 않음 |
| `month_commander_unverified_transcription` | 역사 전사에 사령관과 ‘사령원’ 표기가 섞임 | 제외3표현을 적용해도 남는 오탐. 음원 확인 없이 교정하거나 새 제외어로 확정하지 않음 |

따라서 사령관/사령탑의 기존 뉴런 검사를 개념지도에 통째로 복사하지 않는다. 사령탑은 현재 자료에서0행이며 합성 경계 검사만 가능하다. 후속 조건은 발생 위치별 실제 월지/기간/글자 설명, 군 직책·다른 체계의 비유, 이어지는 문단, 제목만 일치하는 경우를 구별하는 검수다. 보류를 검색 정확도100%로 포장하지 않는다.

## 4. 같은 자료의 전후 측정

[측정 스크립트](measure_month_command.py)는 이전 단계의 입력·전체 코퍼스 해시를 그대로 확인하고, 기준판의 실제 사전/두 빌더와 현재판을 따로 실행한다. 제목 포함·gist 제외이며271개 전체 개념의 문단 ID를 대조한다. 이전 측정 코드/해시를 변경하지 않고 공용 로더의 의존 해시도 기록한다.

[측정 결과](data/foundation_month_command_measurement.json)는 같은56,202행(웹21,251·전사34,951)에서 다음을 확인했다.

| 항목 | 뉴런 전 → 후 | 개념지도 전 → 후 |
|---|---:|---:|
| 월률분야·사령 | 281 → 281 | 337 → 309 |
| 해당 노드 제거 | 0 | 사령부 포함28행 |
| 해당 노드 추가 | 0 | 0 |
| 나머지270개 개념 ID 변화 | 0 | 0 |
| 지장간 | 3,686 → 3,686 | 3,686 → 3,686 |

두 빌더의 남은 차이28행은 사령관의 군 직책·다른 비유·월지 설명이 섞인 보류 범위다. 제외 표현을 포함한61행(사령부28·사령관33·사령탑0)을 통째로 버리는 가상 방식은 현재 뉴런이 찾는5행도 잃는다. 이5행 중4행은 실제 사령과 비유가 함께 있고1행은 사령원 전사다. 따라서 ‘실제 사령5개를 모두 보존했다’는 식으로 의미 정답 수를 만들지 않는다.

미등록 표현도 확인했다. 월률분일용사8행·月律分野6행·當令2행·人元用事8행은 기존 표현으로 모두 검색된다. 월령용사6행 중1행(`T-326a8b75b6-0002`)은 검색되지 않고 월주 암장간의 기간/격국 문맥이다(`month_unregistered_ryeongyongsa`). 관련 용례 누락을 보존하며 새 별칭은 판정 범위 확장 전까지 추가하지 않는다. 司令3행 중 미회수1행(`CHO-GANJI-P007-14`)은 무토의 萬物司令/萬物司命 설명과 표기 차이이며 월지 기간의 사령으로 바로 합치지 않는다(`month_unregistered_hanja_context`).

자료의 중복·같은 저자 의존이 있으므로 문단 수는 독립 근거나 정확도가 아니다. 모든 제거 ID·남은 차이·검수 사례와 코드/입력/측정 의존 해시를 기록했다. 생성 지도·D5·P2·앱에는 적용하지 않는다.

## 5. 검증과 다음 재개

원문 근거25구간 추가로176구간, 차이76·사전271·누적 별칭4를 유지한다.
