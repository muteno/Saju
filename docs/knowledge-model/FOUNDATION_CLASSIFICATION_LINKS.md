양인은 기본 그래프 노드가 없어 `label: 양인`, `node_id: null`로 보존한다. 겁재 노드로 대체하지 않으며 새 양인 노드도 만들지 않는다. 직접 `양인` 조회는 기존처럼 `not_found`이고 사흉신 주제의 근거에서 확인할 수 있다.

보드 사흉신은 첫 세 글자 살·상·겁을 해당 인용에서 풀어 쓰지 않았다. `coverage: partial`과 빈 `members`로 그 한계를 표시하고 끝 항만 연결한다. 다른 글에서 익힌 편관·상관·겁재 목록을 보드에 소급하지 않는다. 刃과 印을 혼동하지 않으며 양인/편인 두 대안을 합집합으로 만들지 않는다.

2021-08-28은 작성일이지 운의 적용 시점이 아니다. 색상 설명용 명조는 원문 자체가 실제 존재하지 않을 수 있다고 한다. 색상 서술은 해당 사이트의 분류 관점이며 앱 디자인 변경 지시가 아니다. 같은 사이트와 같은 개인 저자의 동일 관점도 구별한다. 동결 F02의 사길신 요약에는 별도 글의 편재를 ‘중립’이라고 적은 이전 표현이 남아 있다. 새 `good_plus_other`는 원문의 ‘길흉이 상반’을 사용하며, 원본 검토 이력을 소급 수정하지 않았다. 산책처럼 `sanchaek_formula`는 읽었으나 상관견관 공식 비판으로, 직접 구성원 분류 근거에는 편입하지 않았다.

## 3. 조회와 검증 계약

`foundation_claim_links.json` schema3는 목록을 가진8개 주장에만 `classifications`를 추가한다. 각 항목은 `label`, `coverage`, `groups`; 각 그룹은 원문 `label`과 `members`; 구성원은 `label`, `node_id`를 갖는다. `complete`는 목록 전개 여부이고 모든 구성원 노드가 연결됐다는 뜻은 아니다. 숫자4는 그룹 수이며 항상 서로 다른 네 십성이라는 뜻도 아니다.

새 두 주제의 `relations`는 반드시 빈 배열이다. anchor는 명시적 관계 참여자와 실제 연결된 분류 구성원의 합집합이다. 정인·식신·편인 등 공유 개념에서 조회하면 해당 주제들을 각각 전체 문맥으로 반환하지만, 공유 인용이나 반환된 구성원을 다시 따라가 다른 주제를 재귀 확장하지 않는다. 편재는 사길신만, 겁재는 사흉신만 반환한다. 출처끼리의 목록 합집합을 전역 길흉 정답으로 제공하지 않는다.

검증기는 출처별 고정 claim/evidence 바인딩, 정확한 그룹·구성원·대안·null·partial 계약, 부모 출처/해시/고정 범위의 보충 인용, 동결 F02 판정을 검사한다. 원문 목록 누락/변조·보드 임의 전개·양인→겁재 연결·분류의 인과간선·다른 출처 배정·anchor 누락/추가를 거부한다. 반환값은 깊은 복사다.

이것은 범용 의미 진위 판별기가 아니다. 자연어 statement/conditions/exceptions의 임의 변경은 구조검사만으로 모두 잡히지 않는다. 출처 재대조·특정 의미 회귀·독립 검토가 함께 필요하다. 조회 결과의 `application_status: not_evaluated`, `inference_enabled: false`, `use_as_training_labels: false`, `probability: null`을 유지한다. 새 주제의 도표 문맥은 `no_live_board_binding`이며 실제 Figma 연결선을 복원한 결과가 아니다.
