## 현재 18개 개념과의 대응

기계가 읽는 결과는 [figma_foundation_bindings.json](data/figma_foundation_bindings.json)에 있다. 개념 ID마다 `figma_<concept_id>` 참조 ID, 근거 줄, 정확한 부분 인용, 검토 메모를 기록했다. 기존 블로그 기반 정의나 출처는 바꾸지 않는다.

| 대응 수준 | 개수 | 개념 |
|---|---:|---|
| 명시적 정의 `definition` | 3 | 통근, 합화, 충 |
| 관련 설명 `explanation` | 11 | 오행, 생극, 천간, 지지, 일간, 비겁, 식상, 재성, 관성, 월령, 합 |
| 제목·자리만 확인 `title_only` | 4 | 음양, 십신, 인성, 지장간 |
| 찾지 못함 `not_found` | 0 | 해당 없음 |

이 구분은 보드가 제공하는 철학적·학술적 정확도 점수가 아니다. 이번에 선택한 원문 구간이 현재 개념의 정의까지 설명하는지, 관련 설명만 주는지, 제목만 확인되는지의 구분이다. `title_only`는 보드 전체에 설명이 없다는 단정도 아니다. 평탄화된 도식의 공간 배치를 추측해 정의를 채우지 않았다는 뜻이다.

`explanation`은 완전한 정의를 대체하지 않는다. 특히 하위 십신의 설명을 가족 개념 전체의 정의로 확대하지 않았다. 합의 위치 조건처럼 저자별 차이가 원문에 명시된 경우에는 그 제한도 보존했다. 빈 정의 자리, 표의 파편, 빠진 연결 대상은 블로그나 원래 보드 구조를 대조하기 전까지 보류한다.

## 연결선이 보존된 범위를 구별한다

`figjam_board_full.md`는 텍스트·표를 위치 순서로 평탄화한 자료이며 연결선 양 끝의 노드 ID를 보존하지 않는다. 따라서 이 Markdown의 가까운 문장들이 자동으로 의미 관계가 되지는 않는다.

별도 추적 파일 `dosa-app/methodology/figjam_board_raw.txt`는 XML이며, 구조를 확인한 결과 `connectorStart`·`connectorEnd` 속성이 있는 연결선 요소 154개가 존재한다. 이 수량은 보드 전체 기준이고 개인 기록 영역을 포함할 수 있다. 이번 참조층은 이 원시 연결선을 가져오거나 의미를 부여하지 않았다. 다음에는 허용된 기초·심화 영역의 노드 ID와 연결 대상, 라벨, 방향을 함께 검수할 수 있다. **도식 연결선의 존재는 확률값이나 인과 관계를 뜻하지 않는다.**

## 기본 개념의 기준 자료로 사용하는 방법

사용자가 이 보드를 더 원천적인 개념 자료로 지정했다는 것은 개념의 범위와 구성을 먼저 참조한다는 뜻이다. 이 운영자 편집 보드가 학술적 원전 또는 독립된 실증 자료라는 뜻은 아니다. 기존 참고 노트의 과거 지침보다 최신 사용자 요청을 우선하되, 인용 계보와 근거의 성격은 보존한다.

1. 보드에서 개념·구분·질문을 찾고 현재 개념 ID에 연결한다.
2. 블로그 원문에서 정의·조건·예외·반론을 대조한다. 보드와 다른 주장은 덮어쓰지 않고 함께 기록한다.
3. 같은 블로그·영상에서 옮겨온 보드 설명은 독립된 지지 자료로 더하지 않는다. 원출처 계보를 확인하기 전까지 이 참조층을 독립된 근거로 집계하지 않는다.
4. 직접 정의와 성향·결과 해석을 분리한다. 개인 특성을 단정하는 문장을 자동 규칙으로 승격하지 않는다.
5. 검수된 조건과 출처를 일주·기본 성향 풀이에 연결한 뒤, 맥락별 관계 정도와 확률을 학습하는 단계로 이어간다.

## 검증과 남은 일

기본 개념 ID 18개와 참조 ID의 일대일 대응, 중복 없음, 26개 인용 구간의 원문 부분 문자열 일치, 개인 기록 영역 밖의 위치를 확인했다. 이는 원문 추적 검증이며 해석 정확도나 확률 학습의 검증은 아니다.

보드의 현재 버전과의 동기화, 원시 연결선의 기초·심화 영역 선별, 표 구조 복원, 18개 밖의 개념 추출, 재인용 계보 확인, 정의와 해석의 내용 검수는 남아 있다. 추가 수집물이 들어오면 기존 출처와 비교 가능한 별도 스냅샷으로 보존한다.
