# F01 통근 — 정의 범위·뿌리 구어·검색 영향 검수

2026-09-23 · 기준 main `ec26ac92834a7df3c21dd6b7a07dd26c85cb6dfc` (PR #185).
청사진 v2 §0의 F01-a 실행 결과다. **원문 검수 단위를 완료하고 넓은 별칭 6개의 전역 추가는 보류한다.** 실행 사전·매칭기·앱 계산 변경은 0이며, 다음은 조후→상극이다. 통근 전체 관계 추출이나 관법 통합이 완료됐다는 뜻은 아니다.

## 1. 원문에 있는 세 가지 범위

아래는 저자별 용어 범위다. 어느 범위를 개인의 결과에 적용해도 되는지 검증한 것이 아니다. Figma는 9월 22일에 보존한 노드/필드/해시를 다시 읽었으며 이번에 live 재조회한 것으로 표기하지 않는다.

| 출처·근거 ID | 확인한 범위 | 같은 말로 합칠 수 없는 지점 |
|---|---|---|
| Figma 노드 `498:13700`, `root_figma_same_character` | 천간 글자가 지장간에 같은 글자로 존재 | `같은 글자`를 자동으로 `같은 오행`으로 확대하지 않음 |
| 초코서당 용어사전 2025-07-22, `root_choco_same_element` | 천간 기준, 지지/지장간의 같은 오행. 다른 음양 글자·먼 자리도 용어 사용 가능 | 글자의 동일성과 오행의 동일성, 관계의 존재와 강도를 분리 |
| 명리학탐구 기초, `root_myeongri_same_element` | 천간 오행과 지장간의 같은 오행 | 위와 표현이 비슷해도 원저자·자료 의존을 확인하기 전 독립 근거 수로 더하지 않음 |
| 현묘 「통근, 투간, 투출이란? (8)」2021-01-22, `root_hyeonmyo_supporting_element` | 같은 오행 또는 생해 주는 오행. 을목에 갑·을·임·계의 예시 | 비겁뿐 아니라 인성까지 포함하므로 앞의 두 범위와 다름 |

초코서당 `root_choco_time_scope`는 대운·세운의 천간이 원국 지지/지장간에 뿌리를 두는 표현도 사용한다. 원국 내부의 고정 관계만으로 환원하면 시간·참여자를 잃는다. 투간/투출은 관찰 기준이 반대인 설명이므로 별도 검수 없이 같은 관계의 동의어로 합치지 않는다.

전사 `root_strength_qualified`에서는 같은 문맥에 **임수–신중임수**의 뿌리를 말하면서 **임수–진중계수**는 강하게 내리지 못했다고 설명한다. 이를 단순한 동일 오행 부정 규칙으로 일반화하지 않는다. 관계 존재, 뿌리의 강도, 자리, 저자의 사례 해석을 각각 보존해야 한다. 전사의 오표기나 그림에만 있는 입력은 추측해서 고치지 않는다.

## 2. 넓은 별칭과 기존 별칭의 경계

| 검수한 표현 | 원문에서 확인한 다른 뜻 | 결정 |
|---|---|---|
| 뿌리 없 | `root_tree_without_roots`: 을목 설명 속 살아 있는 나무의 조건·물상 | 실제 뿌리 부재 용례도 있지만 이 표현만으로 천간–지장간 관계를 확정할 수 없어 보류 |
| 뿌리가 | `root_shared_intellectual_origin`: 명리학·한의학의 기원 | 사주 글 안의 구조어 동반만으로 거를 수 없어 보류 |
| 뿌리는 | `root_sowing_verb`: 망종에 씨를 뿌리는 시기 | 명사 뿌리와 동사 뿌리다가 충돌하므로 보류 |
| 뿌리도 | `root_ancestral_too`: 조상·국가·궁성 해석의 뿌리 | 통근과 다른 관계이므로 보류 |
| 뿌리로 | `root_ancestral_origin`: 연주·조상에서 부모로 이어지는 비유 | 연주/일간이 함께 있어도 통근이라고 단정할 수 없어 보류 |
| 뿌리를 | 기존 `root_figurative`: 그림세계의 뿌리 탐색 | 넓은 활용형을 전역 별칭으로 넣지 않음 |
| 기존 뿌리를 내 | `root_literal_tree_existing_alias`: 흙과 나무의 기반 비유 | 기존 검색에도 의미 과포함이 있음을 확인. 이번에 제거하지 않았으며 의미 승인으로 보지 않음 |

`root_ancestry_near_stem`은 일간·일지와 뿌리가 가까이 나오지만 근묘화실의 조상 비유다. 따라서 **일간/일지/오행이 주변에 있다는 단순 조건으로 넓은 별칭을 승인할 수 없다.** 위 사례 중 일부는 한 문단에 실제 통근 설명과 비유가 섞여 있다. 구절의 뜻과 문단 전체의 관련성을 구별하며 문단 전체를 무관하다고 일괄 삭제하지 않는다.

부정 표현도 검색 대상이 될 수 있다. “뿌리가 없다”를 찾았다는 사실은 통근이 성립했다는 판단과 다르다. 문헌 언급→관계 추출→조건 충족→개인 풀이의 단계를 건너뛰지 않는다.

## 3. 재현 가능한 영향 측정

[measure_rooting.py](measure_rooting.py)는 두 빌더가 기준 커밋과 바이트상 같은지 확인한 뒤 동일 입력을 읽는다. 넓은 별칭 6개는 별도 메모리 사본에서만 추가해 비교하며 실행 파일·생성 지도·P2·D5를 쓰지 않는다. 결과와 입력/코드 해시는 [측정 JSON](data/foundation_rooting_measurement.json)에 보존한다.

- 입력: **56,202행**(웹21,251 + 전사34,951). 두 검색기 각각 기존 통근 배정 **1,050개**.
- 가상으로 6개를 모두 추가하면 각각 **2,525개(+1,475)**. 추가 ID 집합은 양쪽이 같고, 다른 개념 배정 변화는0이다. 이 가상 증가를 실제 개선이나 의미 승인으로 세지 않는다.
- 실제 적용: **추가0, 제거0**. 두 생산 빌더는 PR #185와 동일한 해시를 유지한다.

| 표현 | 포함 행 | 출현 횟수 | 기존 통근 배정 외의 후보 ID |
|---|---:|---:|---:|
| 뿌리 없 | 21 | 23 | 13 |
| 뿌리가 | 1,201 | 1,961 | 978 |
| 뿌리는 | 207 | 235 | 185 |
| 뿌리도 | 82 | 97 | 66 |
| 뿌리로 | 43 | 55 | 37 |
| 뿌리를 | 842 | 1,311 | 360 |

합성한 긴 별칭 `일지의 뿌리가`는 실제 원문 구절로 시험한다. 뉴런 검색의 긴 별칭 우선 매칭에서 원래 잡히던 `일지`를 가리고 `통근`만 남긴다. 따라서 이 문구도 새 별칭으로 추가하지 않았다. 앞으로 중첩 관계를 추출할 때 참여 자리·오행을 보존하는 방식이 필요하다. 모든 긴 표현이 안전하다고 주장하지 않는다.

수치는 제목을 포함한 검색 행/문단 ID의 수다. 본문 gist는 제외하지만 같은 저자의 웹/영상, P0와 별도 전사 사본이 포함된다. 독립 근거 수·정밀도·해석 정확도·학습 확률이 아니다. 각 별칭의 잠재 증가 ID는 서로 겹칠 수 있으므로 합산하지 않는다. 전체 신규 ID를 사람이 전수 의미 검수했다고 주장하지 않는다.

### 새 체크아웃에서 다시 측정

저장소 루트에서 수행한다. 생성 코퍼스가 없으면 먼저 다음 두 생성기만 실행한다. 과거 저장된 `전사_적재리포트.md`가 달라질 수 있으므로 별도 검토 없이 커밋하지 않는다. 원래 있던 작업자 변경을 덮어쓰지 않는다.

```bash
python3 -c "import sys; sys.path.insert(0, '정제/_현황판'); import build_dashboard as b; b.DATA.mkdir(exist_ok=True); b.merge()"
python3 정제/_현황판/ingest_transcripts.py
python3 docs/knowledge-model/measure_rooting.py --output /tmp/rooting.json
python3 docs/knowledge-model/foundation_review.py --check
python3 -m unittest discover -s docs/knowledge-model -p 'test_foundation_review.py'
```

기준 Git 커밋과 스냅샷 파일이 있어야 한다. 입력 해시가 다르면 먼저 판본·생성기·필터 차이를 확인하고 과거 측정을 새 결과로 덮어쓰지 않는다. `lint_aliases.py` 등 옛 전체 파이프라인은 실행하지 않는다. D5 인용 자격·P2 결과는 여기서 측정한 것으로 추정하지 않는다.

## 4. 적용과 다음 재개 조건

- 원문 근거 13구간을 추가해 전체 99구간으로 늘렸다. 차이76·사전271·적용 별칭1은 유지한다. 과거 기준 번들과 해시는 수정하지 않았다.
- 통근 검수에서는 새 노드/별칭/일괄 제거를 적용하지 않았다. 파생 실험 코드와 원문 검수 기록만 추가했다. 새로운 계산 정책이나 핵심 매칭 구조를 선택하지 않았으므로 다중 에이전트 평의회를 수행했다고 표기하지 않는다.
- 다음 실제 검수는 인계 §5.1의 조후→상극이다. 통근 재개는 **대상 천간, 지지/지장간, 동일성/생조, 부정/강도, 자리/거리, 원국/운, 출처 관법**을 분리하는 구절 단위 기준을 마련할 때다. 조상·물상·예술 비유와 혼합 문단을 포함하고, 기존 일지·오행 노드가 남는지 양쪽 빌더에서 확인한다.
- 원문 인용 검사 통과는 의미나 개인 예측의 검증이 아니다. 실제 학습 적격0·확률null이며 앱 풀이 정확도가 개선됐다고 보고하지 않는다. 최종 검사·원격 보존·병합 영수증은 체크포인트와 해당 PR에서 확인한다.
