# F01 투간·투출 → 지장간 검수

2026-09-23 · 기준 main `cef1307c673342147afbf74b5996f99a7036864e` (PR #187).
**기존 검색 묶음과 별칭은 유지하고, 저자별 정의·조건·반례를 구분한다.** 두 행의 상태를 제목/문자 확인에서 원문 사례 검수로 올렸다. 관계 계산이나 의미 통합 전체를 완료한 것은 아니다.

## 1. 투간·투출: 무엇을 기준으로 어디까지 같은가

원문 위치·파일 해시·인용은 [검토 자료](data/foundation_taxonomy_review.json)의 아래 근거 ID에 있다. 줄 범위는 기존 검사기의 `str.splitlines()` 기준이다. 보드는 보존 추출본을 읽었으며 이번에 현재 Figma를 새로 동기화하지 않았다.

| 출처·근거 ID | 직접 확인한 범위 | 남겨야 할 차이 |
|---|---|---|
| 보존 보드 `exposure_board_terms` | 투출은 지장간의 오행, 투간은 지장간의 간지가 천간에 나타남 | 오행 동일성과 글자 동일성을 구별. 주변의 격·강도 문구를 조건 없는 계산식으로 옮기지 않음 |
| 초코서당 `exposure_choco_direction`·`exposure_choco_exact` | 지지/지장간이 출발점. 엄격한 투간은 같은 글자, 투출은 같은 오행까지 설명. 일간으로의 투간/투출은 제외 | 통근과 관찰 방향이 반대이며, 동일 오행을 모두 같은 글자로 취급하면 안 됨 |
| 초코서당 `exposure_choco_variation` | 다른 음양의 글자를 ‘변격으로 투간’이라고 표현하는 확장 | ‘변격’ 조건을 지우고 투간 일반 정의에 합치지 않음 |
| 초코서당 `exposure_choco_restricted_views` | 가까운 천간·월지 한정·동주 한정 등 일부 학자 견해를 소개 | 소개된 견해를 전 저자의 공통 규칙이나 초코서당의 최종 입장으로 바꾸지 않음 |
| 현묘 `exposure_hyeonmyo_exact` | 투간은 똑같은 간지에 한정. 본문에서 투간(투출)로 함께 지칭하고 월지/격국의 필요성을 설명 | 통근에 허용한 생조 오행 범위를 투간에 복사하지 않음 |
| 명리학탐구 `exposure_myeongri_exact` | **투출도 반드시 같은 글자**. 동주가 아니어도 용어를 사용하되 멀면 힘이 줄어든다는 문헌 주장 | 초코서당·보드의 넓은 투출 정의와 다름. 존재와 강도를 구분 |

명리학탐구는 일반 투출 설명에서 년간과 **일간**에 투출했다고 적지만, 격국 설명에서는 일간을 제외한다(`exposure_myeongri_daymaster_scope`). 따라서 ‘일간 제외’를 모든 저자의 모든 투출 용례에 적용할 수 없다. 일반 관계와 격국 선택의 문맥을 따로 보존한다.

초코서당 한 글 안에서도 표현 범위가 달라진다. `exposure_choco_time_examples`는 원국 지장간이 대운/세운 천간에 투간했다고 쓰는 예문을 허용한다. 반면 글 끝의 `exposure_choco_editorial_policy`는 앞으로 원국 내부를 투간/투출, 원국→운을 투출로 표기하겠다고 정한다. 허용 예문과 저자의 표기 방침을 함께 남기며 한쪽을 삭제하지 않는다. ‘투출’ 설명 중 ‘통근’이라는 말이 나오는 원문도 임의로 교정하지 않았다.

`exposure_choco_time_direction`은 **원국의 지지/지장간 → 대운·세운 천간**을 허용하지만, **대운 지장간 → 원국 월간**을 투간/투출이라고 부르지 않는다. 두 영역의 글자가 같다는 사실만으로 양방향 관계를 만들 수 없다. 그림에만 있는 전체 명식은 복원하지 않았다.

현재 `투간·투출`은 `투간/투출/透出`을 찾는 검색 묶음이다. 저자·용어·출발 자리·도착 자리·글자/오행 동일성·일간 포함 여부·원국/운·부정·강도를 보존하기 전에는 실제 관계를 하나로 합칠 수 없다. 새 관계 노드나 격국 판정기를 만들지 않았다.

## 2. 지장간: 구성과 해석을 분리

| 근거 | 확인한 내용 | 이번 처리 |
|---|---|---|
| 기존 `candidate_074` | 지지에 저장된 천간 기운을 지장간(地藏干)으로 설명. 같은 글에서 숨겨진 인간사라는 비유도 사용 | 한자 표기 근거는 확인하되 비유를 구성표로 바꾸지 않음 |
| `hidden_board_chen` | 진의 을·계·무와 여기·중기·정기를 표시 | 보존된 글자/단계를 확인. 주변 강도 순위를 학습된 값으로 사용하지 않음 |
| `hidden_hyeonmyo_zi`·`hidden_hyeonmyo_stages` | 자의 임·계, 초기(여기)/중기/정기(본기). 30일을 나눠 설명하는 기간 | 구성, 단계 명칭, 사령 기간을 구별 |
| `hidden_hyeonmyo_wu_exception` | 왕지는 대체로 두 글자지만 오화는 예외라고 명시 | ‘왕지의 지장간은 모두 두 개’로 요약하지 않음 |
| `hidden_choco_wu` | 오의 병·기·정과 저자가 제시한 작용력33/30/37% | 글자 구성과 저자의 비율을 분리. 경험적으로 검증된 확률이 아님 |

현재 실행 정본은 `dosa-app/engine/src/tables.js`의 `HIDDEN_STEMS`이다. 여기→본기 순서, 마지막 원소가 본기라는 계약을 유지한다. 직접 대조한 자 `[임, 계]`, 진 `[을, 계, 무]`, 오 `[병, 기, 정]`은 위 원문과 맞는다. 이번에 12지의 모든 저자별 판본을 전수 검수했다고 주장하지 않는다. 숫자 인덱스·구성표·엔진 계산·vendor 사본은 바꾸지 않았다.

## 3. 암장을 유지하는 이유와 남는 문제

- `hidden_amjang_web`는 월지/시지 속 재성이 암장됐다는 실제 지장간 용례다. 전사 `hidden_amjang_transcript`도 병화가 지지에 암장된 상황을 말한다.
- `hidden_amjang_metaphor`는 여성에 대한 표현에 결혼이라는 전제가 숨어 있다는 논의를 ‘암장’이라고 부른다. 이 구절을 숨은 천간 구성으로 읽을 수 없다. 문단의 사회적 주장이나 개인 판단을 승인한 것이 아니다.
- `hidden_amjang_transcription`에는 ‘암장관’이라는 전사 표기가 있다. 이를 별도의 새 개념으로 만들거나 원문을 ‘암장간’으로 고치지 않았다. 주변 문맥과 음원 검수는 다른 단계다.

따라서 기존 `암장`을 안전한 동의어로 전수 승인하지도, 전역 삭제하지도 않는다. `지장간/지장 간/地藏干/암장` 네 표현은 문헌 주제 검색으로 보존한다. 같은 문단의 구조어 존재만으로 해당 구절의 의미를 확정하는 새 필터도 넣지 않았다.

## 4. 검색 영향 측정

현재 두 빌더를 기준 main과 해시로 대조하고 같은 제목 포함/본문 gist 제외 자료에서 검색한다. `암장` 제거는 별도 메모리 사본에서만 시험한다. 실제 사전·생성 지도에는 쓰지 않는다.

[재현 스크립트](measure_exposure_hidden.py)와 [입력/코드 해시·문단 ID](data/foundation_exposure_hidden_measurement.json)를 보존했다. 입력은 **56,202행(웹21,251·전사34,951)**이다.

| 항목 | 뉴런 검색 | 개념지도 |
|---|---:|---:|
| 현재 투간·투출 | 721 | 721 |
| 현재 지장간 | 3,682 | 3,686 |
| 암장 제거 가상 시험의 지장간 | 3,283 (-399) | 3,287 (-399) |
| 가상 삭제 때 다른 개념의 변화 | 0 | 0 |

두 빌더의 가상 제거399개 ID는 같다. 실제 용례·비유·별도 확인이 필요한 전사 표기의 대표3문단이 모두 빠진다. 이를 전부 오탐 또는 전부 정답으로 분류할 수 없으므로 전역 삭제는 적용하지 않았다. `암장`을 포함한415행 중 다른 지장간 별칭이 함께 있는 행은 남는다.

`透干`은 현재 등록되지 않은 표기지만 포함11행이 모두 기존 투간·투출 검색에 잡힌다. 이 자료에서 추가 회수 필요가 확인되지 않아 이번에 추가하지 않았다. 단독 한자 표기를 포함한 모든 미래 자료를 이미 찾을 수 있다는 뜻은 아니다.

현재 지장간의 두 빌더 차이4행은 `ST-P1078-05`, `ST-P1078-10`, `T-53ebbe2d99-0000`, `T-53ebbe2d99-0003`이다. 원문 `hidden_overlap_hour_branch`의 **시지장간**에서 뉴런 정규식은 앞의 `시지`를 먼저 잡고, `hidden_overlap_month_branch`의 **연월지장 간**에서는 `월지`를 먼저 잡는다. 이어지는 지장간 별칭이 한 글자를 공유해 놓친다. 개념지도는 별칭별로 찾아 두 개념을 보존한다. 이는 이번 변경으로 생긴 손실이 아니라 **기존의 겹침 처리 한계**이며, 원문2구절과 중복 사본4행을 구별한다. 자리와 지장간을 함께 보존하는 수정이 다음 첫 작업이다.

실제 검색 사전·계산 변경은0이다. 두 생산 빌더·사전과 엔진 구성표·관찰 어댑터가 기준 main과 같은 해시이고, 같은 고정 입력의 현재 실행이 곧 기준 실행이다. 수치는 중복/동일 저자 자료를 포함한 검색 행이며 독립 증거나 정밀도·해석 정확도가 아니다. 399문단의 의미 전수 검수도 완료하지 않았다.

새 체크아웃의 코퍼스 생성은 [통근 문서의 명령](FOUNDATION_ROOTING.md#새-체크아웃에서-다시-측정)을 재사용한다. 이 실험은 PR #187의 생산 코드가 유지되는 경우에만 실행한다. 이후 코드를 고쳤다고 과거 해시 검사를 낮추지 않는다.

```bash
python3 docs/knowledge-model/measure_exposure_hidden.py --output /tmp/exposure-hidden.json
python3 docs/knowledge-model/foundation_review.py --check
SMOKE_CHROMIUM=/실제/브라우저/경로 npm run verify
```

## 5. 검사와 다음 작업

근거22구간을 더해135구간, 판정76·사전271·기존 적용 별칭4를 유지한다. 투간·투출/지장간 행의 원문 검수 상태·근거·판단을 보강했으며 기존판을 보존한65행 전체의 의미 검수가 끝난 것은 아니다. 두 행 모두 이번 별칭 추가/제거는0이다.

기준/중간 저장 검사는 실제 Chromium 포함 필수8단계·Python129개(F01 19개) 통과했다. 원문135구간과 측정의 코드/입력 해시를 대조한다. 최종 커밋 검사와 병합은 [PR #188](https://github.com/muteno/Saju/pull/188) 영수증이 정본이다. 앱/UI·P2·D5·학습값은 미변경이며 학습 적격0·확률null을 유지한다.

다음은 **지장간 겹침4행 → 여기·중기·정기 → 월률분야·사령**이다. 먼저 위 두 구절의 자리와 지장간을 동시에 보존하고, 같은 자료의 양쪽 빌더 변화와 다른 개념 손실을 확인한다. 이어 `여기/본기/정기`의 기존 문맥 필터와 일상어 반례, 지장간의 구성과 사령 기간/월령·강약의 관계를 검수한다. 넓은 통근·조후 보류를 자동 해소하거나 특정 관법의 수치를 확률로 옮기지 않는다.
