# F02 관계 조회 후속 — 재생관·관살혼잡

2026-09-27 · 사용자 원문48 · 기준 main `05dc0890d9c5acbe794c0992e88d1fe15da6c91b` (PR #192).

## 1. 바뀐 조회

재생관·관살혼잡의 출처별 조건과 예외를 기존 관계 조회층에 추가했다. 단어 검색 등재만 돼 있던 두 주제가 `knowledge_query.py`에서 원문과 함께 조회된다. 개인의 원국에서 성립하는지 계산한 결과는 아니다.

| 구분 | 전 | 후 |
|---|---|---|
| 재생관 | `not_found` | `found`, 주장5·근거7구간 |
| 관살혼잡 | `not_found` | `found`, 주장3·근거3구간 |
| 조회층 전체 | 주제2·주장10·관계7 | 주제4·주장18·관계기록12 |
| 관계기록 성격 | 생극 등 방향7 | 생극 등 방향10·방향 없는 공존2 |
| 기존 개념에서 주제 조회 | 7개 개념 | 12개 개념 |
| 기본 그래프·조건·사전 | 58/132/11·조건8·사전277 | 파일 불변 |

원문8구간을 재독하고 바로 뒤 문맥2구간을 보충했다. 조회층 전체 고유 인용은19구간(기존 F02 중17 + 별도 보충2)이다. 같은 저자/인용의 반복과 독립 근거 수는 다르다. 기존10개 주장과 편인도식·상관패인 직접 조회는 정확히 보존됐다.

## 2. 원문에 따라 보존한 차이

| 주장 | 근거 | 보존한 범위·조건·예외 |
|---|---|---|
| 재생관 일반 정의 | `sagong_generation` | 재성→관성 일반. 정재/정관만으로 축소하지 않음 |
| 천간 우선·지지의 다른 방법 | `sagong_planes` + `sagong_generation_examples` | 천간 예시의 재생살/재생관 구분, 겁재합·식신제어·지지 합/계절/운/입묘. 지지 재생관 전면 금지가 아님 |
| 기해의 지장간 재생관 | `hyeonmyo_branch_generation` | 기해일주·지장간 범위. 인용에 없는 참여 글자는 보충하지 않아 별도 방향 관계 없음 |
| 정묘의 경자년 재생관 | `hyeonmyo_generation_variant` + `hyeonmyo_generation_exception` | 정묘일주 × 2020년 세운의 천간庚 정재→지지子 편관. 일반적 부정 설명과 강한 인성의 조화에 따른 긍정 가능성 병존 |
| 전사 표기 제한 | `generation_suffix` | 재생관리/관생체/식생제 등의 표기를 교정·별칭·관계로 승격하지 않음 |
| 보드 관살혼잡 | `board_mixed` | 정관·편관 혼재와 관성 과강→일간 신약을 분리. 공존만으로 강약을 계산하지 않음 |
| 기묘의 관살혼잡 | `hyeonmyo_mixed` | 기묘일주 지장간. 기토 성질에 따른 길한 작용과 갑기합에 따른 적용 어려움을 별도 설명으로 보존 |
| 구성만으로 삶을 확정하는 상담 비판 | `choco_determinism` | 관성혼잡은 원문 표기이며 전역 별칭은 보류. 성립 자체를 부정하는 규칙으로 사용하지 않음 |

보충 구간은 사주공부 중급1021–1060, 현묘 경자년380–384다. 기존 F02 인용 범위를 바꿔 과거 검수를 소급하지 않았다. 원문 전체 경로·LF 해시·줄·축자 인용은 `foundation_claim_links.json`의 `supplemental_evidence`에 있다. 보충 구간을 이전 F02의24구간에 합산하지 않는다.

공존2기록의 `source`/`target`은 저장 순서다. predicate에 방향 없는 공존임을 명시하고 양쪽 개념에서 같은 주제를 조회한다. 현재 소비자는 생극 간선·추론·도표에 이를 합치지 않는다. 향후 유향 도표나 추론에 넣을 때는 기계적인 방향 구분부터 검토해야 한다.

## 3. 계약과 실제 소비 경로

- 조회층 schema2는 주제4·명시적 주장18·보충근거2개 계약이다. 새 근거는 부모 F02 인용의 경로·해시·출처·종류와 같아야 하며 고정 줄 범위 전체를 원문과 대조한다. 누락·치환·범위 변경·축자 불일치를 거절한다.
- 원문 F01/F02 판정·검색 사전·기본 그래프를 바꾸지 않았다. 새 조회에는 기존 F02의 모든 조건·보류 별칭도 함께 반환된다. `application_status=not_evaluated`, 추론/학습 비활성, 확률null을 유지한다.
- 정관에서는 상관패인+관살혼잡, 관성·편관에서는 재생관+관살혼잡 전체 맥락이 나온다. 같은 초코 인용을 공유한다고 편인도식 주제까지 재귀 확장하지 않는다.
- CLI 기본 모드는 검증한 네 주제를 조회한다. `--base-only`는 원문 없는 독립 묶음의 명시적 기본 그래프 조회다. 새 주제의 `--diagram-context`는 `no_live_board_binding`이며 보존 인용을 live Figma 연결선으로 만들지 않는다.

## 4. 검증

[실제 전후 측정](data/foundation_generation_mixed_measurement.json)은 기준판의 로더/자료와 현재판을 같은 그래프·legacy에서 실행한 결과다. 기존58노드의 ID·제목·별칭186개에서 새 주장 필드를 제외한 결과 변화0, 이전 두 주제 전체 결과 변화0, 기존10주장 변화0이다. 17개 검색명(6개 기존 개념)의 주장 문맥만 늘었으며 현재 전체 연결 개념은12개다. 불변 주요 파일 해시도 기록했다. 검색 빌더가 바뀌지 않아 전체 코퍼스 매칭을 재실행하지 않았다.

```bash
python3 docs/knowledge-model/foundation_claims.py
python3 docs/knowledge-model/knowledge_query.py 재생관
python3 docs/knowledge-model/knowledge_query.py 관살혼잡 --diagram-context
python3 -m unittest discover -s docs/knowledge-model -p 'test_foundation_claims.py' -v
npm run verify
```

관계 조회 회귀16개(새5개)는 공유 개념 전체 맥락/비재귀 조회, 일반·특정 참여자, 자리·시기·공존/인과 구별, 부정/예외, 보충근거 변조 거절, 실제 CLI를 포함한다. 기준 전체 검사는 Python159개·필수8단계·실제Chromium을 통과했다. 변경본 커밋 훅도 Python164개·필수8단계·실제Chromium을 생략 없이 통과했다. 독립 검토·원격 저장·최종 병합은 [체크포인트](WORK_CHECKPOINT.md)와 해당 PR 영수증을 따른다. 검사 통과를 실제 해석 정확도 검증으로 보고하지 않는다.

## 6. 독립 검토

원문·검증 계약·조회 호환성·추론 경계·회귀·최종 문서/반론 관점을 동일 모델 최고 노력으로 읽기 전용 검토한다. 동시 실행 한도는6명이라8명은6+2로 나눠 진행한다. 아래는 실제 원문·코드·실행 결과로 확인한 검토다. 검증기 자체가 모든 문장 의미를 인증하는 것은 아니다. 최종 반론의 방향 역전/원국 확대/시기 삭제3변이를 직접 재현했다. 구조 검증기는 통과시키지만 해당 의미 회귀는3개 모두 거절한다.

| 검토 | 직접 확인한 결과 | 처리 |
|---|---|---|
