## 사용자에게 달라진 것

생시가 알려진 갑인 입력에서 기존 분석 화면 ‘그 밖의 근거’에 ‘갑인 기본 구조’ 카드가 생긴다. 일주 구성, 일지 본기 비견, 戊丙甲 지장간, 건록 분류, 식신/상관 분류의5개 설명과 적용 한계를 읽는다. 기존 검토 결과를 재사용했으며 새 원문 감사는 추가하지 않았다.

기존 카드의 출처 각주와 관점 차이의 자료명 접두어를 없애고 견해1/2처럼 내용을 구분한다. 기존 갑인 직업 안내의 고정 출처 문장을 짧게 바꾼다. 상담 프롬프트도 출처·저자명·근거줄을 요청하지 않는다. 명시 출처표식이 들어온 공급자 답변은 조건·예외가 함께 잘릴 수 있으므로 통째로 기존 풀이에 되돌린다. 서버와 오래된 응답을 받는 클라이언트 모두 처리하며 변환 후 차단 문장도 다시 검사한다. 자유생성의 모든 암시적 인용이나 모든 형태의 출처를 탐지한다고 보장하지 않는다. 내부 원문·메타데이터·연구용 Markdown 자료는 보존한다.

새 구조는 **구조 이해를 돕는 깊이**이며 아직 Brain·개인 상담의 새 추론 규칙이 아니다. 개인 성격·관계·직업·시기의 종합 해석, 개인 적중률 검증은 완료되지 않았다. 기존35서술/14정책의 개인출력 보류와 식상조건unknown, 생시미상 보류를 유지한다. 학습적격0·확률null이며 관리9/20은 개인 정확도와 무관하다.
