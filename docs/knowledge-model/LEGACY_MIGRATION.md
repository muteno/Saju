기준: 2026-09-22, main `d60de55`. 기존 자료를 전량 폐기할 필요는 없다. 조건·개념명·원문은 재사용하고, 예전의 숫자와 확정 판정은 현재 확률 모델로 승격하지 않는다.

기존 지도는 개념·계층·관계와 탐색 자료를 담고 있다. 현재 모델은 문맥 특징·다중 조합을 받아 검토된 사례로 매개변수를 학습하는 시제품이다. 기존 지도의 선 개수·고정 가중치·추출 품질은 현실의 조건부 확률과 의미가 달라 그대로 연결할 수 없다. 두 구조 사이에 **원문·조건 검토 입력**을 추가하는 것이 이번 이관의 범위다.

## 이관 결과

- 후보 767건. 동일 후보 중복 제거는 0건, 서로 같은 원문 문단을 가리키는 기록은 354개 그룹으로 묶었다. 그룹 수를 독립 사례 수로 해석하지 않는다.
- 정확 구절 발견 455건, 보유 원문에서 구절 미발견 5건, 이번 입력 범위 밖 원문 307건. 마지막 범주는 전사·보드·별도 웹 자료 등으로, 원본이 저장소 전체에 없다고 주장하는 것이 아니다.
- 현재 개념과 연결된 후보는 570건, 그중 구절을 찾은 항목은 337건이다. 미대응 개념·후보도 `data/legacy_review.json`에 남아 있다.
- 원문 위치 1,523개는 중복 구절·같은 출처의 재수록까지 포함한다. 증거 표 수나 신뢰도 가산값이 아니다. `웹:명리학탐구`와 `웹:플러스명리학`은 같은 사이트로 묶고, `웹:현묘`와 `웹:안녕,사주명리(현묘)`도 같은 사이트로 묶는다. 사이트 구분만으로 저자 독립성이 입증되지는 않는다.

`literal_anchor_found`는 해당 출처 아카이브에서 구절을 찾았다는 뜻이다. 전체 조건이 의미상 맞는지, 문단 ID가 예전 정제 문단과 동일한지, 해당 개인의 원국에 적용되는지 검증한 상태가 아니다. 수기 자료는 `검증구`와 수기로 재구성한 `조건절`을 구별한다. 요약을 축자 인용으로 표시하지 않는다.

5건의 미발견 구절은 원문 표기·개행·전사/웹 출처 혼동 가능성을 검토할 대상으로 남겼다. 통과시키기 위한 부분 일치나 출처 밖 검색은 하지 않는다. `신금(辛)`과 `신금(申)`은 서로 다른 노드로 연결하고, 기존 `월지`를 현재 별칭이라는 이유로 `월령`과 자동 동일시하지 않는다.

## 실행과 유지

저장소 루트에서:

```bash
python docs/knowledge-model/legacy_import.py
python docs/knowledge-model/legacy_import.py --check
python docs/knowledge-model/knowledge_query.py 일간
python -m unittest discover -s docs/knowledge-model -p 'test_*.py'
```

현재 CLI의 `legacy_review`는 직접 연결된 후보와 해당 원문을 반환한다. 기존 그래프 관계와 조건부 모델의 매개변수는 변경하지 않는다. 확률·추론·적용 상태는 각각 `null`, `false`, `not_evaluated`다. 그래프의 스냅샷이 달라지면 잘못된 개념 대응을 쓰지 않도록 재생성을 요구한다.

원본 데이터는 수정하지 않는다. 새 원문을 추가하려면 인벤토리·출처 매핑을 검토하고 빌더를 재실행한다. `npm run verify`가 재생성 결과와 저장본의 일치 및 전체 Python 회귀를 확인한다. 출력 JSON을 직접 손편집하지 않는다.
