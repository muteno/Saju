# Handoff: 명식당(命式堂) 사주 앱 — 전체 목업 v2

## Overview
사주 상담 앱 **명식당**("당신의 운명을 위한 오늘의 한 상")의 전체 화면 목업.
로그인 → 로딩 → 메인(오늘/내 원국) → 사주분석 → 사주 재미 → 내 설정 + 좌상단 햄버거 드로어, 우상단 프로필 팝오버, 하단 글래스 플로팅 알약 네비까지 한 파일에서 실동작하는 인터랙티브 프로토타입이다.
캐릭터(주인) 이름: **연리(緣理)** — 수셰프 콘셉트. 식당 은유 카피 시스템: 리포트=메뉴판, 기본 리포트="오늘의 한 상", 심층/유료="코스 요리", 일진="매일 반찬".

## About the Design Files
이 번들의 파일들은 **HTML로 만든 디자인 레퍼런스**(프로토타입)다. 프로덕션 코드가 아니며 그대로 복사해 쓰는 용도가 아니다.
할 일은 이 디자인을 **대상 코드베이스(muteno/Saju — React + Vite + MUI, app/src/)의 기존 패턴으로 재구현**하는 것이다. 기존 앱의 토큰(`app/src/index.css`의 CSS 변수, `app/src/theme.ts`)과 컴포넌트 문법(Screen/StatusBar/OhaengTile/SajuTable 등)을 계승하되, 이 목업의 화면 구조·규격을 적용한다.

`05 명식당 앱 목업 v2.dc.html`은 커스텀 러너용 포맷이지만 내용물은 표준 HTML/인라인 스타일 + 작은 상태 클래스라 그대로 읽으면 된다. `<sc-if value="{{ isX }}">` = 화면 라우팅 조건, `{{ handler }}` = 클릭 핸들러, 하단 `<script data-dc-script>`의 `Component` 클래스 = 화면 상태 머신.

## Fidelity
**High-fidelity.** 색·타이포·간격·블러 값 전부 확정값. 픽셀 수준으로 재현할 것.
(단, 캐릭터 아트는 아이샤 플레이트(aisha.png)를 임시 사용 중 — 연리 아트가 나오면 교체.)

## Interactions & Behavior
- 라우팅: 단일 상태 `screen` ∈ {login, signup, find, loading, home, myday, analysis, fun, settings} + `drawer`/`profile` 불리언. 화면 전환 = `fadein .3s`.
- 로그인/가입 CTA → loading(문구 "연리가 만세력을…") → 1.5s → home.
- 재미 콘텐츠 탭 → loading(문구 "궁합 케미를 계산 중이에요.") → 1.5s → fun 복귀.
- press 상태: 모든 탭 가능 요소 `transform: scale(.98)` .12s ease(.2,.7,.3,1).
- 애니메이션 키프레임: floaty(로딩 타일), fadein(화면), slidein(드로어), popin(팝오버), bob(있다면 ▼ 인디케이터).

## State Management
```
screen: 'login' | 'signup' | 'find' | 'loading' | 'home' | 'myday' | 'analysis' | 'fun' | 'settings'
drawer: boolean, profile: boolean  (전환 시 항상 둘 다 false)
loadingTitle: string  (로딩 진입 시 컨텍스트별 설정)
```
실서비스에선 기존 Saju 엔진(computeChartUI/toReading/myTodayFortune)과 프로필 스토리지(data/profiles.ts)에 연결 — 목업의 수민/병술/78점/72점은 전부 그 산출물 자리의 샘플이다.
