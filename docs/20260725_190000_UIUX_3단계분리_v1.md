# 리포트 3단계 분리 — 인트로 · 분석 · 상담 v1

> 지시: [Q. 34] 2026-07-25 18:5x — "기본 개요, 상담하기 이런거는 아예 분리를 하고 / 맨 인트로에 기본 원국이랑 오늘 사주 봐주는 점수 느낌으로. 그리고 그 다음에 구체적으로 사주 분석 풀이, 그리고 그 다음에는 미연시 뭐 이렇게 구분하면될듯"
> 운영자 확정(문답): 3단계를 **탭 축에 앉힌다** — 오늘+원국을 인트로로 합치고 탭 = 인트로·분석·상담·재미·설정
> 영수증: `app/public/reports/20260725_190000_uiux-3step_v1/`
> 체험: `/?qa=1&view=result` → `&view=analysis` → `&view=talk`

## 1. 전 → 후

```
전 — 한 화면(/result) 긴 스크롤
  원국표 → 오행 → 연리 인사 → 상담 → 근거 리포트 7섹션 → 대운 레일 → 공유
  ↳ 층위 없음. 어디까지가 '기본상'이고 어디부터가 '더 파고들기'인지 안 보임

후 — 세 화면
  ① 인트로  /result    원국표 7행 + 오행 + 오늘 점수(근거 병기)  → [분석 풀이 보기] [상담하기]
  ② 분석    /analysis  구조판정·일주·십신·합충·신살·세운 + 대운  → [연리와 상담하기]
  ③ 상담    /talk      미연시 단독(정곡 단정 → 선택지 → 주제)     → [분석 풀이 보기]

하단 탭 = 인트로 · 분석 · 상담 · 재미 · 설정   (앞 3칸 = 3단계 순서)
드로어   = 같은 5축 1:1(라벨만 길게 = 무엇인지 설명)
```

## 2. 화면별 설계 근거

### ① 인트로 (`/result`)
- **여기서 끝내도 되는 화면.** 확정 태그라인 「당신의 운명을 위해, 오늘도 한 상」 = 매일 들러 한 상 받고 나가는 게 핵심 루프 → **원국 + 오늘 점수까지가 기본상**.
- 오늘 점수는 엔진 일진 관계(합충형파해·공망) 정책 산출이라 **근거를 함께 적는다**("내 일주와 자오충 · 공망 발동") — 근거 병기는 이 앱의 신뢰 축이다.
- `/result`를 인트로 주소로 쓴 이유: **기존 공유 링크가 전부 이 주소**를 가리킨다. 바꾸면 나간 링크가 죽는다.

### ② 분석 (`/analysis`)
- 전엔 요약 2섹션만 보여주는 **중복 화면**이었고 실제 풀이는 `/result` 뒷부분에 있었다 → 이제 **근거 전 섹션 + 대운 레일**을 통째로 받는다.
- 인트로에서 본 원국이 '무엇을 뜻하는가'가 이 화면의 정의다.

### ③ 상담 (`/talk`)
- 탭 하나가 통째로 대화. 연출(타이프라이터 · 정곡 단정 → [맞아/아니야] 분기 → 的中 크리티컬·리커버리)은 **DosaChat 정본 그대로** — 이 화면은 그릇만.
- 대화 영역에 `flex: 1` — 대화가 짧을 때 하단 400px이 비던 걸 막고, 진행되며 자라도 레이아웃이 유지된다.

## 3. 코드 구조 — 3중 복제를 막은 방법

| 무엇 | 왜 |
|---|---|
| `data/useReport.ts` **신설** | 세 화면이 같은 원국·리딩·정곡을 쓴다. 데이터 해소(URL 파라미터 → 저장 프로필 → 샘플) 로직을 **한 곳에만** 둔다. `stepPath()`로 화면 이동 시 쿼리 유실 방지 |
| `components/ReportParts.tsx` **신설** | 공유 표시 부품(`SectionTitle`·`OhaengStrip`·`DaeunRail`·`ReportCard`·`GlassButton`)을 이전. **마크업·값 변경 0**(§B1) |
| `Home.tsx`·`Myday.tsx` **삭제** | 인트로가 둘의 역할을 흡수. 남겨두면 죽은 화면이 정본을 흐린다. 구 `/`·`/myday`는 **쿼리·해시 보존**해 인트로로 이동(`<Keep to>`) |
| `MyeongShell` `MenuKey` 재정의 | `'intro' \| 'analysis' \| 'talk' \| 'fun' \| 'settings'` · 탭·드로어가 같은 5축 |
| `Pict.chat` 추가 | 상담 탭 픽토그램(말풍선 · 대칭 viewBox path — 문자 도형 금지 §방식론 2) |
| `qa.ts` VIEWS 갱신 | `result·analysis·talk`… — 3단계 딥링크가 QA에서 살아있게 |
| **스모크 게이트 확장** | `npm run verify`가 **3화면 전부** 실렌더 확인 — 라우트 재편이 화면을 빈 셸로 만들면 커밋 전에 잡힌다 |
