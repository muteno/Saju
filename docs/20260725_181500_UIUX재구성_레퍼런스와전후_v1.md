### 1-3. 레퍼런스가 우리 앱에 지목한 것
1. **만세력('내 원국')은 최상위 항목이다** — 포스텔러·천을귀인·점신 모두 그렇다. 우리는 하단 탭에 없고 홈 세그먼트로만 들어갔다 = 역행.
2. **긴 리포트는 앱 껍데기 안에 있다** — 어느 앱도 결과 화면에서 탭을 없애지 않는다. 우리 `/result`는 셸 밖 = 막다른 길.
3. **콘텐츠 뒤에 사진을 깔지 않는다** — 우리 `/result`는 캐릭터 플레이트를 전면 배경으로 깔아 글자 65개가 사진 위에 얹혔다.
4. **표에는 행 라벨이 있다** — 우리 원국표 7행은 라벨이 없어 지장간·운성·신살이 값 더미로 보였다.
5. **대화식이 강점이다**(헬로우봇·마이파이) — 우리 L4 도사 대화는 방향이 맞다. 유지·강화.

## 2. 재구성 — 전 → 후

### R1. `/result` 첫 화면: 전면 배경 → '담긴 스테이지' (최대 변화)
- **전**: `CharacterStage`를 `inset:0` 전면 배경으로 깔고 그 위에 원국표·오행·대화를 얹음. 라이트 단일 테마에서 `--stage-scrim`이 `transparent`라 보호막 0 → 캐릭터 머리카락 위 회색 지장간·운성·신살이 안 읽힘.
- **후**: 스테이지가 **높이 300px을 갖고 끝난다**(하단 45% 페이드 → `--c-page`). 아래 콘텐츠는 단색 위에서 시작 = **스크림 없이 가독이 성립**.
- 계승: 이 마크업은 창작이 아니라 같은 레포 `Analysis.tsx`(72–87행)에서 이미 정상 작동하던 것을 공용 부품(`CharacterStage`)으로 승격해 두 화면이 함께 쓴다. 포스텔러도 콘텐츠 뒤에 사진이 없다.

### R2. `/result`를 앱 셸에 편입
- **전**: `MyeongShell` 밖 → 하단 네비 0, 이탈로 `‹ 홈` 1개.
- **후**: 셸 안(활성 탭 = 분석). 임시 탈출구 `‹ 홈` 제거. `gate={false}` 신설 — 공유 링크 수신자(프로필 없음)를 로그인으로 튕기지 않으면서 크롬은 준다. 오류 상태도 셸 안으로.

### R3. 하단 탭 4 → 5 (세그먼트 폐지)
- **전**: 탭 4(오늘·분석·재미·설정) + 홈 세그먼트(오늘/내 원국) + 드로어 5 → 같은 목적지 진입로 3개, 네비 문법 2중.
- **후**: 탭 5(오늘·원국·분석·재미·설정) = **드로어 5항목과 1:1**. `HomeSegment` 부품 삭제(사용처 0). 390px에 5칸이 들어가도록 좌우 패딩만 17→12(높이 40·반경·색은 정본 그대로).

### R4. 상주 크롬 유리 불투명화
- **전**: `rgba(255,255,255,.28)` + `blur(11px)` → 알약 안쪽에서도 뒤 본문이 읽혔다.
- **후**: `.92` + `blur(11px) saturate(0)` — 채도 0으로 뒤 색까지 차단(방식론 §3-c). 유리감(blur)은 유지. 햄버거·아바타·알약이 같은 `chromeGlass` 상수를 쓴다(단일 표준).
- ※ `.78` 중간값은 실렌더에서 여전히 글자가 읽혀 재상향했다.

### R5. 홈 히어로 세로 스택
- **전**: 날짜 블록 + 이름을 한 행 `alignItems:flex-end` → 이름이 2줄이면 43px 위로 침범해 엉킴.
- **후**: 날짜 캡션 위 · 이름 아래 세로 스택(포스텔러 결과 헤더 문법). 이름이 몇 줄이 되든 날짜를 밀지 않는다. 온보딩 히어로도 같은 문법으로 통일.

### R6. 원국표 행 라벨 추가
- **전**: 4열만 세로로 쌓아 지장간·12운성·12신살이 라벨 없는 값 더미.
- **후**: 전체 7행 모드에 좌측 라벨 열(십성·천간·지지·십성·지장간·12운성·12신살). 컴팩트 모드('내 원국')는 기존대로.

### R7. 캐릭터 정체성 단일화
- **전**: 홈·분석 = `chef-default.jpg`(남신) / `/result` = `aisha.png`(여성) + 이름표 "아이샤" + 🐴 / 드로어 = "주인 연리" → **이름 3개·얼굴 2개**.
- **후**: 플레이트는 `chefs.ts` 레지스트리 단일 경유(`aisha.png` 참조 0). 화자 이름 = `HOST_NAME`(연리) 단일 상수 — 드로어·홈 카피가 이미 쓰던 확정 브랜드값에 리포트를 맞췄다.
- ⚠ **연리 ↔ 셰프단(기본캐)의 배치·총칭 관계는 Q.16 미확정** — 확정되면 `HOST_NAME`과 `CHEFS`의 관계를 정리한다. 이번 변경은 '구 이름 잔재 제거 + 확정값 적용'이고 위계를 새로 정하지 않았다.

### R8. 문자 도형 → SVG 픽토그램
- **전**: `↗ ✉ ✎ ✓ ‹ ▼` 문자 렌더(원·박스 정중앙에서 편심) + 이모지 `🎴 🕰️ 🍀`(🎴는 빨간 사각형으로 렌더).
- **후**: `Pict` 레지스트리에 `share·mail·pencil·check·chevronLeft/Down/Right` 7종 추가(대칭 viewBox path). 리포트 섹션 라벨의 이모지는 렌더 제거(라벨은 텍스트 단독 = §6-b).
- 남은 것: 띠 동물 이모지 🐴 = **일러스트 자산 대기 폴백**(콘텐츠, 표지판 도형 아님 — 포스텔러도 띠 동물 아바타를 쓴다) · `정재 ×2`의 `×` = 곱셈 표기(텍스트).

### R9. '준비 중' 단일 표준
- **전**: 한 리스트에 '준비 중' 텍스트 3 + 셰브론 `›` 1 혼재, 비활성 dim 없어 다 눌러보게 됨.
- **후**: `SoonBadge` 부품(테두리 알약 배지) + 카드 `opacity .58` + `aria-disabled`가 한 쌍. 활성 항목만 선명 + SVG 셰브론. 랭킹 섹션은 행마다 반복하지 않고 섹션 dim + 배지 1개.
